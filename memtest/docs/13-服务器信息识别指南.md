# 13 · 服务器信息识别指南

> 状态：[当前有效]（2026-10-22）
> 变更记录：2026-10-22 创建
> 目标读者：纯小白操作员。目标场景：拿到一台**不知道是什么厂商**的服务器，用它自己查出来厂商、型号、序列号。
> 阅读前提：不需要任何基础，照着下面一步步抄命令就行。

---

## 一句话总结

在服务器上打开 PowerShell，输入下面这一条命令，回车，就能看到厂商和型号：

```powershell
Get-CimInstance Win32_ComputerSystem | Select-Object Manufacturer, Model
```

---

## 一、先搞懂「厂商」是什么

**厂商 = 这台服务器是哪个牌子造的。**

常见的有：

| 中文叫法 | 英文/缩写 |
| --- | --- |
| 联想 | Lenovo |
| 戴尔 | Dell |
| 惠普 / 慧与 | HP / HPE |
| 浪潮 | Inspur |
| 华为 | Huawei |
| 超微（DIY 服务器常用） | Supermicro |

为什么要查厂商？
- **查保修**要用序列号（SN）；
- **装驱动 / 更新固件**要去对应厂商官网，按厂商+型号找；
- 服务器上内存槽、硬盘位的排布，不同厂商长得不一样。

---

## 二、Windows 服务器怎么查（最常用）

### 2.1 先打开 PowerShell（黑窗口）

1. 点击屏幕左下角「开始」按钮；
2. 输入 `powershell`（拼音的话可以输入拼音：`windows powershell`）；
3. 在搜索结果里，对 **Windows PowerShell** 点鼠标右键 → 选「**以管理员身份运行**」（推荐，有的命令需要权限）；
4. 弹出来的黑色窗口就是 PowerShell。

### 2.2 查厂商和型号（最常用的一条）

把下面这行**完整复制**进黑窗口，按回车：

```powershell
Get-CimInstance Win32_ComputerSystem | Select-Object Manufacturer, Model
```

看到的结果类似（举例）：

```
Manufacturer : LENOVO
Model        : 21SJ
```

- `Manufacturer` = 厂商（牌子）
- `Model` = 型号

### 2.3 查序列号（SN，查保修要用）

```powershell
Get-CimInstance Win32_BIOS | Select-Object Manufacturer, SMBIOSBIOSVersion, SerialNumber
```

- `SerialNumber` = 序列号，去厂商官网报这个号就能查保修/下载对应驱动。

### 2.4 老系统（Win7 / Windows Server 2012 及更老）用这条

如果上面命令报错「找不到 Get-CimInstance」，说明系统太老，改用旧命令：

```powershell
wmic csproduct get name, vendor, identifyingnumber
```

（`vendor` = 厂商，`name` = 型号，`identifyingnumber` = 序列号）

---

## 三、Linux 服务器怎么查

如果服务器装的是 Linux（而不是 Windows），在命令行里输入（需要 root 权限）：

```bash
dmidecode -t system | head -10
```

看到的结果类似：

```
Manufacturer: LENOVO
Product Name: 21SJ
Serial Number: PW0RQD3Q
```

## 四、从 BMC 管理网页里看（最省事的办法）

很多服务器（尤其联想、戴尔、浪潮）都带一个独立的**管理口（BMC）**——它有自己的 IP，用浏览器登录进去，厂商、型号、序列号一眼就能看到。

### 4.1 先拿到 BMC 的 IP 地址（最关键的一步）

BMC 是一个**单独的管理网口**（一般在机箱背面，旁边标注 `Mgmt` / `IPMI` / 扳手图标，和普通网口不是同一个），它有自己独立的一串 IP。拿到这个 IP 的几种办法（按推荐顺序）：

1. **看机箱上的贴纸**：服务器侧面/背面通常贴了一张小标签，写着管理 IP、用户名、密码（最省事，先找它）；
2. **问网管**：管理 IP 一般由网络管理员统一规划；
3. **在服务器本机查**（服务器装的是 Windows，且本机有 IPMI 驱动时）：
   ```powershell
   ipmitool lan print 1
   ```
   （输出里 `IP Address` 那一行就是 BMC 的 IP；本机没有 ipmitool 时，用本项目离线包 `tools\ipmitool\` 里自带的）

### 4.2 用浏览器打开

1. 打开浏览器（Chrome / Edge 都行）；
2. 在**地址栏**输入 `https://` 加上 BMC 的 IP，比如 `https://192.168.1.100`，按回车；
3. **第一次会提示「证书不安全 / 您的连接不是私密连接」**——这是正常的（服务器自带证书），点「**高级**」→「**继续前往**」就能进。

### 4.3 登录

1. 输入用户名和密码（机箱贴纸上写的默认账号，或者网管给的）；
2. 第一次登录通常**会强制你改一个自己的密码**，照提示改掉并记住；
3. 登录后找「**系统信息 / System Information**」（或「概览 / Overview」）页面，上面直接写着厂商、型号、序列号。

### 4.4 各厂商的管理界面叫什么（别被名字吓到）

| 厂商 | 管理界面名字 |
| --- | --- |
| 戴尔 Dell | iDRAC |
| 惠普/慧与 HP/HPE | iLO |
| 联想 Lenovo | XCC（XClarity Controller） |
| 华为 Huawei | iBMC |
| 浪潮 Inspur | BMC |

### 4.5 网页打不开怎么办

| 现象 | 怎么办 |
| --- | --- |
| 地址栏输入后一直转圈/超时 | 确认没拼错 IP；确认用的是 **BMC 管理口**那根网线而不是普通网口；确认你的电脑和 BMC 在同一网段 |
| 提示「无法访问此网站」 | 试试把 `https://` 换成 `http://`，或不带前缀直接输入 IP |
| 弹出「证书错误」 | 正常，点「高级 → 继续前往」 |
| 提示用户名/密码错误 | 看贴纸上的默认账号，或找网管 |

### 4.6 命令行也能看（进阶，可选）

本项目离线包 `tools\ipmitool\` 已带 ipmitool 工具，在**编排机**上也能查（只要网络通）：

```powershell
ipmitool -I lanplus -H <BMC的IP> -U <用户名> -P <密码> fru
```

（把 `<BMC的IP>`、`<用户名>`、`<密码>` 换成实际值；`fru` 输出里的 `Manufacturer` / `Product Name` 就是厂商和型号）

### 4.7 在 BMC 里怎么看 IP（注意：有两类"IP"）

在 BMC 网页里能看到的 IP 分两种，别搞混：

**① BMC 自己的管理 IP**（就是浏览器地址栏输入的那个）
- 登录后找菜单里的「**网络设置 / Network / 网络**」；
- 里面「**IPv4 地址 / IP Address**」那一行就是；
- 用途：以后就用这个 IP 登录 BMC。

**② 服务器操作系统（系统）的 IP**（业务 IP，系统之间通信用的）
- BMC 网页里**一般看不到**系统的 IP（BMC 只管理自己的网口，管不到系统网卡）；
- 要看系统 IP，两个办法：
  - **能远程到服务器**（远程桌面 / SSH）时，进系统里查：
    - Windows：打开 PowerShell 输入 `ipconfig`，看「IPv4 地址」；
    - Linux：输入 `ip addr`。
  - **什么远程方式都没有**时，用 BMC 里的「**远程控制台 / Remote Console**」（相当于隔着网页看服务器屏幕），登录进系统后，再用上面 `ipconfig` / `ip addr` 查。

## 六、怎么判断是不是「白牌 / 组装机」

「组装机」= 不是整机厂商统一出品，而是用散件拼的（类似自己攒电脑）。判断方法：

1. 查厂商：
   ```powershell
   Get-CimInstance Win32_ComputerSystem | Select-Object Manufacturer, Model
   ```
2. 再查主板：
   ```powershell
   Get-CimInstance Win32_BaseBoard | Select-Object Manufacturer, Product
   ```
3. 对比：
   - 两个结果**厂商一致**（比如都是 LENOVO）→ 品牌整机，正常；
   - 整机厂商显示的是某块主板厂名（Intel、Supermicro、技嘉…），且没有明确型号 → 基本就是**组装机/白牌机**。

组装机不影响测内存，但**查保修、找驱动**就要按主板型号去对应主板厂官网找。

## 七、常见问题（小白排查）

| 现象 | 原因 / 怎么办 |
| --- | --- |
| 提示「不是内部或外部命令」 | 没在 PowerShell 里输入，或者输错了字。重新复制命令再试。 |
| 提示「找不到 Get-CimInstance」 | 系统太老，用 2.4 的 `wmic` 命令。 |
| 提示「拒绝访问 / Access denied」 | 权限不够，重开一个「以管理员身份运行」的 PowerShell。 |
| 命令输进去没反应 | 确认已经按了回车；看是不是黑窗口处于别的状态。 |
