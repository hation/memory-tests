# 06 · 实践操作教程

> 状态：[当前有效]（2026-10-22）
> 变更记录：2026-10-22 文档体系编号化（对齐 disk-tests）；工程基建优化更新

> 从零到批量验收的分步演练。按顺序执行：先用 USB 方式验证 1 根条子跑通链路，再切换到 SOL 控制服务器，最后批量 1000 根。每步给出命令与判读。

---

## 阶段 0：环境准备（一次性，约 30 分钟）

1. 按 [04-运行环境与依赖安装说明.md](04-运行环境与依赖安装说明.md) 完成：
   - 编排机：Windows + PowerShell 5.1（系统自带，免装）
   - ipmitool：**已内置**在离线包 `tools\ipmitool\`（脚本自动发现，无需下载/安装）
   - 服务器 BMC 开启 SOL + BIOS 串口重定向 115200
2. 引导介质：BMC 虚拟介质挂 `boot\memtest.iso`，或 Rufus 写 U 盘
3. 自检通过（`ipmitool -V`、`Test-NetConnection <BMC_IP> -Port 623`）

**阶段 0 验收标志**：`ipmitool sol activate` 能看到服务器 BIOS 输出。

---

## 阶段 0.5：服务器测试能力评估（接入新服务器先做这个）

目标：新服务器接入时，先跑一键评估，确认它能测 17 项里的哪些，再决定做什么。

```powershell
# ① 在服务器本机（已进 Windows）跑：带内 + 带外合并评估
.\scripts\Run-ServerAssessment.ps1 -Local -BmcHost <BMC_IP> -BmcUser <u> -BmcPass <p> -MachineName srv01

# ② 编排机远程（服务器还没进系统时先做带外部分）
.\scripts\Run-ServerAssessment.ps1 -BmcHost <BMC_IP> -BmcUser <u> -BmcPass <p>
```

一键评估自动完成：带内 CIM（内存槽/ECC/类型/CPU/SecureBoot）+ 带外 BMC/IPMI（SOL/断电循环/测温）→ 输出 **17 项可行性 + 每项建议动作**，并给出下一步 SOL 验收命令。

产物（`memory_results\assessment\`）：
- `srv01-assessment.csv` —— 17 项逐项：Item/Name/Status/建议动作
- `srv01-assessment.txt` —— 汇总 + 下一步命令

**判读**：`可测`直接进阶段 1/2；`条件`补齐前提（如插满 ≥2 根）；`需补探测`先连 BMC 或进系统；`外包`送检（02 方案 L3）。

## 阶段 1：USB 方式验证 1 根条子（推荐先用这个，最易排查）

目标：用最简单的链路验证"引导 → 测试 → 报告解析"全流程。

```powershell
# 1. 插好 1 根条子，运行编排（USB 方式，1 轮快速）
.\scripts\Run-MemtestSuite.ps1 -BatchName laptop01 -BootMethod USB -UsbDrive E: -MaxPasses 1
```

实际操作（半自动）：

1. 脚本先自动识别建档（读到序列号/容量/频率）
2. 按提示把 U 盘插到被测机引导 → Memtest86+ 自动开测
3. 测完按 **F1 → 6** 保存报告到 U 盘
4. 脚本自动发现新报告（`MT86P_*`）→ 拷回 → 解析 → 汇总

**阶段 1 验收标志**：`memory_results\reports\laptop01-report.csv` 中该条子 `Result=PASS`、`Errors=0`。

> 常见问题：U 盘不引导（关 Secure Boot 或导入证书）；报告没出现（确认测完按了 F1→6）。

## 阶段 2：切换 SOL 控制服务器（全自动）

目标：从服务器 BMC 远程拿 MTLOG，无人值守。

```powershell
# 1. 一次性引导：BMC 虚拟介质挂 memtest.iso，引导参数加：
#    log=ttyS0,115200 maxpasses=4
#    （或先用 BIOS 设 USB 引导，配好 syslinux 的 APPEND）

# 2. 编排机启动 SOL 全自动验收
.\scripts\Run-MemtestSuite.ps1 -BatchName batch01 -BootMethod SOL `
  -BmcHost 192.168.1.10 -BmcUser admin -BmcPass pwd -MaxPasses 4 -ConfirmSwitch
```

脚本自动完成：识别建档 → `ipmitool sol activate` 抓流 → 等 `ev=done` → 关会话 → 解析 → 汇总。

**阶段 2 验收标志**：日志中出现 `ev=done passes=4 status=pass`，报告 `Result=PASS`。

> 常见问题（详见 [09-SOL使用指南.md](09-SOL使用指南.md) 第 7 节）：
> - 无输出 → BMC 没开 SOL / BIOS 没开重定向
> - 乱码 → 波特率三处不一致
> - 不自动重启 → 引导参数没用 `log=` 模式

## 阶段 3：批量 1000 根（无人值守）

目标：批次清单驱动全部批次，输出全量总表。

1. 每批插满槽位（8–16 根），给每根贴唯一 ID
2. 编辑批次清单（模板 `config\batches.example.csv` → `batches.csv`），每批一行
3. 预览后正式运行：

```powershell
.\scripts\Run-BatchScheduler.ps1 -ManifestCsv .\config\batches.csv -DryRun   # 先预览
.\scripts\Run-BatchScheduler.ps1 -ManifestCsv .\config\batches.csv -ContinueOnError
```

4. 失败批次自动记录（或 `-ContinueOnError` 跳过继续），可 `-ParseOnly` 断点续解析

**阶段 3 验收标志**：`all-batches-report-<时间戳>.csv` 覆盖全部批次，逐根可追溯。

> 吞吐量参考（仅快速筛选轮）：8 槽服务器 24h 连轴约 5–6 天；多台并行约 2–3 天。

## 阶段 4：报告解读与收尾

| 报告文件 | 看什么 |
| --- | --- |
| `<批次>-report.csv` | 每根 Result（PASS/FAIL/未测） |
| `all-batches-report-*.csv` | 全量逐根总表 |
| `master_manifest.csv` | 累计数据库（历史趋势） |
| `raw\` | 原始 MTLOG/报告备份（审计用） |

- 全 PASS → 批次验收通过，出具报告
- 有 FAIL → 单条单槽隔离复测（见 [01-验收测试方案.md](01-验收测试方案.md) 第 5 章排查流程）
- 抽样可靠性项（ECC/ORT/断电循环）与外包项按 [02-批量压力测试方案.md](02-批量压力测试方案.md) 执行
