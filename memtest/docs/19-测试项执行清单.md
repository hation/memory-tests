## 1. 执行顺序总览（先看这张）

```
阶段 0 准备与校验（一次性）
   check_env.ps1 → Diag-Bmc.ps1 → Run-ServerAssessment.ps1
   ↓
阶段 1 建档 ── 第 1/2 项（SPD 校验 + 识别建档）      ← 服务器本机跑
   ↓
阶段 2 全量压测 ── 第 3 项（Memtest 全地址覆盖）       ← 编排机跑
   1轮快筛(摸底) → 2轮全项 → 4轮全项(验收口径)
   ↓
阶段 3 混插 ── 第 16 项（多通道混插压力）              ← 编排机 + 服务器 Windows
   ↓
阶段 4 抽样可靠 ── 第 4/5/10/15 项（L2 抽样）          ← 编排机 + 服务器
   ↓
阶段 5 外包送检 ── 第 6/7/8/9/11/12/13/14 项（L3）      ← 无硬件，只能外包
   ↓
（第 17 项目检+电性：人工，随时可与任何阶段并行）
```

> 标注：**当前进度**见第 4 节；每项详细做法见第 3 节（含输出文件路径与下一项）。

## 2. 阶段 0：准备与校验（一次性，约 10 分钟）

| 步骤 | 命令（在 C:\memtest 下） | 输出文件 | 通过标准 |
| --- | --- | --- | --- |
| ① 环境自检 | `powershell -NoProfile -ExecutionPolicy Bypass -File scripts\check_env.ps1` | 控制台 | 全部 OK |
| ② BMC/SOL 链路 | `powershell -NoProfile -ExecutionPolicy Bypass -File scripts\Diag-Bmc.ps1 -BmcHost 10.0.0.10 -BmcUser root` | 控制台 | 四步无 Error（④ 空闲时无输出属正常） |
| ③ 能力评估（两段式+合并） | **服务器本机**（自动判为被测服务器，免密码提示）：<br>`powershell -NoProfile -ExecutionPolicy Bypass -File scripts\Run-ServerAssessment.ps1 -MachineName srv01`<br>**编排机**（自动判为编排机；不带 `-VerifyPowerCycle`，只读探测不重启服务器）：<br>`powershell -NoProfile -ExecutionPolicy Bypass -File scripts\Run-ServerAssessment.ps1 -BmcHost 10.0.0.10 -BmcUser root -BmcPass <密码> -MachineName srv01`<br>**合并完整 17 项**（先把另一台的 cap CSV 拷到本机同一目录，文件名带角色后缀自动区分）：<br>`powershell -NoProfile -ExecutionPolicy Bypass -File scripts\Run-ServerAssessment.ps1 -MergeInband srv01-cap-被测服务器.csv -MergeOob srv01-cap-编排机.csv -MachineName srv01` | 服务器+编排机各产 `results\assessment\<机器>-cap-<角色>.csv`（角色=被测服务器/编排机，自动区分）；合并报告 `results\assessment\srv01-assessment.csv/.txt` | 两段各产出 cap CSV、合并报告确认第 4 项 ECC、第 10 项电源（可测=命令可用，不重启；重启实测由 RestartLoop 完成）、第 15 项平台 |

**完成标准**：环境 OK、BMC 通、评估出结果。
**下一项去哪**：→ 阶段 1 建档。

## 3. 17 项逐项执行清单

> 每项给出：**前置 / 怎么做 / 判据 / 输出文件在哪 / 下一项去哪**。
> ✅ = 当前能测；⚠️ = 有条件（见前置）；❌ = 当前不能测（无硬件）。

### 第 1/2 项 · SPD 校验 + 基础识别建档（L1 全量）— ✅

| 项 | 说明 |
| --- | --- |
| 前置 | 服务器已进 Windows；管理员权限 |
| 怎么做 | **在服务器本机**跑识别建档（读服务器真实内存）：`powershell -NoProfile -ExecutionPolicy Bypass -File scripts\Identify-Memory.ps1 -BatchName srv01-a1` |
| 判据 | 容量/频率/厂商/序列号与标签一致（防调包）；SPD 无 CRC 错误 |
| **输出文件** | 服务器 `C:\memtest\results\srv01-a1.csv`（批次清单）+ `results\master_manifest.csv`（累计） |
| **下一项去哪** | → 阶段 2（第 3 项 Memtest） |

> 说明：编排机自动建档读的是编排机内存，**服务器真实条子清单必须以服务器本机这份为准**（docs/18 §5.3）。

### 第 3 项 · 全地址读写覆盖（Memtest）（L1 全量）— ✅

| 项 | 说明 |
| --- | --- |
| 前置 | BMC/BIOS 一次性配置好（docs/09 §3）；ISO `memtest-sol.iso` 就位；编排机可通 BMC |
| 怎么做 | 编排机跑编排器（**先启动编排器，再引导服务器**，docs/18 §5.5）三档：① 1轮快筛（摸底，可选）② 2轮全项 ③ **4轮全项（验收口径）**；每档菜单选对应预设，`-MaxPasses` 一致 |
| 判据 | `Errors=0`、`Status=pass`、`Passes=N` 与你选的轮次一致 |
| **输出文件** | 编排机 `C:\memtest\results\raw\<批次>.mtlog.txt`（原始日志）+ `results\reports\<批次>-report.csv`（逐根报告）+ `results\master_manifest.csv`（累计） |
| **下一项去哪** | 4轮全项通过 → 第 16 项（混插） |

命令示例（每轮换 BatchName 与 -MaxPasses）：
```powershell
# 2轮全项（第 2 档）
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\Run-MemtestSuite.ps1 -BatchName srv01-a1-r2 -BootMethod SOL -BmcHost 10.0.0.10 -BmcUser root -MaxPasses 2 -ConfirmSwitch
```

### 第 16 项 · 多通道混插压力（L1 全量）— ✅

| 项 | 说明 |
| --- | --- |
| 前置 | 服务器插满 ≥2 根（当前已插 2 槽 / 64GB，满足） |
| 怎么做 | 混插组合跑 Memtest（同第 3 项，1轮全项即可）+ 服务器 Windows 内跑 TM5/Prime95/OCCT 2–4h（TM5/OCCT **未随包，需自备**；**Prime95 已内置** `tools\prime95\`，docs/18 §5.4） |
| 判据 | 0 错误；单根不稳 → 单根隔离排查 |
| **输出文件** | Memtest 部分：编排机 `results\reports\<批次>-report.csv`；TM5 部分：软件自身日志（人工记录，无固定路径） |
| **下一项去哪** | → 阶段 4（L2 抽样） |

### 第 4 项 · ECC 纠错验证（L2 抽样）— ✅（服务器 ECC=True）

| 项 | 说明 |
| --- | --- |
| 前置 | 服务器是 ECC 平台（**已确认 ECC=True**）；条子为 ECC 条 |
| 怎么做 | 全项/快筛预设已内置 `ecc` 轮询（服务器侧）→ 测完看编排机报告 `EccErrors` 列 + mtlog `ev=ecc/ev=uecc`；服务器本机 WHEA/mcelog 作交叉验证（可选） |
| 判据 | ECC 使能生效、可上报/纠错记录、无未纠正错误（UE） |
| **输出文件** | 编排机 `results\reports\<批次>-whea.csv`（WHEA/ECC 事件记录；**ECC 主体结果看 report.csv 的 `EccErrors` 列**） |
| **下一项去哪** | → 第 10 项（断电循环）或第 5 项（72h ORT） |

### 第 10 项 · 反复上电掉电重启循环（L2 抽样）— ✅

| 项 | 说明 |
| --- | --- |
| 前置 | BMC 已通（已确认）；从编排机运行 |
| 怎么做 | 编排机评估（不带 `-VerifyPowerCycle`）或 Diag-Bmc ② 确认第 10 项"可测(命令可用，未实测)"即具备断电循环能力（只读、不重启服务器）；然后跑 `-RestartLoop 200`（≥200 次，每次上电自动跑首轮、真断电-上电实测，或用 config\memtest-suite.conf 的 `RESTART_LOOP=200`） |
| 判据 | 全部循环正常初始化、无 DDR5 训练失败 |
| **输出文件** | 编排机 `results\reports\<批次>-powercycle.csv`（断电循环记录） |
| **下一项去哪** | → 第 5 项（72h ORT）或第 15 项（多平台） |

### 第 5 项 · 72h ORT 满载老化（L2 抽样）— ✅

| 项 | 说明 |
| --- | --- |
| 前置 | 内置 Memtest86+ ORT 模式（引导菜单选「72h ORT 无限轮」），无需自备负载软件；可选 Prime95 整机满载（`tools\prime95\` 内置）；可选加温舱位 |
| 怎么做 | 编排机 `-MaxMinutes 4320` 跑内置 ORT 模式（72h 满载 + 全程自动测温）；加温为可选增强；可选 Prime95 整机满载（先 ORT 通过后再决定） |
| 判据 | 口径 B：`Status=PASS`（实际时长 ≥4320 分钟 且 Errors=0 且 EccErrors=0 且 无中断 且 温度 ≤85°C） |
| **输出文件** | 编排机 `results\reports\<批次>-ort-report.csv`（ORT 结论）+ `<批次>-temp.csv`（温度记录）+ `master_manifest.csv`；Prime95 部分为服务器 `results.txt` |
| **下一项去哪** | → 第 15 项（多平台） |

### 第 15 项 · 多平台兼容（L2 抽样）— ⚠️（需另一台机器）

| 项 | 说明 |
| --- | --- |
| 前置 | 需另一台 Intel/AMD 平台机器（当前仅 Hygon） |
| 怎么做 | 另一平台跑：识别 + 快筛 + 满载 2–4h |
| 判据 | 0 错误、无兼容异常 |
| **输出文件** | 另一台机器的 `results\`（同上各文件） |
| **下一项去哪** | → 阶段 5（L3 外包） |

### 第 17 项 · 外观/焊点/电性目检（L1 全量）— ⚠️（需万用表）

| 项 | 说明 |
| --- | --- |
| 前置 | 人工目检（可先做）；电性复检需**万用表（需采购）** |
| 怎么做 | 目检金手指/焊点（IPC-A-610）；万用表测关键引脚短路/开路 |
| 判据 | 无氧化/虚焊/桥连；电性正常 |
| **输出文件** | 人工台账（建议记入批次验收表，无固定路径） |
| **下一项去哪** | 可随时并行，与其他项互不影响 |

### 第 6–9、11–14 项 · L3 外包（电压/时序/温循/湿热/ESD/振动/冲击/弯曲）— ❌
