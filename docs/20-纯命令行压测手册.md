# 20 · 纯命令行压测手册（编排机 + 服务器 现网版）

> 本机 BMC：IP `10.0.0.10` / 用户名 `root`（密码运行中提示输入）
> 部署约定：**编排机（你电脑）与服务器都部署于 `C:\memtest`**；所有命令从该目录运行。
> 状态：[当前有效]（2026-10-25）
> 变更记录：2026-10-25 新建（按现网环境整理的纯命令行压测手册）

> 现网环境速览：
> - **编排机** = 你电脑（Windows，能通 BMC，跑编排器/诊断/评估）
> - **被测服务器** = Hygon · 2 槽已用 / 64GB · DDR5-5600 · **ECC=True** · 通过 Ventoy 或 BMC 虚拟介质引导 `memtest-sol.iso`

## 测试周期评估（排期用，含 MONITOR_TEMP / RESTART_LOOP）

> 基准：被测服务器 **64GB · Hygon**；memtest 全项每轮 ≈ 1.5–2h（含较慢的随机/模 20 项）。

**档位基准时长**：

| 档位 | 时长 |
| --- | --- |
| 1轮快筛（前 9 项 × 1 轮） | ≈ 68 分钟（srv01-a1-r1 实测） |
| 1轮全项（13 项 × 1 轮） | ≈ 1.5–2h |
| 2轮全项 | ≈ 3–4h |
| 4轮全项（验收口径） | ≈ 6–8h |

**附加参数增量**：
- `MONITOR_TEMP`：**+秒级**（报告前读一次 IPMI 温度，不全程采样）→ 可忽略
- `RESTART_LOOP=N`：**+N×90 秒**（每次断电后等 90s）→ 200 次 = **+5h**（唯一显著大头）
- `MONITOR_ECC`：+秒级（读 WHEA 事件）→ 可忽略

**组合场景总耗时**（一条编排器命令带全参数）：

| 场景 | 构成 | 合计 |
| --- | --- | --- |
| 2轮全项（默认配置带 ECC/Temp） | 3–4h + 秒 | ≈3–4h |
| 4轮全项（验收口径） | 6–8h + 秒 | ≈6–8h |
| 4轮全项 + 断电循环 200 | 6–8h + 5h | **≈11–13h** |
| 断电循环专项（1轮全项 + 200 次） | 1.5–2h + 5h | ≈6.5–7h |
| 72h ORT（流程 6） | 72h(stress-ng) + 1.5–2h(memtest) + 秒 | ≈73.5–74h |

> 排期要点：**RESTART_LOOP 显著加时**——断电循环单独跑专项（勿与 4 轮全项叠一起）；
> MONITOR_TEMP / MONITOR_ECC 无感，随便开。

## 流程 0 · 准备与校验（约 10 分钟，一次性）

**做什么**：环境自检 → BMC 链路 → 服务器能力评估。

**命令**（编排机）：
```powershell
cd C:\memtest
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\check_env.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\Diag-Bmc.ps1 -BmcHost 10.0.0.10 -BmcUser root
```
**命令**（服务器本机跑，评估读服务器真实内存）：
```powershell
cd C:\memtest
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\Run-ServerAssessment.ps1 -Local -MachineName srv01
```

**得到什么**：check_env 输出"全部 OK"；Diag 四步无 Error（④ 空闲无输出属正常）；评估输出 17 项（服务器 ECC=True、混插已满足 2 槽）。

**日志在哪**：`C:\memtest\results\cmdlog\commands-<日期>.csv`（每步自动记录）+ `results\assessment\srv01-*.csv/.txt`（评估报告，服务器上）。

## 流程 2 · Memtest 压测（第 3 项）—— 编排机跑

**做什么**：SOL 远程抓 Memtest86+ 日志，跑满轮次自动出逐根报告。分三档：1轮快筛（已做 ✅）→ **2轮全项** → **4轮全项（验收口径）**。

**顺序铁律**：**先启动编排器（开 SOL 等日志）→ 再引导服务器**（Ventoy 或 BMC 虚拟介质挂 `C:\memtest\boot\memtest-sol.iso`，GRUB 菜单选对应预设）。顺序反了 = 白测。

**命令**（编排机；每档换 BatchName 与 -MaxPasses）：
```powershell
cd C:\memtest

# 2轮全项（约 3–4 小时）—— 菜单选「2轮全项」
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\Run-MemtestSuite.ps1 -BatchName srv01-a1-r2 -BootMethod SOL -BmcHost 10.0.0.10 -BmcUser root -MaxPasses 2 -ConfirmSwitch

# 4轮全项（验收口径，约 6–8 小时）—— 菜单选「4轮全项」
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\Run-MemtestSuite.ps1 -BatchName srv01-a1-r4 -BootMethod SOL -BmcHost 10.0.0.10 -BmcUser root -MaxPasses 4 -ConfirmSwitch
```

**得到什么**：编排器打印报告路径；判读 `Errors=0`、`Status=pass`、`Passes=N` 与所选轮次一致。
> 注：全项/快筛预设已带 ECC 轮询（`ecc` 参数），测完报告 `EccErrors` 列直接反映服务器 ECC 错误数；mtlog 可查 `ev=ecc/ev=uecc` 明细。

**日志在哪**（编排机）：`C:\memtest\results\raw\srv01-a1-rX.mtlog.txt`（原始日志）+ `results\reports\srv01-a1-rX-report.csv`（逐根报告）+ `results\master_manifest.csv`（累计）。

> 常用默认参数（BMC 地址/用户、ECC/温度监控开关）已配置在 `config\memtest-suite.conf`，命令行可省略；显式指定则覆盖配置。

## 流程 3 · 混插压力（第 16 项）

**做什么**：混插组合跑 Memtest（服务器已插 2 槽，满足条件）+ Windows 内跑 TM5 2–4h（TM5 未随包，需自备）。

**命令**（编排机，Memtest 部分）：
```powershell
cd C:\memtest
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\Run-MemtestSuite.ps1 -BatchName srv01-a1-mix -BootMethod SOL -BmcHost 10.0.0.10 -BmcUser root -MaxPasses 1 -ConfirmSwitch
```
（服务器引导菜单选「1轮全项」；TM5 在服务器 Windows 内人工跑，无固定命令。）

**得到什么**：0 错误；单根不稳 → 单根隔离复测。

**日志在哪**：编排机 `results\reports\srv01-a1-mix-report.csv`；TM5 软件自身日志（人工记录）。

## 流程 4 · ECC 验证（第 4 项）

**测完直接看报告**：全项/快筛预设已内置 `ecc` 轮询（服务器侧，memtest 直接读服务器 ECC 计数器）→ 报告 `reports\<批次>-report.csv` 的 `EccErrors` 列 + mtlog 的 `ev=ecc/ev=uecc` 即服务器 ECC 情况（`EccErrors=0` 正常；`>0` 有 ECC 错误需排查）。服务器本机 WHEA / Linux mcelog 仅作**交叉验证**（可选）。

## 流程 5 · 断电循环（第 10 项）—— 编排机跑

**做什么**：≥200 次断电-上电，验证 DDR5 上电训练稳定。

**第一步 · 用 `-VerifyPowerCycle` 自动验证断电循环**：编排机跑能力评估时置位该参数，脚本自动实测一次断电重启并给出"已验证/条件"结论；已验证可跳过人工确认。原始 `chassis power cycle` 手工命令保留为兜底参考：
```powershell
C:\memtest\tools\ipmitool\ipmitool.exe -I lanplus -H 10.0.0.10 -U root chassis power cycle
```
（服务器重启 = 命令生效；否则 BMC 不支持，别跑 200 次。）

**第二步 · 跑 200 次循环**（总耗时 ≈6.5–7h：1轮全项 1.5–2h + 断电 5h）：
```powershell
cd C:\memtest
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\Run-MemtestSuite.ps1 -BatchName srv01-a1-pc -BootMethod SOL -BmcHost 10.0.0.10 -BmcUser root -MaxPasses 1 -RestartLoop 200 -ConfirmSwitch
```
（或用 `config\memtest-suite.conf` 的 `RESTART_LOOP=200`。）

**得到什么**：200 次全部正常初始化、无训练失败。

**日志在哪**：编排机 `results\reports\srv01-a1-pc-powercycle.csv`。

## 流程 6 · 72h ORT 满载老化（第 5 项）

**做什么**：服务器满载 72h（软件需自备：stress-ng `--vm 0 --verify` / stressapptest / TM5）+ 测温。总时长 ≈73.5–74h。

**命令**（服务器，stress-ng 满载 72h）：
```powershell
stress-ng --vm 0 --verify -t 72h
```
**命令**（编排机，测温）：
```powershell
cd C:\memtest
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\Run-MemtestSuite.ps1 -BatchName srv01-a1-ort -BootMethod SOL -BmcHost 10.0.0.10 -BmcUser root -MaxPasses 1 -MonitorTemp -ConfirmSwitch
```

**得到什么**：72h 内 0 错误、无重启/蓝屏。

**日志在哪**：编排机 `results\reports\srv01-a1-ort-temp.csv`（温度记录）+ 负载软件自身日志（人工记录）。

**做什么**：查某天跑了什么命令、传了什么参数、结果如何。
**命令**：
```powershell
Import-Csv C:\memtest\results\cmdlog\commands-<日期>.csv
```
