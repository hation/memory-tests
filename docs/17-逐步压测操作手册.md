# 17 · 逐步压测操作手册（1轮全项 → 2轮 → 4轮验收）

> 本机 BMC：IP `10.0.0.10` / 用户名 `root`（密码运行中提示输入）；换机器只改这一处。
> 每条命令给两行：**原格式**（通用占位符）+ **本机版**（已填好，复制即用）。

> 状态：[当前有效]（2026-10-22）
> 变更记录：2026-10-22 新建（随菜单版 ISO 交付；预设含 1轮全项 / 2轮 / 4轮验收）

> 适用：对**同一台服务器 / 同一批内存**按轮次逐步加深做压力测试——
> **先测 1 轮全项 → 再测 2 轮 → 最后测 4 轮验收**，每轮通过后再进入下一轮，
> 全部通过后以 4 轮结果作为该批 Memtest86+ 压测的最终结论。

---

## 0. 本轮要回答的问题

| 轮次 | 菜单预设 | 编排器 `-MaxPasses` | 目的 |
| --- | --- | --- | --- |
| 第 1 轮 | `1轮全项（SOL）` | 1 | 全 13 项测试跑 1 遍，快速发现显性问题 |
| 第 2 轮 | `2轮（SOL）` | 2 | 加深覆盖，交叉验证第 1 轮结果 |
| 第 4 轮 | `4轮完整验收（SOL）` | 4 | 最终验收口径，与 17 项方案 L1 第 3 项一致 |

> 注意区分：菜单里还有一个「1轮快速筛选」（`testlist=0..8` 只跑前 9 项）——
> 那是**批量粗筛**用的，**本手册一律选「1轮全项」**，保证 1/2/4 轮口径一致、可对比。

## 1. 前置条件（一次性，确认后再开始）

1. BMC/IPMI 已开 SOL；BIOS 串口重定向已开且波特率 115200（见 `docs/09-SOL使用指南.md` 第 3 节，**这是最常见的失败点**）；
2. 编排机可 ping 通 BMC 管理 IP（`10.0.0.10`）；
3. 菜单版 ISO 已就位：离线包 `memtest\boot\memtest-sol.iso`（**已内置 1轮全项/2轮/4轮验收 等预设，无需重制**）；
4. 先做一次连通自检（可选，10 秒）：
   ```powershell
   # 原格式（通用）
   .\scripts\Diag-Bmc.ps1 -BmcHost <BMC_IP> -BmcUser <用户>
   # 👉 本机版（密码运行中提示）
   .\scripts\Diag-Bmc.ps1 -BmcHost 10.0.0.10 -BmcUser root
   ```
   四步（`mc info` / `chassis status` / `sdr elist` / `sol activate` 短探测）无 Error 即链路 OK。

## 2. 流程总览

```
准备（挂 ISO + 一次性引导 + 自检）
   │
   ├─ 第 1 轮：菜单选「1轮全项」→ 编排器 -MaxPasses 1 → ev=done passes=1 → 判读 PASS？
   │     ↓ 通过
   ├─ 第 2 轮：菜单选「2轮」→ 编排器 -MaxPasses 2 → ev=done passes=2 → 判读 PASS？
   │     ↓ 通过
   └─ 第 4 轮：菜单选「4轮验收」→ 编排器 -MaxPasses 4 → ev=done passes=4 → 判读 PASS？
          ↓ 通过
      结论：该批 Memtest86+ 压测通过（最终依据 = 4 轮报告）
   （任何一轮 FAIL → 停止加深，按第 6 节走失败件流程）
```

## 3. 通用操作（每轮相同的部分）

每轮都执行下面 6 步，只是 **菜单预设、`-MaxPasses`、`-BatchName` 不同**：

1. **BMC 挂 ISO**：BMC 网页 Virtual Media 挂载 `memtest-sol.iso`（首次挂好可一直保持挂载）；
2. **设一次性引导**：BMC 设置「从虚拟光驱一次性引导」（UEFI 模式）；
3. **先启动编排器**（SOL 会话先开着，等服务器引导后的日志）：
   ```powershell
   # 原格式（通用）
   .\scripts\Run-MemtestSuite.ps1 -BatchName <批次> -BootMethod SOL `
     -BmcHost <BMC_IP> -BmcUser <用户> -MaxPasses <N> -ConfirmSwitch
   # 👉 本机版（密码运行中提示；N 换成该轮轮次 1/2/4）
   .\scripts\Run-MemtestSuite.ps1 -BatchName srv01-a1-r1 -BootMethod SOL `
     -BmcHost 10.0.0.10 -BmcUser root -MaxPasses 1 -ConfirmSwitch
   ```
4. **引导服务器进 ISO**：BMC 上重启/引导服务器，KVM 看到 GRUB 菜单后选对应预设（见下表；20s 超时不按键会默认进「4轮验收」）；
5. **等待完成**：编排器自动轮询日志，收到 `ev=done` 后自动关会话、解析、出报告；超时上限 ≈ `N×90+30` 分钟；
6. **判读报告**（见第 5 节），通过则进入下一轮。

> **批次名建议每轮不同**：如 `srv01-a1-r1` / `srv01-a1-r2` / `srv01-a1-r4`。
> 同一批次名重复跑会覆盖上一次的 `results\reports\<批次>-report.csv`，且 `master_manifest.csv`
> 会跳过重复批次名的合并（保留旧记录），导致结果丢失。

## 4. 分步执行

### 第 1 轮：测 1 轮全项

| 项 | 值 |
| --- | --- |
| GRUB 菜单项 | **1轮全项（SOL）** |
| 编排器 `-MaxPasses` | 1 |
| 建议 `-BatchName` | `srv01-a1-r1` |

```powershell
# 👉 本机版（密码运行中提示）
.\scripts\Run-MemtestSuite.ps1 -BatchName srv01-a1-r1 -BootMethod SOL `
  -BmcHost 10.0.0.10 -BmcUser root -MaxPasses 1 -ConfirmSwitch
```
通过标准：报告 `Passes=1`、`Errors=0`、`Status=pass`。通过 → 第 2 轮。

### 第 2 轮：测 2 轮

| 项 | 值 |
| --- | --- |
| GRUB 菜单项 | **2轮（SOL）** |
| 编排器 `-MaxPasses` | 2 |
| 建议 `-BatchName` | `srv01-a2-r2`（或 `srv01-a1-r2`） |

```powershell
# 👉 本机版（密码运行中提示）
.\scripts\Run-MemtestSuite.ps1 -BatchName srv01-a1-r2 -BootMethod SOL `
  -BmcHost 10.0.0.10 -BmcUser root -MaxPasses 2 -ConfirmSwitch
```
通过标准：报告 `Passes=2`、`Errors=0`、`Status=pass`。通过 → 第 4 轮。

### 第 4 轮：测 4 轮（最终验收）

| 项 | 值 |
| --- | --- |
| GRUB 菜单项 | **4轮完整验收（SOL）**（默认项，超时自动进） |
| 编排器 `-MaxPasses` | 4 |
| 建议 `-BatchName` | `srv01-a1-r4` |

```powershell
# 👉 本机版（密码运行中提示）
.\scripts\Run-MemtestSuite.ps1 -BatchName srv01-a1-r4 -BootMethod SOL `
  -BmcHost 10.0.0.10 -BmcUser root -MaxPasses 4 -ConfirmSwitch
```
通过标准：报告 `Passes=4`、`Errors=0`、`Status=pass` → **该批 Memtest86+ 压测验收通过**。

## 5. 每轮结果判读

| 信号 | 含义 |
| --- | --- |
| 报告 `Passes=N` 与你选的轮次一致 | 该轮确实跑满 N 遍（避免选错预设） |
| `Errors=0` 且 `Status=pass` | 该轮通过 |
| `Errors>0` / `Status=fail` | 该轮失败 → 停止加深，走第 6 节 |
| 一直无 `ev=done`（超时） | 未跑完/未选对预设/链路问题 → 见第 7 节 |

记录建议（每轮一行，填到验收台账）：

| 轮次 | 预设 | BatchName | 开始时间 | 结束时间 | Passes | Errors | Status | 备注 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | 1轮全项 | srv01-a1-r1 | | | | | | |
| 2 | 2轮 | srv01-a1-r2 | | | | | | |
| 4 | 4轮验收 | srv01-a1-r4 | | | | | | |

报告文件：`results\reports\<批次>-report.csv`（逐根明细）；累计总表：`results\master_manifest.csv`。

## 6. 任一轮失败的处置

1. **停止后续加深测试**（没必要继续跑更多轮次）；
2. 根据 `report.csv` 的错误明细（`ev=data addr=...`）定位出错条子；
3. **单根隔离复测**：拆下疑似条子，单独装槽位重测该轮，确认是单根问题还是批次共性问题；
4. 批量层面按 `docs/02-批量压力测试方案.md` 的失败件流程处理（换货/复检/升级）。

## 7. 常见问题（摘要，详见 09 指南第 7 节）

| 现象 | 处理 |
| --- | --- |
| 菜单不出现/不进 ISO | UEFI 引导 + 虚拟介质一次性引导设置 + ISO 是 `memtest-sol.iso` |
| 编排器超时收不到 `ev=done` | 核对选中的菜单预设轮数与 `-MaxPasses` 一致；SOL/串口链路排查 |
| 串口乱码 | 三处波特率统一 115200（BIOS 重定向 / BMC SOL / 预设 `log=ttyS0,115200`） |
| `sol activate` 报 Cannot activate | SOL 被占用或权限不足 → `sol deactivate`；用户需 Operator/Admin |
