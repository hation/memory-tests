# 07 · 离线部署检查清单

> 部署/机房开工前逐项勾选。全部 ✅ 后才可开始批量验收；任一 ❌ 先按 [04-运行环境与依赖安装说明.md](04-运行环境与依赖安装说明.md) 或对应指南修复。

## A. 环境与工具

| 检查项 | 验证方式 | 结果 |
| --- | --- | --- |
| 编排机 Windows + PowerShell 5.1+ | `$PSVersionTable.PSVersion` | ☐ |
| 编排脚本可解析 | `Run-MemtestSuite.ps1 -Help` 有输出 | ☐ |
| ipmitool 可用（SOL 方式） | `tools\Setup-Tools.ps1` 已执行，`ipmitool -V` 有版本号 | ☐ |
| 离线包完整（Memtest86+ v9 ISO/binaries） | `boot\memtest.iso` 存在（6.2MB） | ☐ |

## B. 服务器 BMC / BIOS

| 检查项 | 验证方式 | 结果 |
| --- | --- | --- |
| BMC 已开 SOL | 厂商菜单：iDRAC Console/Media → SOL；Supermicro Console Redirection → COM2/SOL | ☐ |
| BIOS 串口重定向已开 | BIOS → Serial Port Console Redirection → Enable | ☐ |
| 波特率统一 115200 | BIOS、BMC、`log=ttyS0,115200` 三处一致 | ☐ |
| BMC 账号有权限 | 能 `ipmitool sdr elist`（Operator/Admin） | ☐ |
| 管理网络连通 | `Test-NetConnection <BMC_IP> -Port 623` | ☐ |

## C. Memtest86+ 引导

| 检查项 | 验证方式 | 结果 |
| --- | --- | --- |
| 引导介质就绪 | BMC 虚拟介质挂 `memtest.iso` 或 U 盘已写 | ☐ |
| 引导参数带 `log=` | 引导配置含 `log=ttyS0,115200 maxpasses=4` | ☐ |
| Secure Boot 处理 | 已关 Secure Boot 或导入 Memtest86+ 证书 | ☐ |
| SOL 链路实测 | `ipmitool sol activate` 能看到 BIOS/MTLOG 输出 | ☐ |

## D. Serial 方式（若用）

| 检查项 | 验证方式 | 结果 |
| --- | --- | --- |
| null-modem 交叉线 | 两端 DB9 对看：2脚↔3脚交叉 | ☐ |
| 端口号确认 | 设备管理器 → 端口 (COM 和 LPT) 记下 COMx | ☐ |
| 波特率一致 | 脚本 `-BaudRate` = BIOS 重定向波特率 | ☐ |

## E. 批量准备

| 检查项 | 验证方式 | 结果 |
| --- | --- | --- |
| 批次清单已填 | `config\batches.csv` 每批一行，`-DryRun` 预览命令正确 | ☐ |
| 预期清单（可选） | `expected.csv` 含 SerialNumber 列 | ☐ |
| 输出目录规划 | `-LogPath` 统一指向 `output\memory_results` | ☐ |
| 条子唯一 ID | 每根已贴标/登记，与槽位对应 | ☐ |

## F. 开工前最终冒烟

| 检查项 | 验证方式 | 结果 |
| --- | --- | --- |
| 单批试跑 1 根 | USB 方式 1 轮，报告 `Result=PASS` | ☐ |
| SOL 全自动试跑 | `ev=done ... status=pass` | ☐ |
| 报告文件生成 | `memory_results\reports\` 有 `<批次>-report.csv` | ☐ |
