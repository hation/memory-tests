# 11 要素字典与填写指南（跨文档统一参数定义）

> **作用**：全部 10 类文档模板中的占位符（`{{...}}`）在此统一定义。**同一参数在彩页、白皮书、用户手册中必须使用同一份值**，本字典是该一致性的唯一维护入口。
> **数据可信度三级标注**（沿用既有工作规则）：
> - 🔴 **已核实**：来自设计规格/测试报告/BOM/认证证书等一手资料
> - 🟡 **区间估算**：来自推算/近似（如功耗估算）
> - 🟢 **经验判断**：来自行业惯例/经验值，未经实测

## 三、数据来源优先级规则（参数取值时）

| 优先级 | 数据来源 | 说明 |
|---|---|---|
| 1 | 设计规格书 / 规格配置表 | 权威、最新 |
| 2 | 测试报告（环境/性能/适配） | 验证性数据 |
| 3 | BOM / 物料清单 | 物料级准确性 |
| 4 | 认证证书 / 官方发布 | 合规性数据 |
| 5 | 已有同类文档（旧机型） | 可参照但需核对 |

**冲突处理规则**：不同来源出现冲突时，以优先级 1~2 为准；无法判定时标注"待核实"并挂起发布。

## 四、填写指南（通用规则）

1. **数值格式统一**：尺寸（宽×高×深 mm）、温度（℃）、湿度（% RH）、频率（MHz/GHz）、容量（GB/TB）
2. **占位符命名规范**：`{{中文短名}}`，全库唯一（本字典为准）
3. **单位与量纲**：涉及功率/速率等带单位参数，数值与单位不可分开填写
4. **可选内容标记**：章节级可选用"（可选）"标注；参数级可选标注"可留空"
5. **每文档发布前**：对照对应模板的"一致性检查清单"逐项勾检
