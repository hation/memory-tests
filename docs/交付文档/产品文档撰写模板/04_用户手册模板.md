# 04 用户手册模板（使用与运维指南）

> **提炼来源**：`R2250H0/中科可控R2250H0服务器用户手册.md`、`X7850H0/中科可控X7850H0 GPU服务器用户手册.md`、`R6250H0/液冷/R6250H0L液冷服务器用户手册` 等 16 份机型用户手册（DOCX/PDF 格式）
> **适用产品**：服务器类硬件整机
> **文档性质**：面向最终用户/运维人员的完整操作指南（拆装、BIOS/BMC 配置、OS 安装）
> **对应 Schema**：`04_用户手册_template.json`
> **提炼规则依据**：用户手册章节结构在全部机型间高度一致；差异点 = ①部件拆装清单按机型增减 ②BIOS/BMC 菜单按平台不同 ③GPU/液冷机型有专属小节。

> - GPU 机型（X7850H0 等）：基本操作中增加"GPU 卡拆装步骤"；OS 安装章节支持 Windows 2022 Server（GPU 直通）；结尾增加"静放电"独立章节。
> - 液冷机型（R6250H0L 等）：散热相关章节替换为液冷部件描述，增加液冷维护注意事项。
> - 单路/入门机型（R2250H0）：无 NUMA 多路章节，BMC 菜单项相对少。

## 二、章节详解

### 1~5. 声明类章节（固定文本，逐字复用）

这些章节在全部机型用户手册中**逐字一致**，可直接复制模板内固定文本：
- **声明**：约 8 段（用途说明/免责/照片差异/无保证声明/软件声明/勘误/服务热线占位符 `{{服务热线}}`）
- **商标和版权**：占位符 `{{品牌名}}`、`{{处理器品牌}}`、`{{OS厂商}}`、`{{版权年份}}`
- **电源相关的操作说明**：接通/断开电源步骤、电源要求（含"负载不超过分支电路 80%"等固定条款）、电气接地要求（IEC 规程）
- **静电释放**：防止静电释放 10 条固定事项 + 接地方法 4 种（腕带/脚跟带/工具垫/维修工具）
- **危险警告声明**：警告组（电池/风扇/电流电击）+ 注意组（电源按钮/外盖标签/分支电路负载）+ 危险组（通电服务器操作）

> ⚠️ **安全合规规则**：以上声明类章节为**必选固定章节**，即使产品没有对应部件也**不得删除整章**（如无电池则删该条警告，保留章节框架）。

### 6. 产品简介

| 小节 | 内容 | 占位符 |
|---|---|---|
| 1.1 产品概述 | 定位 + 目标场景（交通/社区/园区/商场等） | `{{产品概述}}` |
| 1.2 产品特色 | 6~8 条特性（与白皮书"产品特点"共用） | `{{产品特色列表}}` |
| 1.3 产品规格 | 技术规格表（与彩页/白皮书共用要素字典） | `{{技术规格表}}` |
| 1.4 使用环境 | 温度/湿度/海拔等 | `{{环境规格}}` |

### 7. 产品结构及安装

- **2.1 产品结构**：结构构成图 + 部件清单表（部件名/数量/说明）。
- **2.2 产品拆装**：每个部件一个"小节对"，统一结构：
  - **拆装前准备**（工具清单 + 注意事项固定段落）
  - **拆卸步骤**（编号步骤 + 图）
  - **安装步骤**（编号步骤 + 图 + 注意点）

| 部件小节 | 占位符 | 数据来源 |
|---|---|---|
| 机盖 | `{{机盖拆装}}` | 结构设计/SOP |
| CPU | `{{CPU拆装}}` | SOP（含方向/扭力） |
| 散热器 | `{{散热器拆装}}` | SOP |
| 内存 | `{{内存拆装}}` | SOP（含安装顺序） |
| GPU卡【可选】 | `{{GPU拆装}}` | SOP |
| 网卡 | `{{网卡拆装}}` | SOP |
| RAID卡 | `{{RAID卡拆装}}` | SOP |
| 风扇 | `{{风扇拆装}}` | SOP |
| 电源 | `{{电源拆装}}` | SOP |
| 硬盘 | `{{硬盘拆装}}` | SOP |
| OCP卡【可选】 | `{{OCP拆装}}` | SOP |
| 导轨/托轨 | `{{导轨安装}}` | 结构设计 |

> **数据来源规则**：拆装步骤与《生产技术要求》《SOP 视频》保持动作一致，但面向用户需删去产线专用信息（扫码、物料号等），只保留操作动作 + 注意事项。

### 8. 组件识别

前/后视图标注表、按键与指示灯（箱耳/硬盘 LED）、主板各接口标注、DIMM 插槽编号、底板、清除 CMOS 方法、爆炸图。
占位符：`{{前视图}}` `{{后视图}}` `{{指示灯表}}` `{{主板接口图}}` `{{DIMM布局图}}` `{{CMOS清除步骤}}` `{{爆炸图}}`。
数据来源：结构设计、主板规格。

### 9. 产品配置（BIOS + BMC）

| 小节 | 内容结构 | 占位符 |
|---|---|---|
| BIOS配置 | 进入方法 + 各菜单逐项说明（每项：功能名/说明/默认值） | `{{BIOS菜单结构}}`（Main/Advanced/Chipset/Security/Boot/Save&Exit） |
| BMC配置 | 登录方法 + 各功能模块说明 | `{{BMC模块结构}}`（主界面/系统信息/远程控制/设置/日志/故障诊断/维护/注销） |

> **数据来源规则**：BIOS/BMC 菜单结构来自对应平台固件实际截图与说明，需按产品实际固件版本编写；跨机型共享同一 BMC 平台的章节可复用（如"通用自研 BMC"）。

### 10. 操作系统安装指南

| 小节 | 内容 | 占位符 |
|---|---|---|
| KVM 挂载安装 | 每个受支持 OS 一节（如 Windows 2022 Server、CentOS 8.4） | `{{OS安装步骤列表}}` |
| USB/DVD 安装 | 制作启动盘方法 + 安装步骤 | `{{U盘制作}}` `{{安装步骤}}` |
| PXE 安装【可选】 | PXE 启动配置 | `{{PXE配置}}` |

数据来源：《兼容性列表》OS 页（哪些 OS 必写）+ 研发安装验证记录。

### 11. 法规标准（固定文本）

占位符：`{{法规标准列表}}`（CCC/节能/环保/ROHS 等声明）。

### 12. 附录（缩略语表）

`{{缩略语表}}`（如 BIOS/BMC/CPLD/PCIe/RAID/DIMM/OCP……）。

## 三、参数一致性检查清单（发布前必查）

- [ ] 技术规格表与《彩页》《白皮书》一致
- [ ] 拆装步骤与《生产技术要求》《SOP 视频》动作一致（已删产线专用信息）
- [ ] BIOS/BMC 菜单与固件实际版本一致（截图复核）
- [ ] OS 安装章节覆盖《兼容性列表》中"已支持"的 OS
- [ ] 声明/商标/电源/静电/危险警告章节未删改
- [ ] 服务热线、保修政策与当前商务条款一致

- 文件名：`中科可控{{产品型号}}服务器用户手册.docx`

## 五、JSON Schema

程序化生成请加载 `04_用户手册_template.json`，核心字段：
`model_no`、`fixed_declarations{}`（声明/商标/电源/静电/警告五组固定文本，含 `service_hotline`、`brand`、`copyright_year`）、`intro{}`（overview/features/spec_table/env）、`component_views{}`、`teardown_sections[]`（部件数组：name/steps[]/notes）、`bios_menus{}`、`bmc_modules{}`、`os_install[]`、`regulations`、`appendix`。
