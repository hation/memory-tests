# 10 生产组装 SOP 视频转录模板（操作视频转文字稿）

> **提炼来源**：`海光机型生产组装SOP视频/4-R2250H0.md`（faster-whisper base 模型语音转录，含时间戳分段）
> **适用产品**：服务器类硬件整机（有产线组装操作视频的场景）
> **文档性质**：工作底稿——操作视频的转录稿，用于提炼 SOP 步骤、培训材料
> **对应 Schema**：`10_SOP视频转录_template.json`
> **提炼规则依据**：转录稿结构 = 元信息 + 分段正文；正文按视频讲解的自然步骤切分，保留时间戳便于回溯。

---

## 一、模板总览（骨架）

```
标题（{{机型}}生产组装SOP视频转录）
元信息（来源视频/转录模型/语言/时长/段落数）
转录正文（分段）
  每段格式：[时间戳] 讲解内容（步骤标题 / 操作描述 / 注意事项）
转录后加工（可选附加章节，非转录内容）
  ├─ 步骤清单提炼（步骤号/动作/注意点/对应视频时间）
  ├─ 与生产技术要求章节的映射
  └─ 待确认项清单（转录模糊处）
```

---

## 二、章节详解

### 1. 元信息（固定表）

| 字段 | 占位符 | 说明 |
|---|---|---|
| 来源视频 | `{{视频文件名}}` | 如 4-R2250H0.mp4 |
| 转录模型 | `{{模型}}` | 如 faster-whisper base |
| 转录语言 | `{{语言}}` | 如 zh |
| 时长 | `{{时长秒}}` | 如 842 秒 |
| 段落数 | `{{段落数}}` | 如 371 段 |

### 2. 转录正文

按视频讲解自然段落分段，段内格式：
- **段落小标题**（如"准备工作""更换前注意事项""安装标准化滑轨"）
- 内容行保留原讲解语句（允许口语化），关键操作步骤与数字（扭力值、型号、顺序）原样保留
- 时间戳便于定位视频片段

> **转录质量控制规则**：
> - 语音转录可能出错，关键数值（扭力、型号、数量）需人工复核
> - 模型越小时错误越多（base < small < medium < large），重要文档建议用更高级模型重转录
> - 模糊段落标注"（转录模糊，待复核）"

### 3. 转录后加工（非转录内容，标注来源）

| 章节 | 内容 | 数据来源 |
|---|---|---|
| 步骤清单提炼 | 表：步骤号/动作/注意点/视频时间点 | 由转录稿整理 |
| 与SOP映射 | 步骤 ↔ 《生产技术要求》章节 | 对照生产技术要求 |
| 待确认项清单 | 模糊处/存疑处列表 | 人工复核标记 |

---

## 三、参数一致性检查清单（发布前必查）

- [ ] 关键数值（扭力/型号/顺序）已与视频画面或《生产技术要求》人工核对
- [ ] 模糊段落已标注待复核
- [ ] 步骤顺序与视频实际顺序一致
- [ ] 用于培训材料时，与《用户手册》拆装动作一致（删产线专用信息）

## 四、版本与编号规则

- 文件名：`{{序号}}-{{产品型号}}.md`（如 `4-R2250H0.md`）
- 转录稿为工作底稿，不做受控编号；若转化为培训材料则按培训文档规则编号

## 五、JSON Schema

程序化生成请加载 `10_SOP视频转录_template.json`，核心字段：
`video_file`、`model`、`language`、`duration_sec`、`segments`（总段数）、`sections[]`（段落：title/start_time/end_time/content）、`extracted_steps[]`（步骤清单：no/action/notes/video_time）、`mapping_sop`（与生产技术要求章节映射）、`pending_verify[]`（待确认项）。
