# 09 产品动态模板（月度产品线简报）

> **提炼来源**：`海光机型动态/2026年海光服务器产品动态-10月.pptx`
> **适用产品**：整条产品线（多机型）的月度/季度更新简报
> **文档性质**：内部/渠道同步的周期性动态简报（新增适配、量产状态、停产计划）
> **对应 Schema**：`09_产品动态_template.json`
> **提炼规则依据**：结构固定为「封面全家福 → 整体动态总览 → 升级对照表/产品状态 → 部件动态 → 机型分类动态」。

---

## 一、模板总览（骨架）

```
封面（{{年份}}年{{产品线}}产品动态-{{月份}}）
产品全家福（产品全景图 + 四大卖点：性能/可靠/节能/安全）
1 产品线整体动态总览
  1.1 机型动态总览表（大类 | 机型 | 本月更新）
  1.2 部件动态总览表（分类 | 具体型号 | 引入状态）
2 产品升级对照表和产品状态
  2.1 升级对照表（产品品类 | 子类 | 机型名 | BOM号 | 停产状态）
  2.2 量产状态表（产品品类 | 子类 | 机型名 | BOM号 | 量产状态）
3 部件动态（处理器/网卡/内存/GPU/硬盘，逐类展开）
4 按机型分类的动态详情（四路/双路/单路/存储/AI服务器，逐类展开）
  每类：更新内容 / 状态 / 时间节奏
```

---

## 二、章节详解

### 1. 封面与产品全家福

| 要素 | 占位符 | 说明 |
|---|---|---|
| 标题 | `{{年份}}年{{产品线}}产品动态-{{月份}}` | 如"2026年 HG服务器产品动态-10月" |
| 产品全景图 | `{{产品全家福图}}` | 全部在售机型图集 |
| 卖点 | `{{卖点组}}` | 性能领先/稳定可靠/绿色节能/安全可信（固定四维度） |
| 场景分类 | `{{场景分类图}}` | 人工智能/通用计算/通用均衡/关键应用/存储/边缘计算/整机柜（按产品线实际） |

### 2. 整体动态总览（两表固定结构）

**机型动态总览表**：

| 大类 | 机型 | 本月更新 |
|---|---|---|
| 通用机架 | 通用双路 | `{{更新内容}}`（如"R6250H2 金泰克64R 16G完成适配"） |
| | 高端单路 | `{{更新内容}}` |
| | 四路 | `{{更新内容}}` |
| | 入门级单路 | `{{更新内容}}` |
| AI服务器 | 4U 8卡 | `{{更新内容}}` |
| | 8U OAM | `{{更新内容}}` |
| 存储 | 4U40 | `{{更新内容}}` |
| | 4U60 | `{{更新内容}}` |

**部件动态总览表**：

| 分类 | 具体型号 | 引入状态 |
|---|---|---|
| CPU | `{{型号}}` | 已完成/适配中/预计{{时间}}完成 |
| 网卡 | `{{型号}}` | 已完成 |
| 内存 | `{{型号}}` | 已完成/预计{{时间}}完成 |
| GPU | `{{型号}}` | 已完成/适配中 |
| 硬盘 | `{{型号}}` | 已完成/预计{{时间}}完成 |

### 3. 产品升级对照表和产品状态

| 表 | 列结构 | 状态取值 |
|---|---|---|
| 升级对照表 | 产品品类 | 子类 | 机型名 | BOM号 | 停产状态 | 已停产不接单 / 预停产不接新单 |
| 量产状态表 | 产品品类 | 子类 | 机型名 | BOM号 | 量产状态 | 已量产可出货 / 可核价可借测 / 可送测 / 已具备量产条件 / 可开放核价借测 |

数据来源：产品管理部门的 BOM 台账（BOM 号为唯一标识）。

### 4. 部件动态（逐类展开）

每类 = 表格：`具体型号 | 规格/平台 | 引入状态 | 说明（如"需使用新主板支持"）`。
处理器条目含平台代号（如 C86-4G/H、74xxD4）与量产状态。

### 5. 机型分类动态（逐类展开）

按产品线实际分类（四路/双路/单路/存储/AI 等），每类一节，内容格式：
- `{{机型}} {{更新内容}}`（如"X7850H0 天数BI-V150 GPU适配完成"）
- 状态标注：已完成 / 适配中 / 预计{{月份}}完成 / 已开放核价和借测 / 本月发布
- 时间节奏提示（如"预计十月底量产导入，请关注量供节奏"）

---

## 三、参数一致性检查清单（发布前必查）

- [ ] 所有"已完成"状态有对应适配/测试记录支撑
- [ ] BOM 号与 BOM 台账一致
- [ ] 停产/量产状态与最新产品状态一致（不出现互相矛盾）
- [ ] 月份标题与本期内容一致
- [ ] 全家福图不包含已停产机型（或标注停产状态）

## 四、版本与编号规则

- 文件名：`{{年份}}年{{产品线}}产品动态-{{月份}}.pptx`
- 周期：月度更新，不另行编号；页面底部标注发布日期

## 五、JSON Schema

程序化生成请加载 `09_产品动态_template.json`，核心字段：
`year`、`month`、`product_line`、`family_highlights{}`（性能/可靠/节能/安全）、`overview_models[]`、`overview_parts[]`、`lifecycle[]`（机型/BOM/停产或量产状态）、`part_updates{}`（CPU/网卡/内存/GPU/硬盘数组）、`category_updates[]`（分类/机型/内容/状态/时间节奏）。
