# 03 产品技术白皮书模板（技术选型资料）

> **提炼来源**：`R2250H0/中科可控R2250H0服务器产品技术白皮书.md`（及文件夹内共 8 份机型白皮书，DOCX 格式）
> **适用产品**：服务器类硬件整机
> **文档性质**：面向技术选型/采购评估的完整技术资料（规格、架构、兼容性、管理、认证）
> **对应 Schema**：`03_技术白皮书_template.json`
> **提炼规则依据**：白皮书章节结构在全部机型间几乎逐字一致，差异仅在参数值；是 10 类文档中"骨架最稳定"的一类。

---

## 一、模板总览（骨架）


## 二、章节详解

### 1. 声明（固定文本，可直接套用）

> 本手册（白皮书）所提供信息仅供参考。中科可控公司/本公司对本文档内容不提供任何明示或默示的保证……实际规格与配置以出货为准。如发现文档与实物不符，恕不另行通知。
> （完整固定文本见用户手册声明段，白皮书声明为精简版）

### 2~4. 目录 / 插图目录 / 表格目录

自动生成（Word 域代码）。占位符：`{{目录}}` `{{插图目录}}` `{{表格目录}}`。

### 5. 产品概述（1~2 段固定句式）

> {{产品型号}}服务器是一款基于{{处理器系列}}的{{定位词}}，面向{{目标场景}}，支持{{关键特性}}。
> 数据来源：产品定位文档、设计规格。

### 6. 产品特点（列表 6~8 条）

每条 = **加粗特性名 + 描述**。典型条目（从原文提炼）：
- 超强性能：搭载{{处理器系列}}处理器，支持{{核/线程数}}……
- 全新内存架构：支持{{内存类型}}，最高{{容量}}，速率{{频率}}……
- 海量存储：支持{{盘位数}}硬盘，支持{{RAID级别}}……
- 灵活扩展：{{PCIe槽位数}}个 PCIe {{代数}}插槽……
- 高可靠性：支持{{电源冗余}}冗余电源、{{风扇冗余}}风扇……
- 安全可信：支持{{安全模块}}……
- 高环境适应性：工作温度{{温度范围}}……

### 7. 产品技术优势（4 个左右优势段）

| 优势 | 固定句式 | 数据来源 |
|---|---|---|
| 可扩展性 | "高扩展能力——提供最大{{N}}个PCIe{{代数}}插槽与{{N}}个硬盘位" | 设计规格 |
| 性价比 | "高性价比——{{处理器}}多线程高性能，构建高效低成本计算平台" | 产品定位 |
| 环境适应性 | "高环境适应性——{{尺寸}}可部署于{{N}}mm机柜" | 结构设计 |
| 安全可信 | "安全可信——支持{{安全模块}}，保护数据安全" | 安全特性 |
|（AI机型）算力领先 | "原生液冷方案、高算力密度" | 散热/算力规格 |

### 8. 物理结构

产品外形图 + 尺寸图（占位符：`{{外形图}}` `{{尺寸图}}`）。数据来源：结构设计图纸。

### 9. 逻辑架构

系统拓扑概述段 + `{{逻辑框图}}`（主板各子系统连接图）。数据来源：主板原理图。

### 10. 硬件描述（10 个小节，逐节详解）

| 小节 | 固定内容 | 占位符 | 数据来源 |
|---|---|---|---|
| 6.1 前面板 | 面板图 + 部件标注表 | `{{前面板图}}` `{{前面板标注表}}` | 结构设计 |
| 6.2 后面板 | 同上 | `{{后面板图}}` `{{后面板标注表}}` | 结构设计 |

| 6.4 内存 | 插槽数/类型/容量/频率/通道 | `{{内存规格}}` | 设计规格 |
| 6.5 存储 | 盘位/背板/控制器/RAID | `{{存储规格}}` | 背板指南 |
| 6.6 IO扩展 | 插槽数量/类型/通道分配 | `{{PCIe规格}}` | 设计规格 |
| 6.7 网络 | 板载网口 + 扩展网卡支持 | `{{网络规格}}` | 设计规格 |

| 6.10 主板 | 主板图 + 关键特性 | `{{主板图}}` `{{主板特性}}` | 主板规格 |

- **技术规格表**：与彩页参数表共用要素字典，字段一致（处理器/内存/存储/网络/接口/电源/尺寸/重量等）。

## 三、参数一致性检查清单（发布前必查）

- [ ] 技术规格表与《产品彩页》《用户手册》全部一致
- [ ] CPU/内存/硬盘/网卡等兼容列表与最新《兼容性列表》同步
- [ ] 环境规格数值来自最新测试报告
- [ ] 框图与主板实际版本一致（Rev 号标注）
- [ ] BMC 功能描述与固件实际版本一致

## 四、版本与编号规则

- 文件名：`中科可控{{产品型号}}服务器产品技术白皮书.docx`
- 编号：`QBD-CB-TWB-YYYYMMDD+序号`（如 QBD-CB-TWB-202506230001）
- 白皮书由技术文档团队维护，升版走 ChangeList（在文档属性/变更记录页登记）

## 五、JSON Schema

程序化生成请加载 `03_技术白皮书_template.json`，核心字段：
`model_no`、`overview`、`features[]`、`advantages[]`、`physical_structure`（图）、`logical_arch`（图）、`hardware_sections{}`（前面板/后面板/处理器/内存/存储/IO/网络/电源/散热/主板）、`spec_tech{}`、`spec_env{}`、`compatibility{}`（内存/存储/RAID/网卡/电源/OS）、`management`、`certifications[]`、`support`。
