# 07 兼容性列表模板（部件/系统兼容清单）

> **提炼来源**：`兼容性列表/QBD-CB-SHL-202608040051 中科可控R6250H0服务器兼容性列表V2.0.md`（及文件夹内共 5 份机型兼容性列表，XLSX 格式）
> **适用产品**：服务器类硬件整机（有适配/认证流程的机型）
> **文档性质**：权威兼容清单（部件 AVL + OS 矩阵），供选型、投标、生产、售后统一引用
> **对应 Schema**：`07_兼容性列表_template.json`
> **提炼规则依据**：三大部分固定（Change List → Device AVL → OS 矩阵）；AVL 分类与列结构跨机型一致。

---

## 一、模板总览（骨架）

```
封面/标题（{{产品型号}}服务器兼容性列表 + 文档编号 + 版本）
Change List（作者/日期/版本/修改内容）
1 Device AVL（部件兼容清单）
  按分类分表：主板 / CPU / 内存 / HDD / SSD / RAID控制器 / 网卡 / GPU / 电源 / 其他
2 OS Compatiblity List（操作系统兼容矩阵）
  Category | OS Name | （存储控制器/RAID卡列）兼容矩阵，P=支持
```

---

## 二、章节详解

### 1. Change List（固定表）

| 列 | 填写说明 |
|---|---|
| Author | 适配测试负责人 |
| Date | 日期 |
| Version | 版本号 |
| Changes | 本次修改内容（新增/移除部件） |

### 2. Device AVL（固定列结构）

每个分类一张表，固定列（从原文提炼）：

| 列 | 填写说明 | 示例 |
|---|---|---|
| Using Rules | 使用规则/备注（如适用机型条件） | 支持{{机型}} |
| PN | 物料号 | {{PN}} |
| Description | 物料描述 | {{描述}} |
| 型号 | 具体型号 | {{型号}} |
| 主板兼容性 | 与主板/平台的兼容结论 | OK / 限制条件 |
| 备注 | 补充说明（适配状态/验证结果） | 适配完成/适配中 |

**AVL 分类清单**（全部机型通用）：
`主板` `CPU` `内存` `HDD` `SSD` `RAID控制器` `网卡` `GPU` `电源` `其他`
（GPU 分类仅 GPU/AI 机型有；边缘机型可增加"摄像头/采集卡"等自定义分类）

### 3. OS Compatiblity List（固定矩阵结构）

```
Category | OS Name | {控制器列1} | {控制器列2} | ...
Centos 8 | centos-8.5 | P | P | ...
Redhat   | Rhel 9.0    | P | P | ...
麒麟软件   | Kylin V10 SP3 2403 | P | ...
```

- **行**：OS 分类 + OS 名称（海外 OS + 国产 OS 全覆盖：CentOS/RedHat/Ubuntu/麒麟/统信/麒麟信安/凝思/方德/openEuler/Anolis/红旗/移动BCLinux/联通culinux 等）
- **列**：存储控制器/RAID 卡型号（如 AHCI(SATA)、AHCI(M.2)、NVME、BCM 9560-8i、LD 3260-10i 等）
- **值**：`P` = 支持（Pass），空 = 未测/不支持
- **数据来源**：适配测试报告（每条 P 必须有测试记录支撑）

---

## 三、参数一致性检查清单（发布前必查）

- [ ] 每条"P"有对应适配测试报告（可追溯）
- [ ] OS 列表与《用户手册》OS 安装章节覆盖一致
- [ ] AVL 中的物料均来自当前在售 BOM
- [ ] Change List 与版本号一致
- [ ] GPU 分类与产品动态"部件动态"适配状态一致（适配中/已完成）

## 四、版本与编号规则

- 文件名：`{{产品型号}}服务器兼容性列表V{{版本}}.xlsx`
- 编号：`QBD-CB-SHL-YYYYMMDD+序号`
- 版本管理：每次新增/移除适配部件必须升版并在 Change List 登记

## 五、JSON Schema

程序化生成请加载 `07_兼容性列表_template.json`，核心字段：
`model_no`、`doc_no`、`version`、`change_list[]`（author/date/version/changes）、`avl{}`（分类→部件数组：using_rules/pn/description/model/mb_compat/notes）、`os_matrix{}`（os_categories[]/controllers[]/entries[{category,name,values{}}]）。
