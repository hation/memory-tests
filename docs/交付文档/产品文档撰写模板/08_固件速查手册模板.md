# 08 固件速查手册模板（固件版本/问题定位）

> **提炼来源**：`固件速查手册/固件速查手册.md`（含固件类型总览 + 机型×固件清单）
> **适用产品**：服务器类硬件整机（有 BIOS/BMC/CPLD 等固件的机型）
> **文档性质**：内部/售后工具书——哪台机器用哪个固件、固件解决哪类问题
> **对应 Schema**：`08_固件速查手册_template.json`
> **提炼规则依据**：结构固定为「固件类型总览 → 机型×固件清单 → 故障速查 → 命名规则 → 升级注意」；固件"解决哪类问题"的规律跨机型一致。

---

## 一、模板总览（骨架）

```
1 固件类型总览
  1.1 四大固件类型（BIOS/BMC/CPLD/PDB·SCM·风扇板CPLD）
      - 每类：负责什么 / 解决哪类问题 / 升级影响
  1.2 CPLD 细分类型（主板CPLD/PDB CPLD/SCM小板CPLD/风扇板CPLD）
2 机型×固件清单（每机型一节）
  固件类型 | 固件文件名 | 版本 | 芯片方案 | 兼容机型
  ├─ BIOS
  ├─ BMC（国产芯片 / 国际芯片分别列）
  ├─ 主板CPLD
  ├─ PDB CPLD / SCM小板CPLD / 风扇板CPLD（按机型实际有）
3 故障症状→固件速查表（可选）
  症状（无法开机/内存报错/远程管理不可用/传感器误告警/CPU型号识别错误/安全漏洞）→ 建议固件
4 固件命名规则解读
5 固件升级注意事项
6 重要说明（固件不跨整机厂通用等）
```

---

## 二、章节详解

### 1. 固件类型总览

| 固件类型 | 负责内容（固定句式） | 解决的典型问题 | 升级影响 |
|---|---|---|---|
| BIOS | 硬件初始化、CPU/内存/PCIe配置、启动流程 | 新CPU/内存/GPU/网卡兼容、内存压测报错、开机挂起、安全漏洞（CVE）、CPU型号识别错误 | 重启生效 |
| BMC | 带外远程管理（Web控制台/电源控制/硬件监控/远程固件更新） | 远程管理不可用/不稳定、传感器误告警、SEL日志刷屏、安全漏洞、CPU型号显示错误 | 需重启BMC |
| CPLD | 上下电时序控制（主板/PDB/SCM/风扇板各自职责） | 上电时序异常、风扇转速异常 | 需下电升级 |
| PDB/SCM/风扇板CPLD | 电源分配/小板控制（BMC·BIOS flash）/风扇转速控制 | 对应模块功能异常 | 需下电升级 |

> **关键规律（跨机型通用）**："固件解决哪类问题"的规律一致；即使不同整机厂固件不通用，问题定位思路可复用。

### 2. 机型×固件清单（核心数据表）

每机型一节，固定表结构：

| 固件类型 | 固件文件名 | 版本 | 芯片方案 | 兼容机型 |
|---|---|---|---|---|
| BIOS | `{{BIOS文件名}}` | `{{版本}}` | — | `{{兼容机型}}` |
| BMC（国产芯片） | `{{BMC国产文件名}}` | `{{版本}}` | ZX1000 | `{{兼容机型}}` |
| BMC（国际芯片） | `{{BMC国际文件名}}` | `{{版本}}` | AST2600 | `{{兼容机型}}` |
| 主板CPLD | `{{主板CPLD文件名}}` | `{{版本}}` | — | `{{兼容机型}}` |
| SCM小板CPLD | `{{SCM CPLD文件名}}` | `{{版本}}` | ZX1000 / AST2600 | `{{兼容机型}}`（常跨型号通用） |
| 风扇板CPLD | `{{风扇板CPLD文件名}}` | `{{版本}}` | — | `{{兼容机型}}` |

> **通用性标注规则**：同一固件兼容多个机型的要显式标注（如"兼容R5250H0/R5250H1"），这是复用固件的关键信息。

### 3. 故障症状→固件速查表（可选但有价值）

| 症状 | 定位方向 | 建议固件 |
|---|---|---|
| 开机挂起/无法点亮 | BIOS | 升级最新 BIOS |
| 内存压测报错 | BIOS | 升级 BIOS（内存兼容修复） |
| 远程管理界面打不开 | BMC | 升级 BMC |
| 传感器误告警/SEL刷屏 | BMC | 升级 BMC |
| 风扇转速异常 | 风扇板CPLD | 升级风扇板 CPLD |
| CPU 型号识别错误 | BIOS / BMC | 分别升级 |

数据来源：固件发布说明（Release Notes）中的修复记录。

### 4. 固件命名规则解读（固定句式模板）

示例解读（从原文提炼）：
- `F00_*BIOS*` → BIOS 固件；`F10_*BMC*` → BMC 固件
- `*CPLD*` → CPLD 固件
- 字段含：平台代号（如 Dharma/ShangHai(Gx)/ChengDu(Hx)）、机型（如 R2250H0）、版本号
- 解读模板：`{{前缀}}` 表示固件类型，`{{代号}}` 表示平台，`{{机型字段}}` 表示适用机型，`V{{版本}}` 为版本号

### 5. 固件升级注意事项（固定要点）

- 升级前备份当前固件版本信息（记录 BIOS/BMC 版本号）
- BIOS 升级后需恢复默认设置或按需重新配置
- BMC 升级后需重启 BMC 或重新登录
- CPLD 升级需整机下电
- 升级过程禁止断电
- 跨大版本升级注意兼容路径（如有）

### 6. 重要说明（固定文本）

> 本目录固件为{{整机厂名}}产品线专用，与{{其他整机厂}}固件**不通用**；但"固件解决哪类问题"的规律一致，可参考定位思路。正式升级请以厂商发布渠道为准。

## 三、参数一致性检查清单（发布前必查）

- [ ] 每机型固件清单与厂商发布渠道最新版本一致
- [ ] 兼容机型标注与《兼容性列表》在售状态一致
- [ ] 故障速查表的建议固件有 Release Notes 支撑
- [ ] 命名规则解读与最新固件文件名匹配
- [ ] 已注明固件不跨整机厂通用

## 四、版本与编号规则

- 文件名：`固件速查手册.md`（按产品线维护，不分机型独立编号）
- 更新频率：随厂商固件发布更新；每次更新登记在文末"更新记录"

## 五、JSON Schema

程序化生成请加载 `08_固件速查手册_template.json`，核心字段：
`firmware_types[]`（type/role/problems[]/impact）、`cpld_subtypes[]`、`models{}`（机型→固件数组：type/file/version/chip/compat_models）、`troubleshooting[]`（symptom/direction/suggested_fw）、`naming_rule`、`upgrade_notes[]`、`important_notes[]`。
