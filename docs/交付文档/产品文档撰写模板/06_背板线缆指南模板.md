# 06 硬盘背板及相关线缆连接指南模板（接线方案）

> **提炼来源**：`R2250H0/R2250H0服务器硬盘背板及相关线缆连接指南V1.4.md`（及文件夹内共 12 份机型背板连接指南，PPT 格式）
> **适用产品**：服务器类硬件整机（有可配置盘位/背板的机型）
> **文档性质**：面向生产/售后技术支持的"某一类硬件"接线操作方案（供电线/信号线/数据线）
> **对应 Schema**：`06_背板线缆指南_template.json`
> **提炼规则依据**：结构固定为「封面→变更记录→线缆列表→安装说明→按盘位配置逐页展开」；每页按"供电/信号/数据"三类线分组，标注线缆编号与接口号。

---

## 一、模板总览（骨架）

```
封面（标题：{{产品型号}}硬盘背板及相关线缆连接指南 + 版本）
ChangeList（版本/修改内容/修改人/修改时间）
线缆列表（线缆类属/对应背板/物料号/物料描述）
线缆安装相关说明（注意事项 3~5 条）
按"盘位配置"分节，每节结构：
  配置概述（盘位数 + 背板型号 + 配置说明，如"前置2盘做板载RAID"）
  ├─ 供电线（线缆编号/名称/接口连接关系 + 图）
  ├─ 信号线（同上）
  └─ 数据线（同上）
  （附：检测表备注/RAID配置提示）
```

---

## 二、章节详解

### 1. 封面与 ChangeList

| 要素 | 占位符 | 说明 |
|---|---|---|
| 标题 | `{{产品型号}}硬盘背板及相关线缆连接指南` | 固定句式 |
| 版本 | `{{版本号}}` | 如 V1.4 |
| ChangeList 表 | `{{变更记录}}` | 表：版本/修改内容/修改人/修改时间 |

### 2. 线缆列表（全文档索引表）

固定表结构：

| 列 | 填写说明 | 示例 |
|---|---|---|
| 线缆类属 | 供电线/信号线/数据线 | 数据线 |
| 对应背板 | 背板型号 | BD12G04-SAS-U1 C01硬盘背板 |
| 物料号 | BOM 料号 | {{物料号}} |
| 物料描述 | 名称+规格 | 42cm SlimSAS X4转SlimSAS X4 S3数据线缆 |

### 3. 线缆安装相关说明（注意事项区）

固定句式要点（从原文提炼）：
- 拆装线缆前需对服务器下电
- 线缆插拔对准接口方向，禁止斜插/暴力插拔
- 线缆走线需按卡扣/线槽固定，防止压伤
- 拔插信号线时注意防静电要求

### 4. 按盘位配置分节（核心内容）

**每页固定结构**：

```
【配置概述】
前置 {{N}}U{{M}} SATA背板×{{N}}：接{{硬盘类型}}   ← 盘位与背板型号
后置 {{N}}U{{M}} SATA背板×{{N}}：接{{硬盘类型}}
配置说明：{{如"前置2盘做板载RAID"}}

【供电线】线缆编号{{①②③}} {{线缆名称}}
  前置：电源背板{{接口号}} 通过{{线缆编号}}连接到前置背板的{{接口号}}；
  后置：主板{{接口号}} 通过{{线缆编号}}连接到后置背板的{{接口号}}；
【信号线】线缆编号{{①②③}} {{线缆名称}}
  前置：主板{{接口号}} 通过{{线缆编号}}的{{端口名}}连接前置背板的{{接口号}}；
【数据线】线缆编号{{①②③}} {{线缆名称}}
  主板{{接口号}} 通过{{线缆编号}}连接到{{背板}}{{接口号}}；
（每页附连接示意图 + "检测表备注/RAID 根据此页插线"提示）
```

**盘位配置节命名**：按盘位数分节（如"4 盘位""6 盘位""12 盘位"），覆盖全部可选配置。

## 四、版本与编号规则

- 文件名：`{{产品型号}}服务器硬盘背板及相关线缆连接指南V{{版本}}.pptx`

- ChangeList 为唯一变更登记入口

## 五、JSON Schema

程序化生成请加载 `06_背板线缆指南_template.json`，核心字段：
`model_no`、`version`、`change_list[]`、`cable_list[]`（type/backplane/part_no/description）、`notes[]`、`configs[]`（盘位配置数组：name/backplanes[]/desc/cables[{type,no,name,connections[{from,to}]}]）。
