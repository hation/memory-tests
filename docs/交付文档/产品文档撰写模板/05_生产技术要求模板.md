# 05 生产技术要求模板（生产装配作业规范 SOP）

> **提炼来源**：`R2250H0/R2250H0服务器生产技术要求V1.9.xlsx`（及文件夹内共 11 份机型生产技术要求，XLSX 格式）
> **适用产品**：服务器类硬件整机（产线装配）
> **文档性质**：面向生产制造部门的分步装配作业规范，17 个标准章节
> **对应 Schema**：`05_生产技术要求_template.json`
> **提炼规则依据**：章节序号与标题在全部机型间基本固定（1~17）；每个工序页使用标准表头模板；机型差异体现在物料号、扭力值、工序步骤描述。

## 二、章节详解

### A~E 部（封面/说明/修改记录/目录/螺钉表）

| 部 | 内容 | 占位符 |
|---|---|---|
| A 封面 | 文档编号、名称、版本、受控状态 | `{{文档编号}}` `{{版本}}` |
| B 相关说明 | 下发范围、拟制/审核/批准人、特别说明（通用条款 4~6 条） | `{{下发范围}}` `{{拟制人}}` `{{审核人}}` `{{批准人}}` |
| C 修改记录 | 表：序号/修改内容/修改工艺/文件版次/修改日期/修改人 | `{{修改记录表}}` |
| D 目录 | 17 章标题 | 固定 |
| E 螺钉使用说明 | 表：料号/物料描述/功能/扭力 | `{{螺钉清单}}`（来源：BOM + 结构设计） |

### 1~16 工序章（核心结构）

每个工序章 = **一张（或多张）工序表**，工序表固定表头：

| 表头字段 | 填写说明 | 数据来源 |
|---|---|---|
| 机型 | 适用机型（如 R2250H0） | 固定 |
| 工序名称 | 如"安装内存" | 固定 |
| 工序编号 | 章号+序号 | 固定 |
| 工序目的 | 该工序要达成的目标 | 工艺部门 |
| 装入件及辅助材料 | 物料清单（料号+名称） | BOM |
| 设备及工具 | 如防静电手套、T20螺丝刀 | 工具清单 |
| 静电防护要求 | 佩戴防静电环/手套等 | 工艺部门 |
| HSF要求 | 环保物料标识要求（固定句式） | 工艺部门 |
| 工艺规则 | 该工序总规则 | 工艺部门 |
| 工艺过程步骤 | 编号步骤 + 操作描述 + 注意项 | 工艺部门（从试产记录） |
| 变更理由及内容 / 更改 / 批准 / 变更日期 | 变更跟踪区 | 升版时填 |

**工艺过程步骤的写法规范**（从原文提炼）：
1. 每步 = 动作 + 对象 + 关键参数（扭力/方向/顺序）
2. 关键"注意"事项单列（如：三角标识对齐、锁紧顺序 1-2-3-4、扭力 6~8kgf·cm）
3. 涉及物料标注料号（如"散热器（3003818）"）
4. 步骤中嵌入检查点（扫码、目检项）

### 17-关键过程和特殊过程识别（固定结构）

| 类别 | 内容 |
|---|---|
| 关键过程 | 表：工序/关键特性/控制方法（如扭力、压接） |
| 特殊过程 | 表：工序/特殊特性/参数范围（如点胶、焊接） |

数据来源：质量部门关键特性清单（FMEA）。

## 三、参数一致性检查清单（发布前必查）

- [ ] 工序步骤与《用户手册》拆装动作一致（用户手册删去产线信息后的反向校验）
- [ ] 物料号与当前 BOM 一致（每次 BOM 变更必须同步）
- [ ] 扭力值有工艺验证记录支撑
- [ ] HSF 要求符合最新环保法规
- [ ] 修改记录表与历次升版一致

## 四、版本与编号规则

- 文件名：`{{产品型号}}服务器生产技术要求V{{版本号}}.xlsx`
- 编号：`QBD-CB-SOP-YYYYMMDD+序号`
- 版本管理：C 部修改记录表是唯一升版入口；升版需"拟制/审核/批准"三签

## 五、JSON Schema

程序化生成请加载 `05_生产技术要求_template.json`，核心字段：
`doc_no`、`version`、`approvers{}`（拟制/审核/批准）、`change_log[]`、`screw_list[]`（料号/描述/扭力）、`processes[]`（工序数组：name/no/purpose/materials[]/tools[]/esd_req/hsf_req/rules/steps[{no,action,notes}]）、`key_special_processes{}`。
