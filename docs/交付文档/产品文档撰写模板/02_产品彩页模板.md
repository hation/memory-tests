# 02 产品彩页模板（一页纸宣传页）

> **提炼来源**：`R2250H0/中科可控R2250H0服务器产品彩页.pdf`（及文件夹内共 11 份机型彩页，均为 PDF 一页纸宣传页）
> **适用产品**：服务器类硬件整机
> **文档性质**：对外市场物料（一页纸：卖点 + 技术参数），用于官网、展会、销售拜访
> **对应 Schema**：`02_产品彩页_template.json`
> **提炼规则依据**：彩页结构固定为「定位标题 → 卖点区 → 参数表区 → 免责声明」；参数表列项在全部机型彩页中高度一致。

---

## 一、模板总览（骨架）

```
┌────────────────────────────────────────────┐
│ 产品型号（大标题）+ 一句话定位（副标题）        │
│  [品牌 LOGO]   [产品外观图]                  │
├────────────────────────────────────────────┤
│ 核心卖点区（3~5 个卖点，每个：图标+短语+一句说明）│
├────────────────────────────────────────────┤
│ 技术参数表（2~3 列：参数名称 / 规格介绍）       │
│  处理器 / 内存 / 网络 / 存储 / 扩展槽 /        │
│  外部接口 / 电源 / 散热 / 管理 / 机箱尺寸 /    │
│  工作温度 / 操作系统 / 认证 等                 │
├────────────────────────────────────────────┤
│ 免责声明（"规格可能变更，恕不另行通知"）        │
└────────────────────────────────────────────┘
```

---

## 二、章节详解

### 1. 标题区

| 要素 | 占位符 | 填写说明 | 数据来源 |
|---|---|---|---|
| 产品型号 | `{{产品型号}}` | 如 R2250H0 | 产品命名规范 |
| 一句话定位 | `{{一句话定位}}` | 如"基于海光3400系列处理器的入门2U单路机架式服务器" | 产品定位 |
| 外观图 | `{{产品外观图}}` | 正面45°渲染图 | 工业设计/渲染图库 |
| 品牌信息 | `{{品牌}}` | 中科可控 / 自有品牌 | 品牌规范 |

### 2. 核心卖点区（3~5 个）

每个卖点 = **短语标题 + 一句支撑**（参考《产品介绍模板》卖点维度，两文档共用同一组卖点文案，保持一致）。

### 3. 技术参数表（彩页核心，列项固定）

| 参数组 | 占位符 | 填写说明 | 数据来源 |
|---|---|---|---|
| 处理器 | `{{处理器规格}}` | 系列/最高核数，如"最大支持1颗HYGON 3400系列" | 设计规格 |
| 内存 | `{{内存规格}}` | 插槽数/类型/容量/频率/ECC | 设计规格 |
| 网络 | `{{网络规格}}` | 板载网口数量速率 + 可选网卡 | 设计规格 |
| 存储 | `{{存储规格}}` | 盘位数/硬盘类型/RAID能力 | 设计规格 |
| 扩展槽 | `{{扩展槽规格}}` | PCIe 槽位数量/速率 | 设计规格 |
| 外部接口 | `{{外部接口}}` | VGA/USB/管理口/Debug/COM 数量与位置 | 设计规格 |
| 机箱尺寸 | `{{机箱尺寸}}` | 宽×高×深（mm） | 结构设计 |
| 电源 | `{{电源规格}}` | 功率档位/冗余方式/标准（如 CRPS） | 电源 BOM |
| 散热系统 | `{{散热规格}}` | 风扇数量/冗余/液冷选项 | 散热设计 |
| 系统管理 | `{{管理规格}}` | BMC 能力（IPMI/Redfish/远程控制） | BMC 规格 |
| 显示系统 | `{{显示规格}}` | 集成显示控制器等 | 设计规格 |
| 工作温度 | `{{温度规格}}` | 工作/存储温度范围 | 环境测试报告 |
| 操作系统 | `{{OS支持}}` | 已适配 OS 列表摘要 | 兼容性列表 |
| 认证 | `{{认证}}` | CCC/节能/环保等 | 认证证书 |

> **一致性规则**：本表与《技术白皮书》"系统规格"、《用户手册》"产品规格"使用**同一份参数值**，由要素字典统一维护。

### 4. 免责声明（固定文本）

> 注：可控公司/本公司保留在不通知用户的情况下更改配置的权力。产品实际规格与配置以出货为准。

---

## 三、参数一致性检查清单（发布前必查）

- [ ] 卖点文案与《产品介绍》一致
- [ ] 参数表全部数值与《技术白皮书》规格表一致
- [ ] 外观图为最新版本（与实物/渲染一致）
- [ ] OS 列表与最新《兼容性列表》一致
- [ ] 认证信息有证书支撑

## 四、版本与编号规则

- 文件名：`中科可控{{产品型号}}服务器产品彩页.pdf`（V1.0 起，变更时升版）
- 变更记录维护在彩页源文件（AI 源文件）中

## 五、JSON Schema

程序化生成请加载 `02_产品彩页_template.json`，核心字段：
`model_no`、`positioning`、`brand`、`appearance_image`、`selling_points[]`、`spec_items[]`（参数组数组：group/name/value）、`disclaimer`。
