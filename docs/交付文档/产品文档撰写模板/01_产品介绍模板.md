# 01 产品介绍模板（产品定位演示稿）

> **提炼来源**：`R8450H0/中科可控R8450H0服务器产品介绍.md`、`X7950H0/中科可控X7950H0服务器产品介绍.md`、`X7850H0/中科可控X7850H0服务器产品介绍.md`、`R2250H0/中科可控R2250H0服务器产品介绍.md` 等 8 份产品介绍（PPT 格式）
> **适用产品**：服务器类硬件整机
> **文档性质**：对外营销演示 PPT（讲"为什么要买、产品是什么、怎么做的"）
> **对应 Schema**：`01_产品介绍_template.json`
> **提炼规则依据**：产品介绍按"产品定位→规格→硬件详解"三段展开；AI/GPU 机型在开头插入市场背景；通用机型跳过市场部分直接讲产品。

---

## 一、模板总览（骨架）

```
封面（产品名 + 一句话定位 + 部门/作者/日期）
├─（可选）市场背景引入【AI/GPU类机型必选】
│   ├─ 宏观市场趋势（需求增长数据）
│   ├─ 市场需求发展趋势（场景/行业）
│   └─ 本产品线系列全览（产品家族定位图）
├─ 产品定位与目标场景
├─ 核心卖点（3~5 个，带图标/关键词）
├─ 产品特色详解
│   ├─ 产品概述（一句话定位 + 特性要点列表）
│   ├─ CPU/核心规格参数（或 SPEC 性能对比）
│   ├─ RAS 特性（可靠性/可用性/可服务性）
│   └─（可选）多重变体方案（不同配置形态）
├─ 产品规格详解
│   ├─ 机型规格参数表（完整技术参数）
│   ├─ 前视图详解（外观 + 标注）
│   ├─ 后视图详解（外观 + 标注 + 可选方案）
│   ├─（可选）硬盘对应关系说明
│   ├─ 开箱图
│   └─ 主推配置（标准配置单）
├─ 产品硬件详解
│   ├─ 产品架构图（整机层级）
│   ├─ 主板架构 TOPO + 详解
│   ├─（可选）NUMA 架构详解
│   ├─（可选）主板 I2C TOPO
│   ├─ 供电系统
│   ├─ PCIe 子系统
│   ├─ 存储系统
│   ├─ 散热系统
│   └─ 计算系统
└─（可选）附录：FW 升级方法等
```

## 二、章节详解

### 1. 封面

| 要素 | 占位符 | 填写说明 | 数据来源 |
|---|---|---|---|
| 产品型号 | `{{产品型号}}` | 如 R6250H0、X7950H0 | 产品命名规范 |
| 一句话定位 | `{{一句话定位}}` | 如"基于海光3400系列的入门2U单路机架式服务器" | 产品定位文档 |
| 出品部门 | `{{部门}}` | 如"海光服务器产品事业部" | 组织信息 |
| 制作人/日期 | `{{作者}} {{日期}}` | 演示稿署名 | 实际填写 |

### 2. 市场背景引入（可选章节，AI/GPU 机型必选）

| 要素 | 占位符 | 填写说明 | 数据来源 |
|---|---|---|---|
| 市场趋势数据 | `{{市场趋势数据}}` | 如"AI服务器需求持续增长"及具体数字 | 市场研报（IDC/咨询机构） |
| 需求趋势要点 | `{{需求趋势要点}}` | 3~5 条场景/行业需求 | 市场研报 |
| 产品系列定位图 | `{{产品系列图}}` | 本系列各机型覆盖场景的全景图 | 产品线规划 |

> **可选性规则**：通用计算机型可省略；AI/GPU/存储等有明确市场叙事的机型建议保留，作为"为什么做这个产品"的铺垫。

### 3. 核心卖点（3~5 个）

每个卖点按"**关键词短语 + 一句话支撑**"呈现，典型卖点维度（从原文提炼）：

| 卖点维度 | 固定句式示例 | 参数来源 |
|---|---|---|
| 性能 | "超强性能——搭载高效处理器与全新内存架构，最高支持X核Y线程" | 处理器规格 |
| 性价比 | "高性价比——C86架构多线程高性能，构建高效低成本计算平台" | 产品定位 |
| 环境适应性 | "高环境适应性——机箱深度小，可部署于600mm机柜，宽工作温度" | 结构尺寸/环境规格 |
| 可靠性 | "稳定可靠——百项RAS特性、增强系统可靠性" | RAS特性清单 |
| 节能 | "绿色节能——节能设计、原生液冷方案" | 电源/散热规格 |
| 安全 | "安全可信——硬件加解密、安全加密虚拟化技术" | 安全特性 |

### 4. 产品特色详解

- **产品概述**：固定句式"{{产品型号}}服务器是基于{{处理器系列}}的一款{{定位词}}，具备{{卖点词组}}等特点"，后接特性要点列表（6~8 条，每条含关键参数）。
- **性能对比**（可选）：SPEC CPU 2017 分数、与上一代/竞品对比图。数据来源：官方测试报告，标注"未核实勿用于投标"。
- **RAS 特性**：可靠性/可用性/可服务性特性清单。数据来源：设计规格、BIOS 特性文档。
- **多重变体方案**（可选）：风冷/液冷、盘位数变体、主板变体（通用主板/国产BMC主板）等。数据来源：产品配置表。

### 5. 产品规格详解

- **机型规格参数表**：见《要素字典》统一参数项，与彩页、白皮书、用户手册共用同一份参数值（一致性检查点）。
- **前/后视图详解**：外观图 + 数字标注 + 标注说明表（1.机箱上盖 2.…）。
- **硬盘对应关系说明**（可选）：盘位编号与背板、控制器对应关系。
- **主推配置**：标准配置单（CPU/内存/硬盘/网卡/电源组合）。数据来源：产品配置部门。

### 6. 产品硬件详解

| 小节 | 内容 | 数据来源 |
|---|---|---|
| 产品架构 | 整机层级图（计算/存储/网络/管理） | 架构设计文档 |
| 主板架构 TOPO | 主板各子系统连接图 + 详解 | 主板原理图 |
| NUMA 架构 |（多路机型）内存与CPU拓扑 | 主板设计规格 |
| I2C TOPO |（可选）管理总线拓扑 | 主板原理图 |
| 供电系统 | 电源层级、VR、功率预算 | 电源设计规格 |
| PCIe 子系统 | 插槽分布、通道分配、信号切换 | 主板设计规格 |
| 存储系统 | 盘位、背板、控制器连接 | 背板连接指南 |
| 散热系统 | 风道、风扇模组、散热规格 | 散热设计规格 |
| 计算系统 | CPU 配置、算力指标 | 处理器规格 |

### 7. 附录（可选）

FW 升级方法、驱动获取渠道等。数据来源：研发固件发布说明。

## 三、参数一致性检查清单（发布前必查）

- [ ] 规格参数表中所有数值与《技术白皮书》《用户手册》《彩页》一致（型号/容量/频率/盘位/尺寸/温度）
- [ ] 卖点中的量化数据（核数/线程/频率）与规格表一致
- [ ] 对比图数据有测试报告依据，标注了数据来源与测试条件
- [ ] 产品系列图与最新产品线状态一致（不出现已停产机型为主推）
- [ ] 主推配置与《兼容性列表》中的在售物料一致

## 四、版本与编号规则

- 文件名：`中科可控{{产品型号}}服务器产品介绍.pptx`
- 演示页脚标注版本与日期；内部使用不加编号，正式发布可挂 `QBD-CB-INT-YYYYMMDD+序号`（内部资料编号）

## 五、JSON Schema

程序化生成请加载 `01_产品介绍_template.json`，核心字段：
`model_no`（机型）、`positioning`（一句话定位）、`market_bg`（可选市场背景）、`selling_points[]`（卖点数组）、`spec_table`（规格表对象）、`view_diagrams[]`（视图图组）、`hardware_sections[]`（硬件详解章节数组）、`appendix[]`（附录）。
