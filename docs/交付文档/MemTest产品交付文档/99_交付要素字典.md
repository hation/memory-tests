## 3. 功能清单（脚本级能力）

| 功能 | 脚本 | 说明 |
|---|---|---|
| 单批压测编排（核心） | `scripts\Run-MemtestSuite.ps1` | 识别建档 → 引导 Memtest86+（SOL/Serial/USB/EFI）→ 抓日志 → 解析 MTLOG → 判定 PASS/FAIL/INCOMPLETE → 输出逐根报告；支持 `-ParseOnly` 断点续测 |
| 批量调度（核心） | `scripts\Run-BatchScheduler.ps1` | 批次清单 CSV 驱动逐批自动运行，输出全量逐根总表 |
| 智能识别建档（核心） | `scripts\Identify-Memory.ps1` | 读 SPD（序列号/容量/频率/DDR5 判定）+ 预期清单匹配（防调包） |
| 服务器能力评估 | `scripts\Run-ServerAssessment.ps1` / `Check-ServerCapabilities.ps1` | 17 项可行性评估（带内 CIM + 带外 BMC/IPMI，角色化三态判定） |
| BMC 诊断与防护 | `scripts\Diag-Bmc.ps1` / `Set-BmcStaticIp.ps1` | BMC 一键诊断；BMC 静态 IP 查询/恢复 |
| 环境自检 | `scripts\check_env.ps1` | 首行打印工具版本、核对依赖可用 |
| 菜单版 ISO 构建 | `scripts\New-MemtestSolIso.ps1` / `Smoke-MemtestIso.ps1` / `iso9660_build.py` | 生成 GRUB 菜单版 `memtest-sol.iso`（预设档位 + 20s 超时自动默认），QEMU/OVMF 冒烟验证 |
| 整机满载 | `scripts\Run-Prime95Stress.ps1` | Prime95 无值守 torture 封装（Windows 整机满载，ORT 可选增强） |
| 结果归集 | `scripts\Export-ServerResults.ps1` / `Import-ServerResults.ps1` | 跨机器结果打包导出与导入合并 |
| 任务清单进度 | `scripts\New-TaskChecklist.ps1` / `Update-TaskChecklist.ps1` | 17 项测试执行清单进度追踪（总览 + 流程勾选自动更新） |
| 指令记录 | `scripts\Start-CommandLog.ps1` / `Stop-CommandLog.ps1` | 会话转录（可选）；所有脚本自动写 `results\cmdlog\commands-<日期>.csv`（常开、密码打码） |
| 历史库（可选） | `db\`（Db-Import/Query/Export/Merge） | SQLite 跨批次按 SN 追踪历史，需 Python 3，不影响主流程 |
| 单源构建 | `scripts\build.ps1` | 一键同步离线包 / `-Zip` 打包，VERSION 单一来源 |
| 附加监控 | 内置 | WHEA/ECC 错误采集（`-MonitorEcc`）、IPMI 温度采样（`-MonitorTemp`）、断电循环（`-RestartLoop`，前置电源风险警示） |

## 4. 运行环境参数

| 项 | 要求 |
|---|---|
| 编排机系统 | Windows 10 / Windows Server 2016+ |
| PowerShell | 5.1+（系统自带，首选 `powershell.exe`，兼容 `pwsh`） |
| 网络 | 编排机可 ping 通服务器 BMC 管理 IP（端口 623）；无需互联网 |
| 被测服务器 | 带 BMC/IPMI + 内存槽；开启 BMC SOL + BIOS 串口重定向（**115200**） |
| 被测内存 | DDR4 / DDR5（Memtest86+ v9 支持） |
| 内置依赖（免联网免安装） | ipmitool 1.8.18（`tools\ipmitool\`）、Memtest86+ v9.00（`boot\`）、GRUB 2.06（`tools\grub\`）、便携 Python（构建类脚本用） |
| 可选外部依赖 | Rufus（制作 USB 引导盘）；Serial 方式需 null-modem 交叉串口线 + USB-RS232 转接头；db/ 历史库需 Python 3 |

## 5. 常用命令（交付文档引用基准）

```powershell
# 单批 SOL 全自动验收（4 轮）
.\scripts\Run-MemtestSuite.ps1 -BatchName batch01 -BootMethod SOL `
  -BmcHost <BMC_IP> -BmcUser <user> -MaxPasses 4 -ConfirmSwitch

# 批量调度（批次清单驱动）
.\scripts\Run-BatchScheduler.ps1 -ManifestCsv .\config\batches.csv -DryRun      # 先预览
.\scripts\Run-BatchScheduler.ps1 -ManifestCsv .\config\batches.csv -ContinueOnError

# 仅解析已有日志（断点续测 / 复核）
.\scripts\Run-MemtestSuite.ps1 -ParseOnly -LogFile <raw log 路径>

# Serial 物理串口线（完全离线）
.\scripts\Run-MemtestSuite.ps1 -BootMethod Serial -SerialPort COM3 -BaudRate 115200 -MaxPasses 4

# USB 半自动
.\scripts\Run-MemtestSuite.ps1 -BootMethod USB -UsbDrive E: -MaxPasses 4

# 智能识别建档
.\scripts\Identify-Memory.ps1 -BatchName batch01

# 环境自检
.\scripts\check_env.ps1
```

## 6. 输出与判定参数

| 项 | 说明 |
|---|---|
| 输出根目录 | `results\`（可用 `-LogPath` 重定向） |
| 关键输出文件 | `<批次>-inventory.csv`（识别建档）、`<批次>-report.csv`（单批逐根报告）、`master_manifest.csv`（累计台账）、`raw\`（原始 MTLOG/报告备份）、`all-batches-report-<ts>.csv`（调度器全量总表）、`batch-summary-<ts>.csv`（调度器批次汇总） |
| 判定逻辑 | `ev=done` + `status=pass` + `Errors=0` → **PASS**；任一错误事件/`status=fail` → **FAIL**；超时未完成（`MaxPasses×90+30` 分钟）→ **INCOMPLETE** |
| MTLOG 事件 | 每行 `MTLOG ts=<秒> ev=<事件> key=value`：start / info / spd / pass_end / progress / data（错误明细）/ done |
| CSV 编码 | UTF-8（Excel 直接打开）；汇总文本 UTF-8 BOM |
| 报告字段 | Batch / ToolVersion / Slot / SerialNumber / PartNumber / CapacityGB / SpeedMTs / MemType / MatchState / TestDate / Passes / Errors / EccErrors / Result |

## 7. 兼容性参数

| 分类 | 兼容范围 |
|---|---|
| 编排机平台 | Windows 10 / Windows Server 2016+（PowerShell 5.1） |
| 引导方式 | **SOL**（机房批量，推荐，需 BMC 串口重定向）；**Serial**（物理串口线，完全离线）；**USB**（半自动，需人工插拔）；**EFI**（一次性引导，不破坏默认启动项） |
| BMC 厂商 | Dell iDRAC / Supermicro / AMI 通用（浪潮、华硕等）/ Lenovo XCC（SOL 开启入口不同，见 `docs/04`） |
| 内存类型 | DDR4 / DDR5 |
| 历史库 | Python 3（可选功能，纯标准库 sqlite3，WAL 模式） |
