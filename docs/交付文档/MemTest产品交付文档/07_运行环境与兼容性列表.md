## 1 运行环境要求

| 项 | 要求 | 说明 |
| --- | --- | --- |
| 编排机系统 | Windows 10 / Windows Server 2016+ | 工具全链路在 Windows PowerShell 上运行 |
| PowerShell | 5.1+（系统自带） | 首选 `powershell.exe`；兼容 `pwsh`（PowerShell 7） |
| 网络 | 编排机可 ping 通服务器 BMC 管理 IP（端口 623） | SOL 走 BMC 管理网口；**无需互联网**，完全离线可用 |
| 被测服务器 | 带 BMC/IPMI + 内存槽 | 需开启 BMC SOL 与 BIOS 串口重定向（波特率 **115200**，须与 Memtest86+ `log=ttyS0,115200` 一致） |
| 被测内存 | DDR4 / DDR5 | Memtest86+ v9 支持 DDR4 / DDR5 |

> 安装与一次性配置细节（BMC/BIOS 串口重定向、引导介质制作）详见 [运行环境与依赖安装说明](../../04-运行环境与依赖安装说明.md)。

## 3 兼容矩阵

### 3.1 引导方式兼容表

| 方式 | 适用环境 | 前置条件 | 自动化程度 | 备注 |
| --- | --- | --- | --- | --- |
| **SOL**（BMC 串口网络化） | 机房批量（有 BMC 管理网） | BMC 开启 SOL + BIOS 串口重定向（115200）；编排机可连通 BMC 管理 IP（端口 623） | 全自动无人值守 | 推荐方式；附带断电循环 / 温度读取（IPMI）附加能力 |
| **Serial**（物理串口线） | 完全离线、无 BMC 网络 | null-modem 交叉串口线 + USB-RS232 转接头，接好线即可 | 全自动零按键 | 唯一"离线 + 零按键"方案 |
| **USB**（U 盘报告） | 单机/笔记本快速验证 | 需人工插拔 U 盘 + 按键保存（F1→6） | 半自动 | 最易排查、无前置配置；`maxpasses` 自动重启需人工按键保存 |
| **EFI**（一次性引导） | 本地一次性进入 Memtest86+ | 需 UEFI；一次性引导在部分固件上不可用 | 全自动（需取日志通道） | 属"引导手段"而非独立方案，取日志仍需配合 SOL/Serial/USB |

> 四种方式的原理、场景选型与决策建议详见 [引导方式对比评估](../../11-引导方式对比评估.md) 与 [技术白皮书](./03_技术白皮书.md) 4.1 节。

## 4 已知限制（明确声明）

1. **引导方式依赖环境**：SOL 方式需服务器带 BMC/IPMI 串口重定向（SOL）；USB 方式需人工插拔；EFI 方式需 UEFI 且一次性引导在部分固件上不可用。四种方式并存，按环境选择。
2. **不替代 Memtest86+ 本身**：本工具只编排与汇总，测试能力完全依赖 Memtest86+。
3. **重启行为依赖系统配置**：`maxpasses` 跑满后 Memtest86+ 自动重启，需确保重启回到系统并续跑下一批（批次切换编排处理）。
4. **硬件依赖项不在工具范围**：电压裕量、时序/SI、高低温、THB、ESD、振动、冲击、弯曲、目检电性等加压/加温类外包项（及人工项）不由本工具承担；系统级满载如需增强，可选内置 Prime95 整机满载。

> 限制项与 [需求说明](../../03-PowerShell压测工具需求说明.md) 相关章节一致：第 1、3 条对应第 9 节风险与限制；第 4 条对应第 2 节覆盖范围（外包/人工项）与第 9 节第 4 条（性能受限项）。
