## 1. 项目背景与目标

**为什么做**：内存条批量验收此前依赖人工逐根操作——手动进 BIOS 引导测试、盯屏幕看结果、抄录序列号、手工汇总表格，耗时长、易出错、难以追溯。随着来料/出货验收规模扩大，需要一套把整条链路自动化的工具。

**目标**：做到"插满内存，跑一条命令，拿走逐根结论"——一条命令完成从识别建档到逐根结论的全流程，全程无人值守、结果逐根可追溯、过程可审计。

## 2. 交付成果

**已完成 v20 交付**，工具以 PowerShell 编排器 + Memtest86+ 真实内存测试 + 批量压测报告的形态落地，五大核心能力：

| # | 卖点 | 说明 |
|---|---|---|
| ① | **全自动无人值守** | SOL（服务器带外串口）一条命令跑完全程：自动识别内存、自动引导测试、自动抓取日志、自动判定 PASS/FAIL，最后输出逐根结论，无需人员盯机。 |
| ② | **四种引导方式全覆盖** | SOL（机房批量）/ Serial（物理串口线，完全离线）/ USB（半自动）/ EFI（一次性引导），按机房环境灵活选用，总有一种适配你的条件。 |
| ③ | **智能识别建档 + 预期清单匹配防调包** | 自动读取每根内存的序列号、容量、频率并判定 DDR5，与预期清单逐条比对，发现“调包”（串号、换条）即时暴露，从源头保证“测的就是该测的那根”。 |
| ④ | **完全离线包** | 测试所需依赖全部内置（含 Memtest86+、ipmitool 等），零安装、零联网即可部署运行，适合对网络安全有严格要求的机房环境。 |
| ⑤ | **逐根可追溯** | 每根内存条以序列号关联测试结果，配合断点续测与全量指令记录，任何一根条子从识别到结论的过程都可回查、可复核。 |

**覆盖测试范围**：行业 17 项验收方案中 **8 项由工具覆盖**（SPD 校验 / 基础识别 / 全地址读写 / ECC 监控 / ORT 72h 老化 / 上电掉电重启循环 / 多平台兼容 / 混插压力）；硬件依赖项（电压裕量 / 时序 / 高低温 / THB / ESD / 振动 / 冲击 / 弯曲 / 目检电性，需专用测试设备）维持外包或人工执行。配套 17 项执行清单与进度追踪见 [../../19-测试项执行清单.md](../../19-测试项执行清单.md)。

## 4. 价值与意义

- **效率**：批量验收从逐台人工操作改为一条命令无人值守，多机台可同时开测，人员无需盯机；
- **质量**：逐根判定、自动汇总，测试内核采用久经考验的 Memtest86+ 真实内存测试，工具只做编排与汇总、不替代测试本身；
- **可信**：序列号关联 + 防调包比对 + 全量指令记录，逐根可追溯、可审计，结果经得起复核；
- **安全**：完全离线、零安装零联网，可部署到网络安全要求高的机房环境；
- **稳健**：断点续测不返工——中途中断可续跑、已出结果不丢失；开工前 BMC 体检、SOL 链路加固，长时 ORT 老化测试温度监控贴合实际；
- **可管**：版本号单一来源、自动化测试框架护航，工具自身质量有保障。
