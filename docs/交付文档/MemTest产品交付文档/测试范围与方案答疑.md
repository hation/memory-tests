## Q1 测试范围与边界（哪些内存条能测 / 不能测）

### 1.1 测试边界总览：17 项矩阵 × 三层执行

项目验收体系 = **17 项行业测试矩阵**（总纲见 `docs/02-批量压力测试方案.md`），按三层执行：

| 层 | 覆盖项 | 规模 | 当前状态 |
|---|---|---|---|
| **L1 全量**（每根必测） | 1 SPD 校验、2 基础识别、3 全地址读写（Memtest）、16 混插压力、17 目检+电性复检 | 每根都做 | 第 1/2/3/16 可测（软件）；第 17 目检可做、电性复检需万用表 |
| **L2 抽样**（每批抽 N 根） | 4 ECC 验证、5 72h ORT 老化、10 上电掉电循环、15 多平台兼容 | 每 100 根抽 3–5 根 | 第 4 待确认 ECC 平台；第 5/10/15 可测（软件） |
| **L3 外包**（工程样件） | 6 电压裕量、7 时序/SI、8 高低温循环、9 湿热 THB、11 ESD、12 振动、13 冲击、14 弯曲 | 每来源类别送 1–3 根 | **当前无硬件，全部不能自测**，需外包实验室 |

**验收结论 = L1 全量 0 失败 + L2 抽样通过 + L3 样件报告合格**，三者共同构成。

### 1.2 哪些内存条能测

| 维度 | 能测的范围 | 说明 |
|---|---|---|
| 内存类型 | **DDR4 / DDR5** 均可（Memtest86+ v9 支持） | 消费级 UDIMM、服务器 ECC / RDIMM / LRDIMM 均可引导测试 |
| 引导环境 | **SOL**（需 BMC 串口重定向 115200，机房批量，推荐）<br>**Serial**（物理串口线，完全离线）<br>**USB**（半自动，需人工插拔）<br>**EFI**（一次性引导，不破坏默认启动项） | 四种方式按机房条件选，总有一种可用 |
| 能测的能力 | ① 识别建档（SPD 序列号/容量/频率/DDR5 判定 + 防调包）<br>② 全地址读写覆盖（Memtest86+ 全 13 项，1/2/4 轮 + 快筛）<br>③ ECC 监控（需 ECC 平台 + ECC 条）<br>④ 72h ORT 满载老化（内置 ORT 模式 + 全程测温）<br>⑤ 上电掉电循环（IPMI 断电 ≥200 次）<br>⑥ 多平台兼容 / 混插压力（Memtest + Prime95 整机满载） | 即 L1 的 1/2/3/16 + L2 的 4/5/10/15 + 17 目检部分 |

### 1.3 哪些内存条不能测 / 当前不能测

| 情形 | 限制 | 替代/处理 |
|---|---|---|
| 服务器无 BMC/IPMI | SOL 方式不可用 | 改用 Serial / USB / EFI 方式（功能不受影响） |
| 非 ECC 平台（消费级主板） | 第 4 项 ECC 纠错功能无法验证 | 先确认平台（`Run-ServerAssessment` 评估）；ECC 条需 ECC 平台才可验证 |
| 普通消费条（无 ECC） | 无 ECC 可验证 | 跳过第 4 项，其余项不受影响 |
| 第 6/7/8/9/11/12/13/14 项 | **当前无硬件，全部不能自测** | 外包第三方可靠性实验室（工程样件 1–3 根） |
| 第 17 项电性复检 | 需万用表 | 自购万用表（低价必购）后即可测 |
| 打磨重标/假条 | 功能测试中**压力下必报错**，能测 | 但需先过防伪识别关卡（SPD 深读 + 颗粒编码核对），见 Q5 |
| RDIMM 与 LRDIMM 混插 | 平台不允许混插（服务器主板限制，非工具限制） | 按平台规范分型号装机 |
| 高负载加压/加温类 | 第 5 项加压/加温是增强项 | 满载软件已可测（72h ORT），加压/加温需外部手段（可编程电源/加热舱位） |

### 1.4 结论一句话

> **凡是"软件 + 现有服务器"能解决的项（8 项）全部可测；涉及测量级硬件的 8 项（L3）当前不能自测，只能采购或外包；目检可做、电性复检补一台万用表即可。** 测试边界不受内存条本身形态限制（DDR4/DDR5、UDIMM/RDIMM/LRDIMM/ECC 都能测），限制只来自环境（BMC）与硬件（L3 设备）。

## Q2 测试成本与周期（不同方案的时间范围 + 全新/拆新推荐方案）

### 2.1 各测试方案的时间范围（单根/单机，估算）

| 方案 | 时长（估算） | 依据 |
|---|---|---|
| Memtest86+ **1 轮快筛**（前 9 项） | 16GB≈1.5–2h；32GB≈2.5–3h | 快筛约为全项 1/2–2/3 时长（社区经验） |
| Memtest86+ **1 轮全项**（13 项） | 约 **7–8 分钟/GB/轮**：16GB≈2–2.5h；32GB≈4–4.5h；64GB≈过夜 | Memtest86 官方/社区实测 |
| **2 轮全项** | 16GB≈4–5h；32GB≈8–9h | 上述 ×2 |
| **4 轮全项**（验收最终口径） | 16GB≈8–10h；32GB≈**16–18h（需过夜）** | 上述 ×4；社区"4 轮为常见验收底线" |
| **72h ORT** 无限轮老化 | **72h**（固定） | 内置 ORT 模式（`-MaxMinutes`） |
| Prime95 混插整机长压 | 2–4h（`Run-Prime95Stress.ps1 -Minutes`） | 项目内置脚本 |
| 上电掉电循环 | 约 10h+/台（≥200 次 × 约 3 分钟/次，不含每次 Memtest 首轮时间，实际更长） | 项目方案（docs/02） |
| L3 外包送检 | **2–4 周**（含实验室排队）；JEDEC 鉴定级项（1000 次温循 / 1000h THB）约 **42 天**级 | 实验室报价与 JEDEC 标准 |
| 批量 1000 根全检 | 单台 16 槽服务器 24h 连轴约 **5–6 天**；多台并行约 **2–3 天** | 项目方案（docs/02）执行计划 |

> ⚠️ 时长与容量/CPU 核数/带宽相关，官方无固定值；建议先拿目标机型（如 32GB）实测 1 轮标定后折算。

### 2.2 测试成本构成（估算）

| 成本项 | 金额（估算） | 说明 |
|---|---|---|
| 软件与现有服务器 | **0 元**（已有） | Memtest86+、Prime95、识别脚本、BMC 全内置/已有 |
| 自购小件（建议） | **合计约 3–6 万元** | 万用表、可编程电源、ESD 静电枪、便携内存测试机（RAMCHECK LX 约 1.2–1.8 万）、弯曲治具（可选） |
| 自购环境箱（可选） | 温循箱约 1.5–6.6 万、双 85 恒温恒湿箱约 1.3–8 万 | 使用频率高时可自购 |
| L3 外包送检 | 高低温/温循约 800–3,000 元/次；THB 约 1,200–3,000 元/次；ESD 约 1,500 元/h；振动 500–2,500 元/h；冲击约 1,000–2,000 元/次 | 一次送检尽量在同一实验室做齐 L3 项（共用样件、共享报告） |
| 高价设备（**不建议自购**） | 20GHz 示波器全套 300 万+（租赁月费约 8.6 万起）；振动台 28–180 万；冲击台 1.7–40 万 | 投入产出比低，外包/租赁最经济 |

### 2.3 全新条 vs 拆新条：推荐测试方案

| 货源 | 推荐测试深度 | 理由 |
|---|---|---|
| **全新原厂条** | ① 识别建档 + SPD/防调包核对（L1: 1/2）<br>② Memtest86+ **1–2 轮全项**（L1: 3）<br>③ 目检（L1: 17）<br>④ 批次抽检：4 轮全项 + 24h 老化 + ECC（L2 抽 N 根）<br>⑤ 按批次送 L3 样件 | 原厂已过完整测试与老化（金士顿 100% 全检 + 服务器条 24h Dynamic Burn-In），来料只需验证"正品、无运输损伤、与清单一致"；全项 1–2 轮即可筛出绝大多数缺陷 |
| **拆新条**（从整机拆下、未长期服役） | ① 识别建档 + 防调包（L1: 1/2）<br>② **≥4 轮全项**（L1: 3，验收底线）<br>③ **24–72h 老化 burn-in**（L2: 5）<br>④ ECC 纠错日志核查（L2: 4，需 ECC 平台）<br>⑤ 金手指目检/氧化检查（L1: 17）<br>⑥ 断电循环抽检（L2: 10）+ 多平台抽检（L2: 15）<br>⑦ L3 样件送检 | 拆新条已有服役史（虽短），间歇性失效风险高——行业"回收条翻新"流程就是 SPD 读取 → MemTest ≥4 轮全检 → 金手指检查 → 分级 → 老化 burn-in → 出货复测；服务器场景建议过夜多轮 + 盯 ECC 计数 |

> 判断口径：**全新 = 验正品 + 快筛**；**拆新 = 全检 + 老化筛选**（时长差在"老化"与"轮次深度"）。

## Q3 各方案的测试内容与指标（17 项明细 + 工具档位）

### 3.1 按执行层逐项：测试内容 / 判据 / 指标

**L1 全量组（每根必测）**

| # | 测试项 | 内容 | 判据 / 指标 |
|---|---|---|---|
| 1 | SPD 信息校验 | 读 SPD 字段 + CRC，与标签/预期清单比对 | SPD 有效、无 CRC 错误、与标签一致 |
| 2 | 基础识别/容量频率 | 核对容量、频率、厂商、序列号 | 全部一致 → 通过（防调包核心） |
| 3 | 全地址读写覆盖 | Memtest86+ 全 13 项（walking ones / moving inversions / bit fade 等） | **0 错误**；记录错误地址与测试号 |
| 16 | 混插压力 | 实际混插组合（不同容量/品牌/频率）跑 Memtest + Windows 内 Prime95 长压 2–4h | 0 错误；Prime95 `Status=PASS`；单根不稳→隔离排查 |
| 17 | 目检 + 电性复检 | 目检（IPC-A-610：金手指氧化/划伤、焊点虚焊/桥连）+ 万用表测短路/开路 | 无氧化、无虚焊桥连、电性正常 |

**L2 抽样组（每 100 根抽 3–5 根）**

| # | 测试项 | 内容 | 判据 / 指标 |
|---|---|---|---|
| 4 | ECC 纠错验证 | 确认 ECC 平台后，Memtest86+ `ecc` 参数 + Windows WHEA / Linux mcelog 监控 | ECC 生效、能上报/纠错记录，**无未纠正错误（UE）** |
| 5 | 72h ORT 老化 | 内置 ORT 模式满载 72h + 全程测温（`-MaxMinutes`，口径 B） | **72h 内 0 错误、0 ECC、无中断、温度 ≤85℃** |
| 10 | 上电掉电循环 | `ipmitool chassis power cycle` 自动断电-上电 ≥200 次，每次上电跑首轮 | 全部正常初始化、**无训练失败**（DDR5 常见失效点） |
| 15 | 多平台兼容 | Intel/AMD 各 ≥1 台：识别 + 快筛 + 满载 2–4h | 各平台 0 错误、无兼容性异常 |

**L3 外包组（工程样件，每来源类别 1–3 根）**

| # | 测试项 | 内容 | 判据 / 指标 |
|---|---|---|---|
| 6 | 电压裕量 | VDD/VDDQ 的 Vmin/Vmax 边界扫描（结合温度边界） | 规格电压 ± 裕量内功能正常 |
| 7 | 时序 / 信号完整性 | 示波器抓 DQ/DQS 眼图，对照 JEDEC DDR5 mask | 眼高/眼宽达标，**BER ≤ 1E-16** |
| 8 | 高低温循环 | JESD22-A104（如 -40℃↔85℃、每区驻留 15–30 分钟，500–1000 次） | 循环后电性复测通过 |
| 9 | 湿热 THB | JESD22-A101（85℃/85%RH + 偏压，96–1000h） | 无腐蚀/漏电超标 |
| 11 | ESD | IEC 61000-4-2（接触 ±4kV、空气 ±8kV 典型）；HBM JESD22-A114 / CDM JS-002 | 测试后功能正常（破坏性，抽坏即淘汰） |
| 12 | 机械振动 | JESD22-B103（典型 3G、0.75mm、5–500Hz 扫频） | 振动后电性复测通过 |
| 13 | 机械冲击 | JESD22-B110（典型 1500G 半正弦脉冲，6 方向） | 冲击后电性复测通过 |
| 14 | 弯曲扭曲 | 板级弯曲/扭曲治具施加规定应力 + 电性监测 | 应力下及卸力后功能正常 |

### 3.3 行业标准参考值（联网调研）

- **Memtest86+ 验收惯例**：官方建议默认 4 轮；"4 轮满 pass 才算 used, working"是二手条分级通行做法；疑似间歇性故障需长时间跑（memtest.org / MemTest86 官方）。
- **厂商老化**：金士顿服务器 ECC 条采用 Dynamic Server Burn-In，**24h 等效 3 个月重度使用**；成品 100% 全检。
- **现场数据**：Google 大规模现场研究显示**每年 >8% DIMM 出现错误**（25k–70k 错误/十亿器件小时/Mbit）→ 支持内存条全检 + 老化筛选。
- **国标**：GB/T 36418-2018 要求服务器内存条 55℃ 数据保留 ≥12h、-20℃ ≥20h、误码率 ≤5×10⁻¹² bit/h。
- **JEDEC 可靠性项周期**：A104 温循 500–1000 次 ≈ 42 天级；A101 THB 96–1000h ≈ 42 天级（属鉴定级测试，不适合作为来料例行筛选项——例行筛选用 HAST 96h 或更短方案 + Memtest 全项 + 24–72h 老化）。

### 4.2 自购 vs 外包总判断

- **建议自购（合计约 3–6 万元；加环境箱约 3–15 万元）**：万用表、可编程电源、ESD 静电枪、高低温试验箱、恒温恒湿箱、弯曲治具、便携内存测试机——便宜且使用频率高；
- **建议外包/租赁**：≥20GHz 示波器（自购 300 万+，送检或租赁月费 8.6 万起远低于自购）、振动台（28–180 万）、冲击台（1.7–40 万）、批量 burn-in 系统（定制数十万起）；
- **L3 送检单次费用参考**：高低温/温循 800–3,000 元/次；THB 类 1,200–3,000 元/次；ESD 约 1,500 元/小时；振动 500–2,500 元/小时；冲击约 1,000–2,000 元/次；高温老化 800–1,500 元/天；
- **关键策略**：一次送检尽量在同一家实验室把 L3 项做齐（共用样件、共享报告），降低成本；破坏性项（11/12/13/14）样件不返还，送检数量按损耗预留。

### 4.3 没有这些测试项的风险

| 缺项 | 风险 | 典型后果 |
|---|---|---|
| 第 6 电压裕量 | 边缘电压（Vmin/Vmax）下不稳定漏检 | 机房供电波动/降压时蓝屏、死机、数据错误（量产场景高频失效点） |
| 第 7 时序/SI | 高速率下信号裕量不足漏检 | 高负载/长时间运行偶发错误；DDR5 速率越高对 SI 越敏感 |
| 第 8 高低温循环 | 焊点/封装热应力缺陷漏检 | 温度变化环境（夏季高温、断电降温）下间歇性失效 |
| 第 9 THB | 防潮/腐蚀缺陷漏检 | 高湿环境漏电、金手指腐蚀，长期可靠性隐患 |
| 第 11 ESD | 静电损伤漏检（破坏性） | 来料/装机过程静电击伤，使用期提前报废 |
| 第 12/13 振动/冲击 | 运输/安装应力损伤漏检 | 运输后隐性损伤、机箱振动下接触不良、装机后失效 |
| 第 14 弯曲 | 安装受力损伤漏检 | 插拔受力后虚焊/断裂 |
| **无 L3 全项** | 可靠性边界不明 | 只能保证"当前环境功能通过"，无法支撑"全场景长期可靠"的验收结论 |

> **风险结论**：L3 属工程样件级验证（行业不对每根做），**没有 L3 时验收结论降级为"L1+L2 功能级通过"，缺失可靠性级结论**。建议至少按来源批次/周期送检一次 L3；若不做，需在验收报告中明确标注"可靠性项未验证"。

## Q5 内存条分类与测试方案（全新 / 拆新 / 其他）

### 5.1 市面上内存条分类总表

| 类别 | 定义 / 来源 | 典型风险 | 建议测试深度 |
|---|---|---|---|
| **全新原厂条** | 品牌/原厂正规渠道出货，原厂正片颗粒，出厂已过完整测试与老化 | 假货/高仿包装冒充、水货 | 识别（SPD + 颗粒编号核对）+ 功能（Memtest 1–2 轮全项）+ 批次抽检老化 |
| **OEM 工包 / 散片** | 原厂为整机/服务器定制（Dell/HPE 等），无零售包装、SPD 按 OEM 定制编程 | 来源难查、参数与零售版不同、无保修 | 识别（SPD 深读）+ 功能 + 抽检老化 |
| **拆新条**（pulled / used） | 从整机/服务器拆下、未长期服役（本项目的第二类货源） | 已服役损耗（虽短）、间歇性失效（自检过、压力下才报错） | 识别 + **≥4 轮全项** + **老化 burn-in（24–72h）** + ECC 日志核查 + 金手指目检 + L2 抽样 + L3 样件 |
| **翻新条**（refurbished / recycled） | 回收后清洗、重新植球、重贴标再售；分正规分级出货 vs 低端"电子垃圾翻新" | 寿命透支、性能衰减、随时报废；低端翻新是造假源头 | 全检 + 老化筛选 + 出货前复测（按回收条流程，见 5.2） |
| **返修条**（RMA 流出） | 售后维修件、工厂返修件流入市场 | 维修痕迹、质量参差、无原厂保障 | 同拆新条，另加维修痕迹/植球点检查 |
| **假条**（remarked / resealed） | 打磨重标片（磨原标激光打三星/海力士标）、杂牌颗粒贴标、SPD 篡改（如 2133 改 3200）、容量造假（标 64G 实 16G） | 高负载蓝屏/死机、数据丢失；打磨损伤表层电路 | **防伪识别优先**：SPD 底层读取 + 颗粒编码查官方库 + 带宽实测；压力测试必报错即淘汰 |
| **服务器 ECC / RDIMM / LRDIMM** | 服务器专用注册式/带 ECC 条（RDIMM 带 RCD 寄存器，LRDIMM 再加数据缓冲） | 混插不兼容；ECC 会静默纠正单位错误、掩盖早期失效 | 识别 RCD/ECC/等级状态 + 平台兼容 + ECC 纠错日志 + 长时间 burn-in |

> 除"全新、拆新"外，市面上还有 **OEM 工包、翻新、返修、假条、服务器专用 ECC/RDIMM/LRDIMM** 等类别，采购货源时应先明确类别再定测试深度。

### 5.2 行业"回收条翻新"典型流程（拆新条验收基准）

```
SPD 读取验证（抓 remarked / die-swapped 假条）
  → MemTest86 批量全检（≥4 轮满 pass 才算 "used, working"）
  → 金手指外观检查（氧化/划痕降级）
  → 按结果分级（错误条降级/报废）
  → 老化 burn-in（筛早期失效；服务器场景过夜多轮 + 盯 ECC 计数）
  → 出货前复测留档
```

### 5.3 不同分类如何设置测试方案（结合本项目工具落地）

| 货源分类 | 用现有工具的落地方案 | 执行档位/参数 |
|---|---|---|
| **全新原厂条** | `Identify-Memory` 建档 + SPD/防调包核对 → 1 轮全项（或快筛）→ 批次抽 N 根升级 4 轮/24h 老化 → L3 样件送检 | 档位"1轮全项/1轮快筛"；L2 抽检"4轮全项" |
| **拆新条** | 建档 + SPD 深读 → **4 轮全项** → **24–72h ORT 老化** → `-MonitorEcc` 盯纠正计数 → 金手指目检 → L2 抽样（断电/多平台）+ L3 送检 | 档位"4轮全项" + "72h ORT"（`-MaxMinutes` 可调 24h）；`-MonitorEcc` |
| **翻新/返修条** | 按拆新条深度 + 维修痕迹检查；先过防伪关卡（SPD 深读） | 同上 |
| **假条（怀疑）** | 建档时看 `MatchState`（未匹配/待复核）+ CPU-Z/台风读底层 SPD + 颗粒编码查官方库 + AIDA64 带宽实测；压力测试必报错 | `Identify-Memory` + 4 轮全项 |
| **服务器 ECC / RDIMM / LRDIMM** | 识别 RCD/ECC/等级 + 平台兼容验证 + `-MonitorEcc` 监控可纠正/不可纠正计数 + burn-in | 档位"4轮全项/72h ORT" + `-MonitorEcc` |

> **服务器内存条特殊性提醒**：RDIMM/LRDIMM 带 sideband ECC（真 ECC），UDIMM 一般无 ECC；DDR5 自带 on-die ECC 只做片内自检，**不能替代 sideband ECC**——验收必须确认 ECC 真开，并盯可纠正错误计数（BMC/IPMI），不能只看 PASS/FAIL。
