# DDR5 内存条 SOL 全自动验收工具

> 状态：[当前有效]（2026-10-29）
>
> **一句话定位**：“插满内存，跑一条命令，拿走逐根结论”——基于 Windows PowerShell 的 DDR5 内存条批量压力测试与验收工具
>
> **当前版本**：v20

---

## 核心卖点

| 卖点 | 说明 |
|---|---|
| **全自动无人值守** | SOL（服务器带外串口）一条命令跑完全程：自动识别内存、自动引导测试、自动抓取日志、自动判定 PASS/FAIL，最后输出逐根结论，无需人员盯机。 |
| **四种引导方式全覆盖** | SOL（机房批量）/ Serial（物理串口线，完全离线）/ USB（半自动）/ EFI（一次性引导），按机房环境灵活选用，总有一种适配你的条件。 |
| **智能识别建档 + 预期清单匹配防调包** | 自动读取每根内存的序列号、容量、频率并判定 DDR5，与预期清单逐条比对，发现“调包”（串号、换条）即时暴露，从源头保证“测的就是该测的那根”。 |
| **完全离线包** | 测试所需依赖全部内置（含 Memtest86+、ipmitool 等），零安装、零联网即可部署运行，适合对网络安全有严格要求的机房环境。 |
| **逐根可追溯** | 每根内存条以序列号关联测试结果，配合断点续测与全量指令记录，任何一根条子从识别到结论的过程都可回查、可复核。 |

---

## 核心能力参数表

| 能力项 | 规格 |
|---|---|
| 技术形态 | PowerShell 编排器（Orchestrator）+ Memtest86+ 真实内存测试 + 批量压测报告 |
| 目标场景 | 服务器内存条来料/出货验收、批量压测、产线质检、ORT 老化测试、混插压力测试 |
| 引导方式 | SOL（机房批量，推荐）/ Serial（物理串口线，完全离线）/ USB（半自动）/ EFI（一次性引导，不破坏默认启动项） |
| 内存支持 | DDR4 / DDR5（Memtest86+ v9） |
| 编排机环境 | Windows 10 / Windows Server 2016+，PowerShell 5.1+ |
| 依赖 | 全内置免联网（ipmitool 1.8.18、Memtest86+ v9、GRUB 2.06） |
| 输出 | 逐根 CSV 报告 + 累计台账（UTF-8 编码，Excel 直接打开） |
| 判定 | PASS / FAIL / INCOMPLETE（每根内存独立三态结论） |
| 附加能力 | ECC 监控（WHEA）、温度采样（IPMI）、断电循环（前置风险警示）、历史库（可选，跨批次按序列号追踪） |
| 版本 | v20 |

**快速上手（一条命令完成单批 SOL 全自动验收）**：

```powershell
.\scripts\Run-MemtestSuite.ps1 -BatchName batch01 -BootMethod SOL `
  -BmcHost <BMC_IP> -BmcUser <user> -MaxPasses 4 -ConfirmSwitch
```
