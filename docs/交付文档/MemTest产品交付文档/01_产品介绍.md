## 1. 产品定位与目标场景

**这是什么？**

DDR5 内存条 SOL 全自动验收工具是一款**软件工具**，技术形态为：**PowerShell 编排器（Orchestrator）+ Memtest86+ 真实内存测试 + 批量压测报告**。

通俗地讲：它像一个"自动化测试车间主任"——真正的内存压测由久经考验的 Memtest86+ 完成，本工具负责把"开机引导、抓取测试日志、逐根判定结果、汇总成报告"这一整条链路串起来，全程无人值守，最终给你一份**每根内存条独立结论**的验收报告。

**解决什么问题？**

内存条批量验收过去依赖人工逐根操作：手动进 BIOS 引导测试、盯屏幕看结果、抄录序列号、手工汇总表格——耗时且容易出错。本工具把这一过程压缩为**一条命令**，尤其适用于大批量、多机台同时验收的场景。

**目标场景**：

- 服务器内存条**来料/出货验收**
- **批量压测**（多批次、多机台同时跑）
- **产线质检**
- **ORT 老化测试**（长时间满载稳定性验证）
- **混插压力测试**（满槽位混合配置验证）

## 3. 产品特色详解

### 3.1 工具概述

DDR5 内存条 SOL 全自动验收工具是基于 Windows PowerShell 编排器的一款内存条批量压力测试与验收软件工具，具备**全自动无人值守、四种引导方式全覆盖、智能识别建档防调包、完全离线包、逐根可追溯**等特点。要点如下：

- 核心流程一条命令完成：识别建档 → 引导测试 → 抓日志 → 解析 → 判定 → 汇总报告；
- 测试内核采用 Memtest86+ v9 真实内存测试，执行全地址读写等真实测试项，本工具只做编排与汇总、不替代测试本身；
- 支持单批压测与批次清单驱动的批量调度，多批次结果自动归集成全量总表；
- 内置断点续测：日志与解析分离，中途中断可续跑、已出结果不丢失；
- 提供菜单版 ISO（memtest-sol.iso），预设多档测试配置、开机自动默认，适配现网批量启动场景；
- 单源构建与版本管理：一条命令同步离线包，版本号单一来源，杜绝版本漂移；
- 附带自动化测试框架，脚本共享库、参数校验、历史库均有测试覆盖，保证工具自身质量。

### 3.2 自动化验收链路说明

一条命令背后是六步自动化链路（编排机 + 被测服务器协同完成）：

```
① 智能识别建档   → 读取每根内存的序列号/容量/频率，判定 DDR5，与预期清单比对（防调包）
② 引导测试       → 按所选方式（SOL/Serial/USB/EFI）启动 Memtest86+ 并自动进入测试
③ 捕获日志       → 实时抓取测试输出（MTLOG 机器可解析格式），完整落盘
④ 解析结果       → 逐行解析轮次、错误事件、错误地址/测试号等明细
⑤ 结果判定       → 按判定逻辑输出 PASS / FAIL / INCOMPLETE 三种结论
⑥ 汇总报告       → 按序列号逐根汇总，形成累计台账与批次总表
```

全程只有第 ② 步需要服务器真正重启进入测试，其余全部自动完成；USB 方式下需人工插拔 U 盘（半自动）。

### 3.5 输出成果

- **输出根目录**：`results\`（可用参数重定向）；
- **关键输出文件**：识别建档表 `<批次>-inventory.csv`、单批逐根报告 `<批次>-report.csv`、累计台账 `master_manifest.csv`、原始日志备份 `raw\`、调度器全量总表 `all-batches-report-*.csv`、批次汇总 `batch-summary-*.csv`；
- **逐根结论**：每根内存条输出 批次 / 槽位 / 序列号 / 型号 / 容量 / 频率 / 内存类型 / 匹配状态 / 测试日期 / 轮数 / 错误数 / ECC 错误 / 最终结果 等字段，结论为 **PASS / FAIL / INCOMPLETE** 三态；
- **CSV 编码**：UTF-8，Excel 直接打开即可查看。

## 4. 使用方式概览

**快速开始（核心命令）**：

```powershell
# 单批 SOL 全自动验收（4 轮）
.\scripts\Run-MemtestSuite.ps1 -BatchName batch01 -BootMethod SOL `
  -BmcHost <BMC_IP> -BmcUser <user> -MaxPasses 4 -ConfirmSwitch

# 批量调度（批次清单驱动，先预览再实跑）
.\scripts\Run-BatchScheduler.ps1 -ManifestCsv .\config\batches.csv -DryRun
.\scripts\Run-BatchScheduler.ps1 -ManifestCsv .\config\batches.csv -ContinueOnError

# 仅解析已有日志（断点续测 / 复核）
.\scripts\Run-MemtestSuite.ps1 -ParseOnly -LogFile <raw log 路径>

# Serial 物理串口线（完全离线）
.\scripts\Run-MemtestSuite.ps1 -BootMethod Serial -SerialPort COM3 -BaudRate 115200 -MaxPasses 4

# USB 半自动
.\scripts\Run-MemtestSuite.ps1 -BootMethod USB -UsbDrive E: -MaxPasses 4

# 智能识别建档
.\scripts\Identify-Memory.ps1 -BatchName batch01

# 环境自检（首行打印工具版本）
.\scripts\check_env.ps1
```

## 5. 覆盖测试范围

本工具基于行业 17 项验收测试方案设计。其中 **8 项由工具覆盖**，其余硬件依赖项（需专用测试设备）维持外包或人工执行：

| # | 测试项 | 覆盖方式 | 说明 |
|---|---|---|---|
| 1 | SPD 信息校验 | ✅ 工具覆盖 | 识别建档自动完成 |
| 2 | 基础识别读取 | ✅ 工具覆盖 | 槽位/序列号/容量/频率自动读取 |
| 3 | 全地址读写覆盖 | ✅ 工具覆盖 | Memtest86+ 真实内存测试执行，工具负责编排引导与日志解析 |
| 4 | ECC 纠错功能验证 | ✅ 工具覆盖 | WHEA 事件日志监控（ECC 平台） |
| 5 | ORT 72h 满载老化 | ✅ 工具覆盖 | 内置 ORT 长跑模式 + 整机满载增强 |
| 6 | 电压裕量 | ❌ 外包 | 需可编程电源 + 示波器 |
| 7 | 时序 / SI | ❌ 外包 | 需示波器 |
| 8 | 高低温循环 | ❌ 外包 | 需高低温箱 |
| 9 | THB | ❌ 外包 | 需恒温恒湿箱 |
| 10 | 上电掉电重启循环 | ✅ 工具覆盖 | 测试完成后自动重启续跑；配合 IPMI 物理断电可扩展 |
| 11 | ESD | ❌ 外包 | 需静电枪 |
| 12 | 机械振动 | ❌ 外包 | 需振动台 |
| 13 | 机械冲击 | ❌ 外包 | 需冲击台 |
| 14 | 弯曲扭曲 | ❌ 外包 | 需治具 |
| 15 | 多平台兼容 | ✅ 工具覆盖 | 同脚本跨平台编排，输出平台信息 |
| 16 | 混插压力 | ✅ 工具覆盖 | 满槽位混插配置跑 Memtest86+ |
| 17 | 目检 + 电性复检 | ❌ 人工 | 人工 + 万用表 |

**结论**：工具覆盖 8 项（SPD 校验 / 基础识别 / 全地址读写 / ECC 监控 / ORT 72h / 重启循环 / 多平台 / 混插）；硬件依赖项（电压裕量 / 时序 / 高低温 / THB / ESD / 振动 / 冲击 / 弯曲 / 目检电性）外包或人工。配套流程与执行清单见 [../../18-测试方案总览.md](../../18-测试方案总览.md) 与 [../../19-测试项执行清单.md](../../19-测试项执行清单.md)。
