# 16 · 新工具压力测试使用指南（菜单版 ISO + 编排器）

> 本机 BMC：IP `10.0.0.10` / 用户名 `root`（密码运行中提示输入）；换机器只改这一处。
> 每条命令给两行：**原格式**（通用占位符）+ **本机版**（已填好，复制即用）。

> 状态：[当前有效]（2026-10-22）
> 变更记录：2026-10-22 新建（随"Memtest SOL 菜单引导 ISO 工具"交付）

> 适用：用新工具跑 DDR5 内存条 SOL 压力测试——引导介质换成**菜单版 ISO**（开机可选
> 轮数），其余流程（SOL 抓日志、解析、出报告）与既有 SOL 指南一致。

---

## 1. 这套新工具解决什么

之前用官方 `memtest.iso` 挂 BMC 虚拟介质时，引导参数 `log=ttyS0,115200 maxpasses=N`
只能由引导加载器传入，ISO 挂载后**改不了轮数**——想跑 2/3 轮就得重制 ISO，很麻烦。

新工具产出一个**带 GRUB 引导菜单的 UEFI ISO**（`memtest-sol.iso`），开机时在服务器
屏幕上选预设：**4 轮验收 / 2 轮 / 1 轮快速筛选 / 交互界面**，超时 10 秒自动进默认项
（4 轮验收），无人值守可用。改轮数 = 改一个配置文件重跑工具，不用手改二进制。

## 2. 新工具清单

| 组件 | 作用 | 位置 |
| --- | --- | --- |
| `memtest-sol.iso` | 菜单版 UEFI ISO（**离线包已内置，直接用**） | `memtest\boot\` |
| `New-MemtestSolIso.ps1` | 构建 / 改预设后重制 ISO；`-Smoke` 自动 QEMU 冒烟 | `scripts\` |
| `Smoke-MemtestIso.ps1` | QEMU/OVMF 冒烟验证（构建机自检用） | `scripts\` |
| `memtest-presets.conf` | 引导菜单预设配置（改轮数在这里改） | `config\` |
| `iso9660_build.py` | ISO 组装器（New-MemtestSolIso 内部调用） | `scripts\` |

依赖：构建机需 Python 3（仅重制 ISO 时需要）；产物 ISO 运行不需要 Python。
**GRUB 2.06 已随本项目内置**（`tools\grub`，约 3.8MB），构建 ISO **全程离线可用**；
`-DownloadGrub` 仅作兜底（GRUB 缺失且可联网时自动补下载），离线时不需要。
> `-Smoke`（QEMU 冒烟）是**构建机可选自检**，需要 QEMU（约 1.2GB，未随包内置，离线包不含）；
> 压测流程本身不需要它——跳过 `-Smoke` 即可完全离线。

## 3. 压测整体流程

```
① 拿到/构建菜单版 ISO（memtest-sol.iso）
② BMC 虚拟介质挂载 → 一次性引导进 ISO（UEFI）→ 屏幕上选轮数（或超时自动默认）
③ Windows 编排器跑 Run-MemtestSuite -BootMethod SOL → ipmitool 抓 MTLOG
④ Memtest86+ 跑满轮数输出 ev=done → 自动重启回系统 → 编排器解析出报告
```

与既有 SOL 流程（见 `docs/09-SOL使用指南.md`）的区别只在 ①②：**引导介质换成菜单版
ISO，轮数在开机菜单里选**；BMC/BIOS 一次性配置（SOL、串口重定向 115200）完全相同。

## 4. 详细步骤

### 4.1 拿到或构建菜单版 ISO

**直接用离线包内置的**（推荐，已随包分发，OVMF/QEMU 实测可引导）：

```
memtest\boot\memtest-sol.iso
```

**改预设后重制**（例如想把默认改成 2 轮，见第 5 节）：
```powershell
# 原格式（通用）
.\scripts\New-MemtestSolIso.ps1                          # GRUB 已内置，离线直接跑
.\scripts\New-MemtestSolIso.ps1 -Smoke                   # 可选：构建后 QEMU 冒烟自检（需 QEMU）
# 👉 本机版（复制即用，全程离线）
.\scripts\New-MemtestSolIso.ps1
.\scripts\New-MemtestSolIso.ps1 -Smoke
```
产物默认写到 `memtest\boot\memtest-sol.iso`。

### 4.2 挂载并引导（BMC 虚拟介质）

1. BMC 网页 Virtual Media 挂载 `memtest-sol.iso`；
2. 设置**一次性引导从虚拟光驱**（UEFI 模式）；
3. 服务器屏幕上出现 GRUB 菜单：
   ```
   Memtest86+ 4轮完整验收（SOL）     ← 默认（10s 自动进）
   Memtest86+ 2轮（SOL）
   Memtest86+ 1轮快速筛选（SOL）
   Memtest86+ 交互界面（无串口日志）
   ```
   用方向键选择并按回车；**无人值守可不按键**，超时自动进 4 轮验收。

> 提示：菜单版 ISO 是 **UEFI 专用**（不含 Legacy/软盘模拟）；现代 EPYC/Xeon 服务器
> 默认 UEFI，BMC 虚拟介质直接可用。

### 4.3 编排器跑 SOL 抓日志（在 Windows 编排机上）

```powershell
# 原格式（通用）
.\scripts\Run-MemtestSuite.ps1 -BatchName <批次> -BootMethod SOL `
  -BmcHost <BMC_IP> -BmcUser <用户> -MaxPasses <N> -ConfirmSwitch
# 👉 本机版（复制即用，密码运行中提示）
.\scripts\Run-MemtestSuite.ps1 -BatchName srv01-a1 -BootMethod SOL `
  -BmcHost 10.0.0.10 -BmcUser root -MaxPasses 4 -ConfirmSwitch
```

- `-MaxPasses` 与你在开机菜单里选的轮数**保持一致**（编排器用它算超时上限，并期望
  收到对应轮数的 `ev=done`）。
- 可选附加：`-MonitorEcc -MonitorTemp -RestartLoop 2`（ECC/温度监控、测完断电循环）。

### 4.4 看报告

- 单批逐根报告：`results\reports\<批次>-report.csv`
- 累计总表：`results\master_manifest.csv`
- 判读：收到 `ev=done passes=N status=pass` 且 `Errors=0` → **PASS**；有错误明细
  （`ev=data addr=...`）→ FAIL，按失败件流程单根隔离复测。

## 5. 预设与改轮数

默认预设（`config\memtest-presets.conf`）：

| 预设 | 引导参数 | 用途 |
| --- | --- | --- |
| 4轮验收（默认） | `log=ttyS0,115200 maxpasses=4` | 完整验收 |
| 2轮 | `log=ttyS0,115200 maxpasses=2` | 折中/复测 |
| 1轮快速筛选 | `log=ttyS0,115200 maxpasses=1 testlist=0,1,2,3,4,5,6,7,8` | 批量快速筛错 |
| 交互界面 | `nomch`（无串口日志） | 有人值守调试 |

**改轮数/增删预设**（例如把 2 轮改成 3 轮）：

1. 编辑 `config\memtest-presets.conf`：
   ```
   preset.2轮.cmdline=log=ttyS0,115200 maxpasses=3
   ```
2. 重跑工具（几秒，离线可用）：
   ```powershell
   .\scripts\New-MemtestSolIso.ps1
   ```
3. 把新 `memtest\boot\memtest-sol.iso` 重新挂到 BMC 虚拟介质。

> 也可以不重制：引导时在 GRUB 菜单直接选预设即可（已内置 4/2/1/交互四种）。

## 6. 场景建议

| 场景 | 做法 |
| --- | --- |
| 批量 1000 根全检 | 1 轮快速筛选预设 + `Run-BatchScheduler.ps1` 逐批跑（见 05 手册） |
| 单批完整验收 | 4 轮预设 + `Run-MemtestSuite` 4 轮 |
| 失败件升级深测 | 换 2/4 轮预设单独复测该根 |
| 有人值守/界面调参 | 交互预设（界面按 F1 配置） |
| 无人值守连轴转 | 默认 4 轮预设，菜单超时自动进，测完自动重启回系统 |

## 7. 常见问题

| 现象 | 处理 |
| --- | --- |
| 服务器不出现菜单/不进 ISO | 确认 UEFI 引导、虚拟介质一次性引导设置、ISO 是 `memtest-sol.iso` |
| QEMU 冒烟报错 | `-Smoke` 需要 QEMU（构建机可选自检，离线包不含）；如需用，先 `-DownloadQemu`（约 1.2GB）或把 `tools\qemu` 拷入；`-accel whpx` 不可用自动回退 tcg |
| 冒烟提示缺 `ev=spd` 但已通过 | 属正常：QEMU 无 SPD 数据，spd 为可选事件（必需事件 start/pass_end/done） |
| 重制时提示缺 GRUB | 离线包已内置 `tools\grub`，确认该目录存在（含 `bin\grub-mkimage.exe`）；确缺失且可联网才跑 `-DownloadGrub` |
| 重制提示缺 Python | 构建机需 Python 3（`Get-PythonExe` 自动探测） |
| 编排器超时收不到 `ev=done` | 核对菜单预设轮数与 `-MaxPasses`；SOL/串口链路见 09 指南第 7 节 |
