## 任务 1：lib_common.ps1 新增 Write-CmdLog

**位置**：`scripts/lib_common.ps1` 末尾追加。

```powershell
# 指令记录（cmdlog）：把本项目每次脚本调用记入 <包根>\results\cmdlog\commands-YYYY-MM-DD.csv。
# 常开、CSV、按日期滚动；敏感参数（-BmcPass/-P 密码）自动打码为 ***。
# 注意：参数名用 $CmdArgs（$Args 是 PowerShell 保留自动变量，声明同名参数会绑定失效）。
function Write-CmdLog {
    param(
        [string]$Script,
        [string]$CmdArgs = '',
        [string]$State = 'Start',
        [string]$Result = '',
        [int]$ExitCode = 0,
        [double]$DurationSec = 0
    )
    $masked = $CmdArgs
    foreach ($re in @(
        '(-BmcPass\s+)(\S+)',
        '(-BmcPass=)(\S+)',
        '(-P\s+)(\S+)',
        '(-P=)(\S+)'
    )) {
        $masked = $masked -replace $re, ('${1}' + '***')
    }
    $row = [PSCustomObject]@{
        Timestamp    = (Get-Date -Format 'yyyy-MM-dd HH:mm:ss')
        Machine      = $env:COMPUTERNAME
        Dir          = (Get-Location).Path
        Script       = $Script
        Args         = $masked
        State        = $State
        Result       = $Result
        ExitCode     = $ExitCode
        DurationSec  = $DurationSec
    }
    $logDir = Join-Path (Split-Path $PSScriptRoot -Parent) 'results\cmdlog'
    if (-not (Test-Path -LiteralPath $logDir)) { New-Item -ItemType Directory -Path $logDir -Force | Out-Null }
    $file = Join-Path $logDir ("commands-{0:yyyy-MM-dd}.csv" -f (Get-Date))
    if (-not (Test-Path -LiteralPath $file)) {
        $row | Export-Csv -LiteralPath $file -NoTypeInformation -Encoding UTF8
    } else {
        $row | ConvertTo-Csv -NoTypeInformation | Select-Object -Skip 1 | Add-Content -LiteralPath $file -Encoding UTF8
    }
}
```

要点：包根 = `Split-Path $PSScriptRoot -Parent`（lib_common 在 scripts/，父目录即包根）；
首次写 header（Export-Csv），之后 `ConvertTo-Csv | Skip 1 | Add-Content` 追加且不重复 header。

**验证**：`powershell -NoProfile -Command ". scripts\lib_common.ps1; Write-CmdLog -Script t1 -Args '-BmcPass secret -P pwd' -State End -Result OK; Get-Content 'results\cmdlog\commands-<今天>.csv'"` 输出含 `***` 且无明文。

## 任务 2：7 个脚本接入 Start/End

每个脚本（UTF-8 with BOM 保持）：
- **Start**：在 `-Help` 处理后、主流程开始处插入：
  ```powershell
  $scriptStartTime = Get-Date
  Write-CmdLog -Script '<脚本名>' -Args $MyInvocation.Line -State Start
  ```
- **End**：在成功结束与每个 `exit` 分支前插入：
  ```powershell
  Write-CmdLog -Script '<脚本名>' -State End -Result '<OK|FAIL: 原因|超时>' -ExitCode <码> -DurationSec ((Get-Date) - $scriptStartTime).TotalSeconds
  ```
- 各脚本名与接入点：
  | 脚本 | Start 位置 | End 位置（现有 exit/结束点） |
  | --- | --- | --- |
  | Run-MemtestSuite.ps1 | 配置化读取之后（约 125 行后） | 主流程结束 + 各 exit（失败/超时/校验失败）前 |
  | Diag-Bmc.ps1 | Help 后、密码提示前 | 结尾 + 失败 exit 前 |
  | check_env.ps1 | 开头 param 后 | 结尾（全部 OK / 有失败） |
  | Run-ServerAssessment.ps1 | Help 后、密码提示前 | 结尾 |
  | New-MemtestSolIso.ps1 | Help 后 | 结尾 + 各 exit |
  | build.ps1 | 开头 | 结尾 + 各 exit（打包失败等） |
  | Identify-Memory.ps1 | 开头 | 结尾 |
- Result 摘要遵循脚本自身既有输出语义（如 check_env 的"全部 OK"、Run-MemtestSuite 的 PASS/FAIL/超时）。

**验证**：逐个脚本 `Parser::ParseFile` 语法 0 错误；抽查 2 个脚本试跑（如 `check_env.ps1`、`Run-MemtestSuite.ps1 -Help`）确认 cmdlog 目录出现 `commands-<今天>.csv`。

## 任务 3：Start/Stop-CommandLog.ps1

```powershell
# scripts/Start-CommandLog.ps1
$logDir = Join-Path (Split-Path $PSScriptRoot -Parent) 'results\cmdlog'
if (-not (Test-Path $logDir)) { New-Item -ItemType Directory -Path $logDir -Force | Out-Null }
$logFile = Join-Path $logDir ("{0:yyyy-MM-dd}_{0:HHmmss}.log" -f (Get-Date))
Start-Transcript -Path $logFile -Append
Write-Host "会话转录已开启：$logFile"
```
```powershell
# scripts/Stop-CommandLog.ps1
Stop-Transcript
Write-Host "会话转录已停止"
```
（两脚本 UTF-8 with BOM。）

## 任务 4：tests/test-cmdlog.ps1

```powershell
# ============================================================================
# test-cmdlog.ps1 — Write-CmdLog 指令记录回归测试
# 覆盖规格 5 个用例：写入建文件字段齐全 / 追加不重复 header / 密码打码 /
#   按日期滚动命名 / 目录自动创建。
# 用法：powershell -NoProfile -ExecutionPolicy Bypass -File tests\test-cmdlog.ps1
# ============================================================================
. "$PSScriptRoot\..\scripts\lib_common.ps1"
function Assert($cond, $msg) { if (-not $cond) { throw "ASSERT FAIL: $msg" } }
$logDir = Join-Path (Split-Path (Split-Path $PSScriptRoot -Parent) -Parent) 'results\cmdlog'
# 清掉测试文件避免污染
$f = Join-Path $logDir ("commands-{0:yyyy-MM-dd}.csv" -f (Get-Date))
Remove-Item -LiteralPath $f -Force -ErrorAction SilentlyContinue
# 1 写入 → 建文件、字段齐全
Write-CmdLog -Script test -Args '-BmcHost 10.0.0.10' -State Start
Assert (Test-Path -LiteralPath $f) "1 文件已创建"
$rows = Import-Csv -LiteralPath $f
Assert ($rows.Count -eq 1) "1b 首行"
Assert ($rows[0].Script -eq 'test' -and $rows[0].State -eq 'Start') "1c 字段"
# 2 追加不重复 header
Write-CmdLog -Script test -Args '-BmcHost 10.0.0.10' -State End -Result OK
$lines = Get-Content -LiteralPath $f
Assert ($lines[0] -like 'Timestamp*') "2a 首行仍 header"
Assert ((Import-Csv -LiteralPath $f).Count -eq 2) "2b 2 行数据"
# 3 密码打码
Write-CmdLog -Script test -Args '-BmcPass secret -BmcPass=sec2 -P p1 -P=p2' -State Start
$txt = Get-Content -LiteralPath $f -Raw
Assert (-not ($txt -match 'secret|sec2|\bp1\b|\bp2\b')) "3 密码已打码"
Assert (($txt -split '***').Count -ge 5) "3b 有 4 处 ***"
# 4 日期命名
Assert ($f -match 'commands-\d{4}-\d{2}-\d{2}\.csv$') "4 按日期滚动命名"
# 5 目录自动创建（先删目录再写）
Remove-Item -LiteralPath $logDir -Recurse -Force -ErrorAction SilentlyContinue
Write-CmdLog -Script test -State Start
Assert (Test-Path -LiteralPath $logDir) "5 目录自动创建"
Write-Host "ALL PASS"
```
