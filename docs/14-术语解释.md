## 1. 能力评估四类状态（服务器能测哪些）

> 来自 `Run-ServerAssessment.ps1` 输出，对应 17 项验收里的每一项。

| 状态 | 含义 | 需要做什么 | 要买硬件吗 |
| --- | --- | --- | --- |
| **可测** | 探测已确认能力具备 | 直接开测 | 否 |
| **需条件** | 缺的是"条件"而非硬件（如插满 ≥2 根、ECC 平台） | 补齐条件再测 | 通常否 |
| **需补（探测）** | 本次探测**没测出结果**（超时/未通/没读到），结果未知 | **重测 / 改配置确认**，别急着买硬件 | 一般不用 |
| **外包** | 确实需要专业设备（示波器/试验箱/静电枪等），服务器无此能力 | 抽 1–3 根样件送第三方实验室 | 是（但外包，不自己买） |

**常见疑问："
需补"是要我买硬件吗？**
不是。它表示探测没确认，通常是**配置问题**（如 BMC 未开 SOL、账号权限不够）或网络不通，重测即可转"可测"。只有重测仍不行且确实缺该能力（老型号无传感器/无断电控制）才涉及硬件。

## 2. 执行分层：L1 全量 / L2 抽样 / L3 外包

| 层 | 含义 | 对应测试项 | 规模 |
| --- | --- | --- | --- |
| **L1 全量** | 服务器软件即可完成，每根内存必测 | 1 SPD、2 识别、3 Memtest、16 混插、17 目检 | 1000 根全做 |
| **L2 抽样** | 需特定硬件但服务器已具备，按批次抽样 | 4 ECC、5 ORT、10 断电循环、15 多平台 | 每批抽 N 根 |
| **L3 外包** | 需专业设备/实验室，工程样件送检 | 6–9、11–14 | 每来源类别 1–3 根 |

> 行业惯例：破坏性/实验室项从不对整批全做；全检底线由 L1 保证（每根都过）。

## 3. 硬件与协议

| 术语 | 解释 |
| --- | --- |
| **BMC** | 服务器主板上独立的"管理小电脑"，自带网口/供电，主机断电也活着，负责远程管理 |
| **IPMI** | 管理软件与 BMC 通信的标准化协议（走网络端口 623） |
| **SOL（Serial over LAN）** | 把服务器串口输出通过网络转发出来，远程抓 Memtest86+ 日志的通道 |
| **带内（in-band）** | 服务器**进了操作系统**之后，通过系统（CIM/WMI）读信息 |
| **带外（out-of-band）** | 不依赖操作系统，通过 BMC/IPMI 直接管理（即使系统崩溃也可用） |
| **串口重定向（Console Redirection）** | BIOS 把串口控制台转到 BMC/SOL 的设置；波特率需统一 115200 |
| **管理网口** | BMC 独立的管理网口，与业务网口是两套；SOL 只走管理网 |

## 4. 测试工具与产物

| 术语 | 解释 |
| --- | --- |
| **Memtest86+** | 开源内存诊断工具，UEFI 独立引导，绕开操作系统测几乎全部物理内存（本项目的测试引擎） |
| **MTLOG** | Memtest86+ 输出给串口的机器可解析日志（`ev=start/pass/done...`），脚本据此自动判定 |
| **文本报告** | Memtest86+ 保存到 USB 的人类可读报告（`Final Result: PASS` 等） |
| **轮次（Pass）** | 完整跑一遍全部测试项算 1 轮；验收标准 = 4 轮 0 错误 |
| **快速筛选轮** | 只跑 1 轮用于批量快速筛错，失败件才升级深测 |
| **PASS / FAIL / INCOMPLETE** | 通过（0 错误）/ 失败（有错误）/ 未完成（中断/超时） |
| **SPD** | 内存条上的出厂信息芯片（容量/频率/时序/序列号），脚本读取用于识别建档 |
| **XMP 3.0 / EXPO** | DDR5 的超频预设配置（Intel/AMD），验收按标称频率开启 |
| **ECC / ODECC** | ECC=系统级纠错（需 ECC 平台）；ODECC=DDR5 颗粒内部单比特纠错（不等于系统 ECC） |
| **报告三件套** | `report.csv`（逐根明细）/ `summary`（汇总）/ `master_manifest.csv`（累计数据库） |

## 5. 专业测试项（外包 8 项，一句话速记）

| 项 | 是什么 | 为什么外包 |
| --- | --- | --- |
| **电压裕量** | 找 VDD/VDDQ 的稳定边界（Vmin/Vmax） | 需可编程电源 + 示波器 |
| **时序/SI** | 眼图高度/宽度、信号完整性 margin | 需 ≥20GHz 示波器 |
| **高低温循环** | 温循应力下焊点/封装可靠性 | 需高低温试验箱 |
| **THB（湿热偏压）** | 高温高湿 + 偏压加速，查防潮/腐蚀 | 需恒温恒湿箱 |
| **ESD** | 静电抗扰能力 | 需静电枪 |
| **机械振动** | 运输/使用振动疲劳 | 需振动台 |
| **机械冲击** | 抗冲击能力 | 需冲击台 |
| **弯曲扭曲** | PCB 受力应力 | 需治具 + 力传感器 |

## 6. 工程与流程

| 术语 | 解释 |
| --- | --- |
| **批次（Batch）** | 一次"插满槽位 → 测一轮 → 出报告"的完整流程 |
| **智能识别** | 脚本自动读 SPD（序列号/容量/频率）+ 比对预期清单，自动分类正常/待复核 |
| **混合路由** | 按条子状态差异化测试深度（正常件快速筛选、可疑件深测），但每根都测=100% 全检 |
| **预期清单 / 防调包** | 用厂商序列号清单自动匹配，容量/型号不符自动打标 |
| **断点续测** | 日志与解析分离，中断后可 `-ParseOnly` 续解析，不白跑 |
| **幂等** | 同一操作重复执行结果一致（如重复构建 CHECKSUM 不变、重复导入数据不重复） |

## 7. 一图速览：一条内存条的验收路径

```
接入服务器 → 智能识别建档（1/2）→ 能力评估（能测哪些）→ SOL 全自动 4 轮（3/4/16）
→ 判定 PASS/FAIL → 逐根入库（master_manifest）→ 抽样 L2（5/10/15）→ 外包 L3（8 项）送检
```
