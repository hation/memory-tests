# 05 · 使用手册

> 本手册覆盖三个编排脚本的全部参数、命令示例与输出。脚本与本文档同目录（项目根 `scripts/` 或离线包 `scripts/`）。

## 1. 脚本总览

| 脚本 | 功能 | 参数数 |
| --- | --- | --- |
| `Run-MemtestSuite.ps1` | 单批编排：引导 Memtest86+（SOL/Serial/USB/EFI）+ 抓日志 + 解析 + 汇总报告 | 22 个参数 |
| `Run-BatchScheduler.ps1` | 批量调度：读批次清单 CSV，逐批调用编排脚本，汇总全量报告 | 6 个参数 |
| `Identify-Memory.ps1` | 智能识别建档：读槽位内存 SPD 信息 + 预期清单匹配 + 分类 | 2 个参数 |

> 脚本默认输出到 `<脚本所在目录>\memory_results\`，可用 `-LogPath` 重定向（批量建议统一指到 `output\`）。

---

## 2. Run-MemtestSuite.ps1 参数说明

```powershell
.\Run-MemtestSuite.ps1 [-BatchName] [-BootMethod] [-BmcHost] [-BmcUser] [-BmcPass] [-IpmiTool]
  [-SerialPort] [-BaudRate] [-UsbDrive] [-UsbReportPrefix] [-EfiImage] [-EfiBootId]
  [-MaxPasses] [-TestList] [-SerialParam] [-ExpectedCsv] [-MonitorEcc] [-MonitorTemp]
  [-RestartLoop] [-LogPath] [-ParseOnly] [-LogFile] [-ConfirmSwitch] [-Help]
```

### 2.1 通用参数

| 参数 | 类型/默认 | 说明 |
| --- | --- | --- |
| `-BatchName` | string，默认时间戳 | 批次名，用于文件名与归集 |
| `-BootMethod` | SOL \| USB \| EFI \| Serial，默认 SOL | 引导与取日志方式 |
| `-MaxPasses` | int，默认 4 | Memtest86+ 跑几轮（4 轮 = 验收标准） |
| `-TestList` | string，默认空=全部 | 只跑指定测试，如 `"0,1,2,3"`；空 = 全 13 项 |
| `-ExpectedCsv` | string，默认空 | 预期清单 CSV（含 SerialNumber 列），自动匹配防调包 |
| `-LogPath` | string，默认 `<脚本目录>\memory_results` | 输出目录 |
| `-ParseOnly` | switch | 只解析已有日志，不执行引导（断点续测/复核） |
| `-LogFile` | string | ParseOnly 模式：待解析的原始日志/报告文件路径 |
| `-ConfirmSwitch` | switch | 涉及重启/切换引导时需显式确认（防误操作） |
| `-Help` | switch | 打印帮助 |

### 2.2 SOL 方式参数（全自动，推荐）

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `-BmcHost` | 空 | BMC 管理 IP |
| `-BmcUser` / `-BmcPass` | 空 | BMC 账号（需 Operator/Admin 权限） |
| `-IpmiTool` | `ipmitool` | ipmitool 路径（PATH 或完整路径） |
| `-MonitorEcc` | off | 采集 WHEA 内存错误事件（Event ID 18/19/47） |
| `-MonitorTemp` | off | SOL 方式下 `sdr elist` 读取温度传感器 |
| `-RestartLoop` | 0 | 测完后 `chassis power cycle` 重启循环次数（批次切换） |

### 2.3 Serial 方式参数（物理串口线，完全离线）

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `-SerialPort` | `COM1` | Windows 串口端口（设备管理器确认） |
| `-BaudRate` | 115200 | 波特率，须与服务器端一致 |
| `-SerialParam` | `ttyS0,115200` | 传给 Memtest86+ 的串口参数 |

### 2.4 USB 方式参数（半自动）

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `-UsbDrive` | 空 | U 盘盘符（报告导出目录，如 `E:`） |
| `-UsbReportPrefix` | `MT86P_*` | 报告文件前缀（Memtest86+ 保存为 MT86P_NN.TXT） |

### 2.5 EFI 方式参数（一次性引导）

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `-EfiImage` | 空 | mt86plus.efi 路径 |
| `-EfiBootId` | `memtest86plus` | 临时引导项描述 |

### 2.6 命令示例

```powershell
# SOL 全自动（4 轮验收 + ECC/温度监控）
.\Run-MemtestSuite.ps1 -BatchName batch01 -BootMethod SOL `
  -BmcHost 192.168.1.10 -BmcUser admin -BmcPass pwd -MaxPasses 4 -ConfirmSwitch

# Serial 离线（物理串口线）
.\Run-MemtestSuite.ps1 -BatchName batch01 -BootMethod Serial -SerialPort COM3 -BaudRate 115200 -MaxPasses 4

# USB 半自动
.\Run-MemtestSuite.ps1 -BatchName batch01 -BootMethod USB -UsbDrive E: -MaxPasses 4

# 只解析已有日志
.\Run-MemtestSuite.ps1 -ParseOnly -LogFile .\memory_results\raw\batch01.mtlog.txt

# 快速筛选（1 轮，前 9 项测试）
.\Run-MemtestSuite.ps1 -BootMethod SOL ... -MaxPasses 1 -TestList "0,1,2,3,4,5,6,7,8"
```

## 3. Run-BatchScheduler.ps1 参数说明

```powershell
.\Run-BatchScheduler.ps1 -ManifestCsv <批次清单.csv> [-SuiteScript] [-LogPath] [-DryRun] [-ContinueOnError] [-Help]
```

| 参数 | 说明 |
| --- | --- |
| `-ManifestCsv` | 批次清单 CSV（必填） |
| `-SuiteScript` | Run-MemtestSuite.ps1 路径（默认同目录） |
| `-LogPath` | 输出目录（默认 `.\memory_results\`，清单行内 LogPath 可覆盖） |
| `-DryRun` | 只打印将执行的命令，不真正运行 |
| `-ContinueOnError` | 某批失败继续下一批（默认遇错停止） |
| `-Help` | 打印帮助 |

### 批次清单 CSV 列（17 列，顺序固定）

```text
BatchName, BootMethod, BmcHost, BmcUser, BmcPass, UsbDrive, EfiImage,
SerialPort, BaudRate, MaxPasses, TestList, ExpectedCsv,
MonitorEcc(yes), MonitorTemp(yes), RestartLoop, ConfirmSwitch(yes), LogPath
```

> 注意：`TestList` 含逗号时必须在 CSV 里用引号包裹（如 `"0,1,2,3"`）。模板见 `config\batches.example.csv`。

## 4. Identify-Memory.ps1 参数说明

```powershell
.\Identify-Memory.ps1 [-ExpectedCsv] [-BatchName]
```

| 参数 | 说明 |
| --- | --- |
| `-ExpectedCsv` | 预期清单 CSV（含 SerialNumber 列，可加 Capacity 列校验容量） |
| `-BatchName` | 批次名（默认按时间戳） |

> 输出 `<批次>.csv`，识别字段与分类规则见 [08-报表结构说明.md](08-报表结构说明.md)。

---

## 5. 退出码约定

| 退出码 | 含义 |
| --- | --- |
| 0 | 正常完成（含 Help / DryRun / 通过） |
| 1 | 参数错误、清单缺失、脚本缺失、全部解析失败 |
| 2 | 单批执行失败（调度器可据此决定是否继续） |
