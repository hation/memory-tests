# 05 · 使用手册

> 状态：[当前有效]（2026-10-22）
> 变更记录：2026-10-22 文档体系编号化（对齐 disk-tests）；工程基建优化更新

> 本手册覆盖三个编排脚本的全部参数、命令示例与输出。脚本与本文档同目录（项目根 `scripts/` 或离线包 `scripts/`）。

## 1. 脚本总览

| 脚本 | 功能 | 参数数 |
| --- | --- | --- |
| `scripts\Run-MemtestSuite.ps1` | 单批编排：引导 Memtest86+（SOL/Serial/USB/EFI）+ 抓日志 + 解析 + 汇总报告 | 22 个参数 |
| `scripts\Run-BatchScheduler.ps1` | 批量调度：读批次清单 CSV，逐批调用编排脚本，汇总全量报告 | 6 个参数 |
| `scripts\Identify-Memory.ps1` | 智能识别建档：读槽位内存 SPD 信息 + 预期清单匹配 + 分类 | 2 个参数 |

> 脚本默认输出到 `<脚本所在目录>\memory_results\`，可用 `-LogPath` 重定向（批量建议统一指到 `output\`）。

## 2. Run-MemtestSuite.ps1 参数说明

```powershell
.\scripts\Run-MemtestSuite.ps1 [-BatchName] [-BootMethod] [-BmcHost] [-BmcUser] [-BmcPass] [-IpmiTool]
  [-SerialPort] [-BaudRate] [-UsbDrive] [-UsbReportPrefix] [-EfiImage] [-EfiBootId]
  [-MaxPasses] [-TestList] [-SerialParam] [-ExpectedCsv] [-MonitorEcc] [-MonitorTemp]
  [-RestartLoop] [-LogPath] [-ParseOnly] [-LogFile] [-ConfirmSwitch] [-Help]
```

### 2.1 通用参数

| 参数 | 类型/默认 | 说明 |
| --- | --- | --- |
| `-BatchName` | string，默认时间戳 | 批次名，用于文件名与归集 |
| `-BootMethod` | SOL \| USB \| EFI \| Serial，默认 SOL | 引导与取日志方式 |
| `-MaxPasses` | int，默认 4 | Memtest86+ 跑几轮（4 轮 = 验收标准） |
| `-TestList` | string，默认空=全部 | 只跑指定测试，如 `"0,1,2,3"`；空 = 全 13 项 |
| `-ExpectedCsv` | string，默认空 | 预期清单 CSV（含 SerialNumber 列），自动匹配防调包 |
| `-LogPath` | string，默认 `<脚本目录>\memory_results` | 输出目录 |
| `-ParseOnly` | switch | 只解析已有日志，不执行引导（断点续测/复核） |
| `-LogFile` | string | ParseOnly 模式：待解析的原始日志/报告文件路径 |
| `-ConfirmSwitch` | switch | 涉及重启/切换引导时需显式确认（防误操作） |
| `-Help` | switch | 打印帮助 |

### 2.2 SOL 方式参数（全自动，推荐）

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `-BmcHost` | 空 | BMC 管理 IP |
| `-BmcUser` / `-BmcPass` | 空 | BMC 账号（需 Operator/Admin 权限） |
| `-IpmiTool` | `ipmitool` | ipmitool 路径（PATH 或完整路径） |
| `-MonitorEcc` | off | 采集 WHEA 内存错误事件（Event ID 18/19/47） |
| `-MonitorTemp` | off | SOL 方式下 `sdr elist` 读取温度传感器 |
| `-RestartLoop` | 0 | 测完后 `chassis power cycle` 重启循环次数（批次切换） |

### 2.3 Serial 方式参数（物理串口线，完全离线）

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `-SerialPort` | `COM1` | Windows 串口端口（设备管理器确认） |
| `-BaudRate` | 115200 | 波特率，须与服务器端一致 |
| `-SerialParam` | `ttyS0,115200` | 传给 Memtest86+ 的串口参数 |

### 2.4 USB 方式参数（半自动）

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `-UsbDrive` | 空 | U 盘盘符（报告导出目录，如 `E:`） |
| `-UsbReportPrefix` | `MT86P_*` | 报告文件前缀（Memtest86+ 保存为 MT86P_NN.TXT） |

### 2.5 EFI 方式参数（一次性引导）

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `-EfiImage` | 空 | mt86plus.efi 路径 |
| `-EfiBootId` | `memtest86plus` | 临时引导项描述 |

### 2.6 命令示例

```powershell
# SOL 全自动（4 轮验收 + ECC/温度监控）
.\scripts\Run-MemtestSuite.ps1 -BatchName batch01 -BootMethod SOL `
  -BmcHost 192.168.1.10 -BmcUser admin -BmcPass pwd -MaxPasses 4 -ConfirmSwitch

# Serial 离线（物理串口线）
.\scripts\Run-MemtestSuite.ps1 -BatchName batch01 -BootMethod Serial -SerialPort COM3 -BaudRate 115200 -MaxPasses 4

# USB 半自动
.\scripts\Run-MemtestSuite.ps1 -BatchName batch01 -BootMethod USB -UsbDrive E: -MaxPasses 4

# 只解析已有日志
.\scripts\Run-MemtestSuite.ps1 -ParseOnly -LogFile .\memory_results\raw\batch01.mtlog.txt

# 快速筛选（1 轮，前 9 项测试）
.\scripts\Run-MemtestSuite.ps1 -BootMethod SOL ... -MaxPasses 1 -TestList "0,1,2,3,4,5,6,7,8"
```

## 3. Run-BatchScheduler.ps1 参数说明

```powershell
.\scripts\Run-BatchScheduler.ps1 -ManifestCsv <批次清单.csv> [-SuiteScript] [-LogPath] [-DryRun] [-ContinueOnError] [-Help]
```

| 参数 | 说明 |
| --- | --- |
| `-ManifestCsv` | 批次清单 CSV（必填） |
| `-SuiteScript` | Run-MemtestSuite.ps1 路径（默认同目录） |
| `-LogPath` | 输出目录（默认 `.\memory_results\`，清单行内 LogPath 可覆盖） |
| `-DryRun` | 只打印将执行的命令，不真正运行 |
| `-ContinueOnError` | 某批失败继续下一批（默认遇错停止） |
| `-Help` | 打印帮助 |

### 批次清单 CSV 列（17 列，顺序固定）

```text
BatchName, BootMethod, BmcHost, BmcUser, BmcPass, UsbDrive, EfiImage,
SerialPort, BaudRate, MaxPasses, TestList, ExpectedCsv,
MonitorEcc(yes), MonitorTemp(yes), RestartLoop, ConfirmSwitch(yes), LogPath
```

> 注意：`TestList` 含逗号时必须在 CSV 里用引号包裹（如 `"0,1,2,3"`）。模板见 `config\batches.example.csv`。

## 5. 退出码约定

| 退出码 | 含义 |
| --- | --- |
| 0 | 正常完成（含 Help / DryRun / 通过） |
| 1 | 参数错误、清单缺失、脚本缺失、全部解析失败 |
| 2 | 单批执行失败（调度器可据此决定是否继续） |

## 6. 共享库 lib_common.ps1

三个脚本（`Run-MemtestSuite.ps1` / `Run-BatchScheduler.ps1` / `Identify-Memory.ps1`）都在 param 之后 dot-source 加载共享库（`. $PSScriptRoot\lib_common.ps1`）。识别、解析、版本、事件、日志等公共逻辑统一入库，业务脚本不再重复实现；lib_common.ps1 只提供可复用函数，不含任何业务主流程逻辑。

| 函数 | 职责 |
| --- | --- |
| `Get-MemoryInventory` | 识别本机内存条并匹配预期清单 |
| `Invoke-MtlogParser` | 解析 MTLOG 串口日志 |
| `Invoke-TextReportParser` | 解析 USB 导出文本报告 |
| `Read-CsvManifest` | 健壮 CSV 读取（.NET TextFieldParser，保留行尾空字段） |
| `Write-Event` | 向 stdout 输出一行 JSON 事件 |
| `Write-Log` | 时间戳日志输出 `[HH:mm:ss] LEVEL msg` |
| `ConvertTo-CsvField` | CSV 字段转义（含逗号/引号/换行加引号） |
| `Get-AppVersion` | 读取 VERSION（缺失回退 v0-dev） |
| `Confirm-Targets` | 打印目标清单并要求 y 确认 |
| `Get-StageDone` / `Set-StageDone` | `.done` 阶段标记读写 |
| `Wait-Slot` | 并发槽位信号量（骨架） |
| `Get-SystemEvents` | WHEA 内存相关系统事件（近 `HoursBack` 小时） |

## 7. 单源构建 build.ps1

从源码一键同步/生成离线包（默认同步到 `SOL内存测试离线包\`，幂等：连续两次构建 `CHECKSUM.txt` 逐字节一致）。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\build.ps1                  # 默认同步 SOL内存测试离线包
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\build.ps1 -KitDir <dir>    # 指定输出目录
```

- **同步范围**：scripts（含 lib_common.ps1）/ docs（顶层 11 份）/ db / boot / config / tools / VERSION / CHECKSUM.txt / README 版本行。
- **产物**：`VERSION`（= 根 VERSION）、`CHECKSUM.txt`（SHA256 校验清单，固定行序）、`README.md` 首行版本行（`> 工具版本：v1`）。

## 8. VERSION 单一来源

- 根目录 `VERSION` 文件是版本唯一来源（当前 `v1`）。
- `Get-AppVersion` 读取 `VERSION`（缺失回退 `v0-dev`），build.ps1 也以此为版本注入离线包。
- 汇总报表含 `ToolVersion` 列，逐行记录测试所用工具版本，可追溯。

## 9. JSON 事件流

主流程（`Run-MemtestSuite.ps1`）共 5 处 `Write-Event`，向 stdout 输出一行 JSON（`{"type":...,"data":{...}}`），供日志/GUI 等外部工具消费：

| type | data 关键字段 | 时机 |
| --- | --- | --- |
| `stage` | stage=orchestrator, status=start | 编排开始 |
| `entity` | stage=inventory, count | 识别完成 |
| `stage` | stage=capture, status=done | 捕获完成 |
| `stage` | stage=parse, status=done | 解析完成 |
| `done` | stage=report, file | 报告生成 |

## 10. 历史库（可选）

`db/` 目录提供 SQLite 历史库工具（需 Python 3）：

| 脚本 | 用途 |
| --- | --- |
| `db_import.py` | 导入报告 CSV 到历史库（幂等，重复导入不产生重复行） |
| `db_query.py` | 查询历史库（按 SN / 批次过滤，`--trend` 输出跨批次时序） |
| `db_export.py` | 导出历史库全量 CSV（utf-8-sig，Excel 可直接打开） |
| `db_merge.py` | 幂等合并两个库（按唯一键去重，写入 out） |

命令示例：

```powershell
python db\db_import.py .\output\batch01-report.csv --db history.db --machine rack01
python db\db_query.py --db history.db --serial <SN> --trend
python db\db_export.py --db history.db --out .\output\history-export.csv
python db\db_merge.py --db1 history.db --db2 other.db --out merged.db
```
