# 13 · 服务器信息识别指南

> 状态：[当前有效]（2026-10-22）
> 变更记录：2026-10-22 创建
> 目标读者：纯小白操作员。目标场景：拿到一台**不知道是什么厂商**的服务器，用它自己查出来厂商、型号、序列号。
> 阅读前提：不需要任何基础，照着下面一步步抄命令就行。

---

## 一句话总结

在服务器上打开 PowerShell，输入下面这一条命令，回车，就能看到厂商和型号：

```powershell
Get-CimInstance Win32_ComputerSystem | Select-Object Manufacturer, Model
```

---

## 一、先搞懂「厂商」是什么

**厂商 = 这台服务器是哪个牌子造的。**

常见的有：

| 中文叫法 | 英文/缩写 |
| --- | --- |
| 联想 | Lenovo |
| 戴尔 | Dell |
| 惠普 / 慧与 | HP / HPE |
| 浪潮 | Inspur |
| 华为 | Huawei |
| 超微（DIY 服务器常用） | Supermicro |

为什么要查厂商？
- **查保修**要用序列号（SN）；
- **装驱动 / 更新固件**要去对应厂商官网，按厂商+型号找；
- 服务器上内存槽、硬盘位的排布，不同厂商长得不一样。

---

## 二、Windows 服务器怎么查（最常用）

### 2.1 先打开 PowerShell（黑窗口）

1. 点击屏幕左下角「开始」按钮；
2. 输入 `powershell`（拼音的话可以输入拼音：`windows powershell`）；
3. 在搜索结果里，对 **Windows PowerShell** 点鼠标右键 → 选「**以管理员身份运行**」（推荐，有的命令需要权限）；
4. 弹出来的黑色窗口就是 PowerShell。

### 2.2 查厂商和型号（最常用的一条）

把下面这行**完整复制**进黑窗口，按回车：

```powershell
Get-CimInstance Win32_ComputerSystem | Select-Object Manufacturer, Model
```

看到的结果类似（举例）：

```
Manufacturer : LENOVO
Model        : 21SJ
```

- `Manufacturer` = 厂商（牌子）
- `Model` = 型号

### 2.3 查序列号（SN，查保修要用）

```powershell
Get-CimInstance Win32_BIOS | Select-Object Manufacturer, SMBIOSBIOSVersion, SerialNumber
```

- `SerialNumber` = 序列号，去厂商官网报这个号就能查保修/下载对应驱动。

### 2.4 老系统（Win7 / Windows Server 2012 及更老）用这条

如果上面命令报错「找不到 Get-CimInstance」，说明系统太老，改用旧命令：

```powershell
wmic csproduct get name, vendor, identifyingnumber
```

（`vendor` = 厂商，`name` = 型号，`identifyingnumber` = 序列号）

## 三、Linux 服务器怎么查

如果服务器装的是 Linux（而不是 Windows），在命令行里输入（需要 root 权限）：

```bash
dmidecode -t system | head -10
```

看到的结果类似：

```
Manufacturer: LENOVO
Product Name: 21SJ
Serial Number: PW0RQD3Q
```

---

## 四、服务器有 BMC/IPMI 管理口的话，网页里也能看

很多服务器（尤其联想、戴尔、浪潮）都带一个独立的**管理口（BMC）**——就是一串管理 IP，可以在浏览器里登录查看。

1. 用浏览器打开 BMC 的管理 IP（比如 `https://192.168.1.100`）；
2. 登录后，在「系统信息 / System Information」页面通常直接写着厂商、型号、序列号。

也可以用命令行查（本项目离线包 `tools\ipmitool\` 里已经带了 ipmitool 工具）：

```powershell
ipmitool -I lanplus -H <BMC的IP> -U <用户名> -P <密码> fru
```

（把 `<BMC的IP>`、`<用户名>`、`<密码>` 换成实际值）

## 五、怎么读懂查出来的结果（对照表）

| 查出来显示 | 实际是 |
| --- | --- |
| LENOVO / Lenovo | 联想 |
| Dell Inc. / DELL | 戴尔 |
| Hewlett-Packard / HP | 惠普 |
| HPE | 慧与（惠普企业） |
| Inspur | 浪潮 |
| Huawei | 华为 |
| Supermicro | 超微 |
| 其他主板厂名（如 Intel、技嘉、华硕） | 很可能是**组装机**，见下节 |

## 六、怎么判断是不是「白牌 / 组装机」

「组装机」= 不是整机厂商统一出品，而是用散件拼的（类似自己攒电脑）。判断方法：

1. 查厂商：
   ```powershell
   Get-CimInstance Win32_ComputerSystem | Select-Object Manufacturer, Model
   ```
2. 再查主板：
   ```powershell
   Get-CimInstance Win32_BaseBoard | Select-Object Manufacturer, Product
   ```
3. 对比：
   - 两个结果**厂商一致**（比如都是 LENOVO）→ 品牌整机，正常；
   - 整机厂商显示的是某块主板厂名（Intel、Supermicro、技嘉…），且没有明确型号 → 基本就是**组装机/白牌机**。

组装机不影响测内存，但**查保修、找驱动**就要按主板型号去对应主板厂官网找。

## 七、常见问题（小白排查）

| 现象 | 原因 / 怎么办 |
| --- | --- |
| 提示「不是内部或外部命令」 | 没在 PowerShell 里输入，或者输错了字。重新复制命令再试。 |
| 提示「找不到 Get-CimInstance」 | 系统太老，用 2.4 的 `wmic` 命令。 |
| 提示「拒绝访问 / Access denied」 | 权限不够，重开一个「以管理员身份运行」的 PowerShell。 |
| 命令输进去没反应 | 确认已经按了回车；看是不是黑窗口处于别的状态。 |
