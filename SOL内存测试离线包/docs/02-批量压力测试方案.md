## 1. 17 项测试总览矩阵

| # | 测试项 | 测试目的 | 行业标准/方法 | 关键设备 | 专业设备 | 执行层 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | SPD 信息校验 | 校验 SPD 内容合法、CRC 无误、参数正确 | JEDEC JESD79-5（DDR5）、SPD CRC 校验 | 软件（脚本/CPU-Z/HWiNFO） | — | L1 全量 |
| 2 | 基础识别/容量频率读取 | 容量、频率、厂商、序列号与标签一致，防调包 | SPD 解析（JESD21-C） | 软件（脚本/BIOS） | — | L1 全量 |
| 3 | 全地址读写覆盖（Memtest） | 地址线、存储单元、数据保持完整性 | Memtest86+ 全 13 项（walking ones / moving inversions / bit fade） | 软件（Memtest86+ v9） | — | L1 全量 |
| 4 | ECC 纠错功能验证 | 验证 ECC 条纠错/报错路径 | 系统级 ECC 平台 + mcelog/edac/WHEA 触发验证 | 你们的服务器（EPYC/Xeon）即 ECC 平台 | — | L2 抽样 |
| 5 | 72h 高压满载老化烧机（ORT） | 早期失效筛选，加速发现缺陷件 | 模块级 burn-in（加温+满载+加压）；行业做法：多平台 72h 标准压力 | 满载软件（TM5/Prime95/OCCT）+ 服务器 24h 运行 | —（软件近似） | L2 抽样 |
| 6 | 电压裕量测试（高低压边界） | 找出 VDD/VDDQ 工作边界（Vmin/Vmax） | 可编程电源 + 温度边界扫描；Intel 过冲/下冲规格 | 可编程电源 + 高速示波器 | ✅需（外包） | L3 外包 |
| 7 | 时序 margin / 信号完整性 | 眼图高度/宽度、mask 裕量、BER（1E-16） | JEDEC DDR5 眼图模板、写均衡、Vref 校准 | ≥20GHz 高速示波器（Tektronix 类）+ 眼图软件 | ✅需（外包） | L3 外包 |
| 8 | 高低温循环测试 | 温循应力下焊点/封装可靠性 | JEDEC JESD22-A104（TC） | 高低温试验箱 | ✅需（外包） | L3 外包 |
| 9 | 高温高湿偏压 THB | 湿热+偏压加速，评估防潮/腐蚀失效 | JEDEC JESD22-A101（85℃/85%RH+偏压，96–1000h） | 恒温恒湿试验箱 | ✅需（外包） | L3 外包 |
| 10 | 反复上电掉电重启循环 | 电源循环下初始化/训练稳定性 | 自动断电-上电循环 | 服务器 IPMI / 智能 PDU 远程断电 + 自动重启脚本 | — | L2 可自做 |
| 11 | 静电 ESD 抗扰 | 系统级/器件级抗 ESD 能力 | 系统级 IEC 61000-4-2；器件级 HBM JESD22-A114 / CDM JS-002 | 静电枪（ESD gun）/ ESD 测试台 | ✅需（外包） | L3 外包 |
| 12 | 机械振动测试 | 运输/使用振动疲劳 | JEDEC JESD22-B103（变频振动，如 3G / 5–500Hz） | 振动台 | ✅需（外包） | L3

**执行层定义**：
- **L1 全量**：本机/服务器软件即可完成，1000 根每根都做（结合智能识别脚本，自动建档分类）
- **L2 抽样**：需要特定硬件（ECC 平台、自动断电设备、多平台机型），按批次抽样做
- **L3 外包**：需专业试验设备/实验室（高低温箱、恒温恒湿箱、示波器、ESD 枪、振动/冲击台），按工程样件抽样，行业惯例**不做每根**
- **专业设备列**：标记 `✅需（外包）` 的项必须使用专业测试设备/实验室，现有服务器**无法完成**；标记 `—` 的项用现有服务器 + 软件即可自测

## 2. 分层执行策略（与 1000 根全检结合）

```
L1 全量（每根必测）: 1, 2, 3, 16, 17 ───── 复用现有智能识别脚本 + Memtest86+ 快速筛选轮
        │
L2 抽样（每批抽 N 根）: 4, 5, 10, 15 ───── 用现有服务器即可，抽检 + 失败件升级深测
        │
L3 外包（工程样件）: 6, 7, 8, 9, 11, 12, 13, 14 ── 破坏性/专业设备，每批送 1–3 根
```

> 行业事实：**破坏性/实验室项（L3）从来不对 1000 根全做**——它们属于工程样件可靠性验证（qualification），按批次抽件送检；全检的底线由 L1 五项保证（每根都过）。这与金士顿等厂商"全测 + 多平台 72h 抽样"的做法一致。

### 抽样数量建议（1000 根批量）
- L2 项：每 100 根抽 3–5 根（含失败件升级），覆盖来源类别
- L3 项：每批（或每来源类别）送 1–3 根做工程样件可靠性验证，一次送检覆盖所有 L3 项
- 破坏性测试（12/13/14）抽出的样件测完即报废，计入损耗

## 3. 各测试项执行细节

### L1 全量组（本机软件，复用现有工具）

**1. SPD 信息校验测试**
- 用 `scripts\Identify-Memory.ps1` 自动采集 SPD：序列号、型号、容量、频率、内存类型
- 校验：SPD CRC（脚本可扩展读取校验状态）；与标签/预期清单比对
- 判据：SPD 有效、无 CRC 错误、与标签一致 → 通过；否则标「待复核」

**2. 基础识别、容量频率读取测试**
- 核对 BIOS / CPU-Z / HWiNFO64 读取的容量与频率，与标签及预期清单一致
- 判据：容量、频率、厂商、序列号全对 → 通过（防调包核心手段）

**3. 全地址读写覆盖测试（Memtest）**
- Memtest86+ v9 全 13 项测试（地址 walking ones、移动反演、随机、bit fade 数据保持）
- 批量模式跑**快速筛选轮（1 轮）**；失败件升级多轮/过夜深测
- 判据：0 错误；记录错误地址与测试号

**16. 多通道混插压力测试**
- 装机验收时按实际混插组合（不同容量/品牌/频率混合、双通道/四通道）跑 Memtest86+ + TM5
- 判据：混插组合 0 错误；发现单根不稳 → 进入单根隔离排查

**17. 外观、焊点、镀金目视检测 + 电性复检**
- 目检：金手指镀金层是否氧化/划伤、板面元件（PMIC、SPD Hub、电阻电容）焊点是否虚焊/桥连、有无破损，参照 IPC-A-610
- 电性复检：万用表测关键引脚短路/开路，或模块测试机复测
- 判据：无镀金氧化、无虚焊桥连、电性正常

### L2 抽样组（用现有服务器即可完成）

**4. ECC 纠错功能验证**
- 你们的服务器（AMD EPYC / Intel Xeon）本身是 **ECC 平台**，无需另购硬件即可验证 ECC 功能
- 验证方式：Linux 下 `mcelog`/`edac-utils` 监控，Memtest86+ 加 `ecc` 参数开启 ECC 轮询；Windows 下看 WHEA 日志
- 判据：ECC 使能生效、能正常上报/纠错记录，无未纠正错误（UE）
- 注意：被测条子需为 ECC 条（服务器条通常自带），普通消费条无 ECC 可验证

**5. 72h 高压满载老化烧机（ORT）**
- 软件近似：服务器满载（TM5 + anta777 Extreme / Prime95 Blend / OCCT Memory 交替），加温环境（密闭机柜/加热舱位），加压运行 72h；服务器天然适合 24h 连续运行
- 行业标准：模块级 burn-in（边老化边测试），金士顿/英睿达类厂商对 DDR5 做多平台 72h 标准压力（含双/四通道）
- 判据：72h 内 0 错误、无重启/蓝屏；失败件淘汰

**10. 反复上电掉电重启循环测试**
- 服务器方案：用 **BMC/IPMI 远程电源控制**（`ipmitool chassis power cycle`）或**智能 PDU** 做自动断电-上电循环（如每 3 分钟一个循环），配合脚本在每次上电后自动跑 Memtest86+ 首轮或快速自检
- 判据：连续 ≥200 次循环全部正常初始化、无训练失败（DDR5 上电训练失败是常见失效点）

**15. 多平台主板兼容性测试**
- 用你们现有的 Intel 与 AMD 两类服务器各至少 1 台（若机型只有单一厂商，则只测一类，另一类需借机/外包）
- 每平台：识别 + 快速筛选轮 + 满载 2–4h；有条件按厂商惯例跑 72h
- 判据：所有平台识别正确、0 错误、无兼容性异常（QVL 之外的情况重点记录）

### L3 外包组（专业设备，工程样件抽样）

**6. 电压裕量测试（高低压边界）**
- 方法：对 VDD/VDDQ 做低压边界（Vmin）与高压边界（Vmax）扫描，结合温度边界（如 0℃ 与 85℃）确认稳定工作区间
- 设备：可编程电源 + 高速示波器，或专业模块测试机；消费主板仅能有限调压，精度不足
- 判据：在规格电压 ±裕量内功能与性能正常，对照 JEDEC DDR5 电源规格

**7. 时序 margin / 信号完整性测试**
- 方法：示波器抓取 DQ/DQS/命令/时钟眼图，对照 JEDEC DDR5 眼图 mask 模板判 Pass/Fail；测眼高、眼宽、裕量；关注 Vref 噪声（DDR5 Vref 纹波 > ±15mV 会显著压缩眼图裕量）
- 设备：≥20GHz 高速示波器（如 Tektronix DPO70000 系列）+ DDR5 协议/眼图分析软件
- 判据：眼图满足 JEDEC mask（BER 目标 1E-16），裕量达标

**8. 高低温循环测试**
- 方法：JESD22-A104 温度循环（如 -40℃↔85℃、每温区驻留 15–30 分钟），循环数按等级 100–1000 次
- 判据：循环后电性复测通过，无焊点开裂/参数漂移

**9. 高温高湿偏压 THB 测试**
- 方法：JESD22-A101，85℃ / 85%RH + 工作偏压，时长 96–1000h（加速湿热失效：腐蚀、漏电、PMIC 可靠性）
- 判据：偏压期间及结束后功能正常，漏电流不超标

**11. 静电 ESD 抗扰测试**
- 方法：系统级 IEC 61000-4-2（接触 ±4kV、空气 ±8kV 典型）；器件级 HBM JESD22-A114 / CDM JS-002
- 判据：测试后功能正常，无损伤（该测试具破坏性，抽坏即淘汰）

**12. 机械振动测试**
- 方法：JESD22-B103 变频振动（典型 3G、0.75mm 峰峰值、5–500Hz 扫描）
- 判据：振动后电性复测通过

**13. 机械冲击测试**
- 方法：JESD22-B110 机械冲击（如 1500G 半正弦脉冲）
- 判据：冲击后电性复测通过，无内部/焊点损伤

**14. 弯曲扭曲应力测试**
- 方法：板级弯曲/扭曲治具施加规定应力（模拟安装与受力），配合电性监测
- 判据：应力下及卸力后功能正常，无断裂/虚焊

### 7.2 开源替代要点

1. **第 5/15/16 项的负载工具换开源**（原方案 TM5/Prime95/OCCT 为 Windows 闭源，服务器多为 Linux 环境，换开源更顺）：
   - **stress-ng**（GPL，Ubuntu/Debian 自带）：`stress-ng --vm 0 --verify -t 72h` 跑满内存并校验，最接近 TM5 定位
   - **stressapptest**（Apache-2.0，Google 出品）：多线程随机读写 + I/O 交叉，适合 72h ORT
   - **memtester**（开源）：随机值 / 异或 / 算术运算快速校验
2. **SPD 与识别**：Linux 下用 **decode-dimms**（i2c-tools 包，DDR5 解码已逐步支持）+ **dmidecode**
3. **ECC 监控**：**mcelog / edac-utils / rasdaemon**（Linux 内核 EDAC 驱动，开源）
4. **断电循环**：**ipmitool**（开源）`ipmitool chassis power cycle`

### 7.3 无开源替代项（本质是硬件依赖）

第 6/7/8/9/11/12/13/14 项需要**测量级硬件设备**（可编程电源、≥20GHz 示波器、高低温箱、恒温恒湿箱、静电枪、振动/冲击台、弯曲治具），开源软件无替代品——开源 SI 仿真工具（PyBERT、SigTop）仅用于设计预研，不能对实物测量。这些项维持外包，见第 4 章设备清单。

### 7.4 第 6 项折中方案

若服务器 BIOS 允许调 VDD/VDDQ，可用 stress-ng 做负载，在低/高压边界各跑 1–2h 做**有限自测初筛**；精确判定仍外包。"初筛通过"可作外包送检的前置门槛，减少送检样件量。
