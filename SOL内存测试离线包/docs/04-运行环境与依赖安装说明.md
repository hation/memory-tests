# 04 · 运行环境与依赖安装说明

> 状态：[当前有效]（2026-10-22）
> 变更记录：2026-10-22 文档体系编号化（对齐 disk-tests）；工程基建优化更新

> 适用：Windows 编排机 + 被测服务器（SOL 全自动内存验收）。本文说明运行整套工具所需的全部前置环境与依赖，及版本自检方法。

## 1. 硬件 / 系统前置

| 项 | 要求 | 说明 |
| --- | --- | --- |
| 编排机系统 | Windows 10 / Windows Server 2016+ | 本工具全部在 Windows PowerShell 5.1 运行 |
| PowerShell | 5.1+（系统自带） | 首选 `powershell.exe`；兼容 `pwsh`（PS7） |
| 网络 | 编排机可 ping 通服务器 BMC 管理 IP | SOL 走 BMC 管理网口，端口 623；无需互联网 |
| 被测服务器 | 带 BMC/IPMI + 内存槽 | 8–16 槽优先（吞吐量关键） |
| 内存条 | DDR4 / DDR5 | Memtest86+ v9 支持 DDR4/DDR5 |

## 2. 依赖清单

| 依赖 | 用途 | 来源 | 必需性 |
| --- | --- | --- | --- |
| **ipmitool.exe** | SOL 抓流 / 断电循环 / 温度读取 | **已内置**：离线包 `tools\ipmitool\`（Windows 版 1.8.18，含依赖 DLL），脚本自动发现，免联网 | SOL 方式必需 |
| **Memtest86+ v9** | 内存测试本体 | 官方 memtest.org（ISO/EFI 已离线打包） | 必需 |
| Rufus（可选） | 制作引导 U 盘（USB 方式） | rufus.ie | 仅 USB/Serial 引导用 |
| BMC 网页控制台 | 开启 SOL / 挂载虚拟介质 | 服务器自带 | SOL 方式必需 |

## 3. BMC / BIOS 一次性配置

### 3.1 开启 SOL（各厂商常见入口）

| 厂商 | 路径 |
| --- | --- |
| Dell iDRAC9 | iDRAC 网页 → Console/Media → Serial Over LAN → Enabled |
| Supermicro | BIOS → Advanced → Serial Port Console Redirection → COM2/SOL → Enable |
| AMI 通用（浪潮/华硕等） | BIOS → Advanced → Serial Port Console Redirection → SOL/COM2 → Enable |
| Lenovo XCC | XCC 界面 → Console → Serial over LAN |

### 3.2 BIOS 串口重定向

1. BIOS → Advanced → Serial Port Console Redirection → **Enable**
2. 波特率选 **115200**（须与 Memtest86+ `log=ttyS0,115200` 一致）
3. 保存退出

> 判据：配置正确后，`ipmitool sol activate` 能看到 BIOS 启动输出；看不到则重定向/波特率没配对。

## 4. ipmitool（已内置，免安装）

离线包**已内置** Windows 版 ipmitool（`tools\ipmitool\`，1.8.18 + 依赖 DLL），脚本自动发现，**无需安装、无需联网、无需配置**。

校验（可选）：

```powershell
# 校验内置 ipmitool 可用
.\SOL内存测试离线包\tools\Setup-Tools.ps1

# 或直接看版本
.\tools\ipmitool\ipmitool.exe -V
ipmitool version 1.8.18
```

## 5. 制作 Memtest86+ 引导介质

### 5.1 BMC 虚拟介质（SOL 全自动首选）

1. BMC 网页 → Remote Console / Virtual Media → 挂载 `boot\memtest.iso`
2. 设置从虚拟光驱一次性引导
3. 引导参数加：`log=ttyS0,115200 maxpasses=4`

### 5.2 USB 引导盘（USB / Serial 方式用）

```text
1. Rufus 选择 boot\memtest.iso → 写入 FAT32 U 盘
2. （Serial 方式）编辑 U 盘根目录 syslinux.cfg，在 KERNEL 后 APPEND 加：
   log=ttyS0,115200 maxpasses=4
3. 服务器从 U 盘引导
```

## 6. Serial 方式额外依赖（可选）

| 项 | 要求 |
| --- | --- |
| null-modem 交叉串口线 | Tx/Rx 交叉 + 共地 |
| USB-RS232 转接头 | 笔记本无 DB9 时用（建议 FTDI/CP2102 芯片） |
| 端口号 | 设备管理器 → 端口 (COM 和 LPT) 确认（如 COM3） |

## 7. 一键自检清单

```powershell
# PowerShell 版本
$PSVersionTable.PSVersion

# ipmitool 可用（内置）
.\tools\ipmitool\ipmitool.exe -V

# 编排脚本可解析（无报错即可）
powershell -NoProfile -File scripts\Run-MemtestSuite.ps1 -Help

# BMC 连通
Test-NetConnection <BMC_IP> -Port 623
```
