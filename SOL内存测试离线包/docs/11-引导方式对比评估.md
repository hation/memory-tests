# 11 · 引导方式对比评估（USB / SOL / Serial / EFI）

> 状态：[当前有效]（2026-10-22）
> 变更记录：2026-10-22 文档体系编号化（对齐 disk-tests）；工程基建优化更新

> 对比四种 Memtest86+ 引导与取日志方式，给出场景化选型建议。本工具四种方式全部支持（`-BootMethod`）。

## 1. 四方式总览

| 维度 | **SOL**（BMC 串口网络化） | **Serial**（物理串口线） | **USB**（U 盘报告） | **EFI**（一次性引导） |
| --- | --- | --- | --- | --- |
| 取日志通道 | BMC → IPMI 网络（端口 623） | 物理串口线直连 | U 盘文本报告 | 需配合 SOL/Serial/USB |
| 需要网络 | 需 BMC 管理网（无需互联网） | **完全离线** | 完全离线 | 需配合取日志通道 |
| 自动化程度 | **全自动无人值守** | 全自动零按键 | 半自动（插拔+按键 F1→6） | 全自动（需取日志通道） |
| 人工干预 | 无 | 无（接好线即可） | 每批插拔 U 盘 + 按键 | 无 |
| 报告格式 | MTLOG 机器可解析 | MTLOG | 文本报告（Final Result） | 同所配合通道 |
| 自动重启（maxpasses） | ✅ log 模式生效 | ✅ log 模式生效 | ❌ 需人工按键保存 | ✅ |
| 附加能力 | 断电循环/温度读取（IPMI） | 无 | 无 | 无 |
| 设备成本 | BMC（服务器自带） | 一根交叉线（几十元） | U 盘 | 无 |

## 2. 场景选型矩阵

| 你的场景 | 推荐方式 | 理由 |
| --- | --- | --- |
| 机房批量 1000 根、有 BMC 管理网 | **SOL** | 全自动、远程无人值守、可断电报温 |
| 服务器完全无网络、要无人值守 | **Serial** | 唯一"离线+零按键"方案 |
| 单机/笔记本快速验证 1–2 根 | **USB** | 最易排查、无前置配置 |
| 无 BMC、无串口、但可本地引导 | USB（或 EFI+USB） | EFI 一次性引导自动重启，报告走 USB |

## 3. 决策建议

1. **首选 SOL**：符合"1000 根服务器批量"主场景，配合 `-RestartLoop`/`-MonitorTemp`/`-MonitorEcc` 一套全做
2. **无网兜底 Serial**：一根交叉线即可，链路最简、完全离线
3. **USB 用于验证与救急**：先跑通 1 根再切 SOL；SOL 链路异常时降级 USB 手工确认
4. **EFI 是"引导手段"而非独立方案**：用于让服务器本地一次性进 Memtest86+，取日志仍需 SOL/Serial/USB 配合
